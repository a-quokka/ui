<Callout className="mb-6 border-emerald-600 bg-emerald-100 dark:border-emerald-400 dark:bg-emerald-900">

**새로 시작하시나요?** shadcn/create 를 쓰면 테마·Base UI 또는 Radix·아이콘 라이브러리까지 설정된 Vite 앱을 바로 만들 수 있습니다.

</Callout>

<Steps>

### Create Project

`--rtl` 플래그와 `vite` 템플릿으로 새 프로젝트를 만듭니다.

**shadcn/create 로 프로젝트를 만들었다면 이 단계는 건너뛰어도 됩니다.**

```bash
npx shadcn@latest create --template vite --rtl
```

그러면 `rtl: true` 가 설정된 `components.json` 이 만들어집니다.

```json title="components.json" showLineNumbers {4}
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "base-nova",
  "rtl": true
}
```

### Add DirectionProvider

`index.html` 의 `html` 태그에 `dir="rtl"` 과 `lang="ar"` 을 붙입니다. `lang="ar"` 은 대상 언어로 바꾸세요.

```html title="index.html" showLineNumbers {2}
<!doctype html>
<html lang="ar" dir="rtl">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Vite App</title>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/src/main.tsx"></script>
  </body>
</html>
```

그다음 `main.tsx` 에서 앱을 `direction="rtl"` 을 준 `DirectionProvider` 로 감쌉니다.

```tsx title="src/main.tsx" showLineNumbers {4,12-13}
import { StrictMode } from "react"
import { createRoot } from "react-dom/client"

import { DirectionProvider } from "@/components/ui/direction"

import App from "./App"

import "./index.css"

createRoot(document.getElementById("root")!).render(
  <StrictMode>
    <DirectionProvider direction="rtl">
      <App />
    </DirectionProvider>
  </StrictMode>
)
```

### Add Font

RTL 을 제대로 쓰려면 대상 언어를 잘 지원하는 폰트를 권합니다. [Noto](https://fonts.google.com/noto) 가 이런 용도에 좋고 Inter·Geist 와도 잘 어울립니다.

[Fontsource](https://fontsource.org/fonts/noto-sans-arabic) 로 폰트를 설치합니다.

```bash
npm install @fontsource-variable/noto-sans-arabic
```

`index.css` 에서 폰트를 불러옵니다.

```css title="src/index.css" showLineNumbers {4,7}
@import "tailwindcss";
@import "tw-animate-css";
@import "shadcn/tailwind.css";
@import "@fontsource-variable/noto-sans-arabic";

@theme inline {
  --font-sans: "Noto Sans Arabic Variable", sans-serif;
}
```

히브리어처럼 다른 언어라면 `@fontsource-variable/noto-sans-hebrew` 를 쓰면 됩니다.

### Add Components

이제 컴포넌트를 추가할 준비가 됐습니다. RTL 지원은 CLI 가 알아서 처리합니다.

```bash
npx shadcn@latest add item
```

</Steps>
