`registry-item.json` 스키마로 직접 만든 레지스트리 항목을 정의합니다.

```json title="registry-item.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "hello-world",
  "type": "registry:block",
  "title": "Hello World",
  "description": "A simple hello world component.",
  "registryDependencies": [
    "button",
    "@acme/input-form",
    "https://example.com/r/foo"
  ],
  "dependencies": ["is-even@3.0.0", "motion"],
  "devDependencies": ["tw-animate-css"],
  "files": [
    {
      "path": "registry/new-york/hello-world/hello-world.tsx",
      "type": "registry:component"
    },
    {
      "path": "registry/new-york/hello-world/use-hello-world.ts",
      "type": "registry:hook"
    }
  ],
  "cssVars": {
    "theme": {
      "font-heading": "Poppins, sans-serif"
    },
    "light": {
      "brand": "oklch(0.205 0.015 18)"
    },
    "dark": {
      "brand": "oklch(0.205 0.015 18)"
    }
  }
}
```

## Definitions

`registry-item.json` 의 JSON 스키마는 [여기](https://ui.shadcn.com/schema/registry-item.json)에서 볼 수 있습니다.

### $schema

`$schema` 속성으로 `registry-item.json` 이 따를 스키마를 지정합니다.

```json title="registry-item.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json"
}
```

### name

항목의 이름입니다. 레지스트리에서 항목을 구분하는 데 쓰이며 레지스트리 안에서 겹치지 않아야 합니다.

```json title="registry-item.json" showLineNumbers
{
  "name": "hello-world"
}
```

### title

사람이 읽는 제목입니다. 짧고 분명하게 적으세요.

```json title="registry-item.json" showLineNumbers
{
  "title": "Hello World"
}
```

### description

항목 설명입니다. `title` 보다 길고 자세해도 됩니다.

```json title="registry-item.json" showLineNumbers
{
  "description": "A simple hello world component."
}
```

### type

`type` 으로 항목의 종류를 지정합니다. 프로젝트에서 항목을 풀 때 종류와 설치 경로를 정하는 데 씁니다.

```json title="registry-item.json" showLineNumbers
{
  "type": "registry:block"
}
```

쓸 수 있는 종류입니다.

| Type                 | Description                                      |
| -------------------- | ------------------------------------------------ |
| `registry:base`      | 디자인 시스템 전체에 씁니다.                     |
| `registry:block`     | 파일이 여러 개인 복합 컴포넌트에 씁니다.         |
| `registry:component` | 단순한 컴포넌트에 씁니다.                        |
| `registry:font`      | 폰트에 씁니다.                                   |
| `registry:lib`       | lib 과 utils 에 씁니다.                          |
| `registry:hook`      | 훅에 씁니다.                                     |
| `registry:ui`        | UI 컴포넌트와 파일 하나짜리 프리미티브에 씁니다. |
| `registry:page`      | 페이지나 파일 기반 라우트에 씁니다.              |
| `registry:file`      | 그 밖의 파일에 씁니다.                           |
| `registry:style`     | 레지스트리 스타일에 씁니다. 예: `new-york`.      |
| `registry:theme`     | 테마에 씁니다.                                   |
| `registry:item`      | 범용 항목에 씁니다.                              |

### author

`author` 로 항목을 만든 사람을 적습니다.

항목마다 다르게 적어도 되고 레지스트리 작성자와 같아도 됩니다.

```json title="registry-item.json" showLineNumbers
{
  "author": "John Doe <john@doe.com>"
}
```

### dependencies

`dependencies` 로 항목의 의존성을 적습니다. `npm` 패키지를 뜻합니다.

버전은 `@version` 으로 지정합니다.

```json title="registry-item.json" showLineNumbers
{
  "dependencies": [
    "@radix-ui/react-accordion",
    "zod",
    "lucide-react",
    "name@1.0.2"
  ]
}
```

### devDependencies

`devDependencies` 로 개발용 의존성을 적습니다. 개발할 때만 필요한 `npm` 패키지입니다.

패키지 버전은 `@version` 으로 지정합니다.

```json title="registry-item.json" showLineNumbers
{
  "devDependencies": ["tw-animate-css", "name@1.2.0"]
}
```

### registryDependencies

레지스트리 의존성에 씁니다. 각 항목은 주소입니다.

- `button`·`input`·`select` 같은 `shadcn/ui` 항목은 이름만 씁니다. 예: `['button', 'input', 'select']`.
- 네임스페이스 항목은 `@namespace/item-name` 을 씁니다. 예: `['@acme/input-form']`.
- GitHub 항목은 `owner/repo/item-name` 을 씁니다. 예: `['acme/ui/button']`. 공개된 레지스트리라면 태그나 전체 커밋 SHA 를 권합니다. 예: `['acme/ui/button#v1.2.0']`.
- 직접 만든 레지스트리 항목은 항목 주소를 씁니다. 예: `['https://example.com/r/hello-world.json']`.
- 로컬 항목 파일은 파일 경로를 씁니다. 예: `['./hello-world.json']`.

```json title="registry-item.json" showLineNumbers
{
  "registryDependencies": [
    "button",
    "@acme/input-form",
    "acme/ui/button#v1.2.0",
    "https://example.com/r/editor.json",
    "./editor.json"
  ]
}
```

참고: 이름만 적으면 기존 동작을 따릅니다. `button` 은 같은 GitHub 저장소의
항목이 아니라 내장 shadcn `button` 을 뜻합니다. 같은 저장소의 의존성이라면
전체 GitHub 항목 주소를 쓰세요.

ref 는 의존성에 물려받지 않습니다. GitHub 의존성을 재현 가능하게 하려면 그
의존성에도 태그나 전체 커밋 SHA 를 붙이세요.

자세한 내용은 [GitHub 레지스트리](/docs/registry/github) 문서를 보세요.

### files

`files` 로 항목에 담을 파일을 적습니다. 파일마다 `path`·`type` 이 있고 `target` 은 선택입니다.

**`registry:page` 와 `registry:file` 에는 `target` 이 반드시 필요합니다.**

```json title="registry-item.json" showLineNumbers
{
  "files": [
    {
      "path": "registry/new-york/hello-world/page.tsx",
      "type": "registry:page",
      "target": "app/hello/page.tsx"
    },
    {
      "path": "registry/new-york/hello-world/hello-world.tsx",
      "type": "registry:component"
    },
    {
      "path": "registry/new-york/hello-world/use-hello-world.ts",
      "type": "registry:hook"
    },
    {
      "path": "registry/new-york/hello-world/.env",
      "type": "registry:file",
      "target": "~/.env"
    }
  ]
}
```

#### path

`path` 로 레지스트리 안의 파일 경로를 적습니다. 빌드 스크립트가 이 경로로 파일을 읽고 변환해 레지스트리 JSON 을 만듭니다.

#### type

`type` 으로 파일의 종류를 지정합니다. 자세한 내용은 [type](#type) 절을 보세요.

#### target

`target` 으로 파일이 프로젝트의 어디에 놓일지 정합니다. 선택 사항이고 `registry:page` 와 `registry:file` 에만 필요합니다.

`shadcn` CLI 는 기본적으로 프로젝트의 `components.json` 을 읽어 설치 경로를 정합니다. 라우트나 설정처럼 일부 파일은 경로를 직접 지정할 수 있습니다.

프로젝트 루트는 `~` 로 가리킵니다. 예: `~/foo.config.js`.

사용자의 `components.json` 이 정한 디렉터리 아래에 파일을 두려면 자리표시자를
쓸 수 있습니다. 자리표시자는 `target` 맨 앞에서만 인식되며, 프로젝트가
import prefix. For example, `@ui/button.tsx` works whether the project imports
`@/`·`#`·패키지 import·워크스페이스 exports 중 무엇을 쓰든 상관없이 동작합니다.

| Placeholder    | Resolves to          |
| -------------- | -------------------- |
| `@components/` | `aliases.components` |
| `@ui/`         | `aliases.ui`         |
| `@lib/`        | `aliases.lib`        |
| `@hooks/`      | `aliases.hooks`      |

`components`·`src`·워크스페이스 패키지 경로를 박아 넣지 않고 사용자가 설정한
shadcn 디렉터리에 설치하고 싶을 때 자리표시자를 쓰세요. 자리표시자 뒤는 그대로
유지되므로 `@ui/ai/prompt-input.tsx` 는 사용자가 설정한 `ui` 디렉터리 아래
`ai/prompt-input.tsx` 로 설치됩니다.

```json title="registry-item.json" showLineNumbers
{
  "files": [
    {
      "path": "registry/new-york/example/button.tsx",
      "type": "registry:ui",
      "target": "@ui/button.tsx"
    },
    {
      "path": "registry/new-york/example/prompt-input.tsx",
      "type": "registry:ui",
      "target": "@ui/ai/prompt-input.tsx"
    },
    {
      "path": "registry/new-york/example/card.tsx",
      "type": "registry:component",
      "target": "@components/card.tsx"
    },
    {
      "path": "registry/new-york/example/helper.ts",
      "type": "registry:lib",
      "target": "@lib/helper.ts"
    },
    {
      "path": "registry/new-york/example/use-demo.ts",
      "type": "registry:hook",
      "target": "@hooks/use-demo.ts"
    }
  ]
}
```

파일이 어디에 쓰일지는 `target` 이 정합니다. 파일 `type` 과 다른 디렉터리를
가리켜도 됩니다.

```json title="registry-item.json" showLineNumbers
{
  "files": [
    {
      "path": "registry/new-york/example/format-date.ts",
      "type": "registry:ui",
      "target": "@lib/format-date.ts"
    }
  ]
}
```

모르는 자리표시자는 평범한 경로로 봅니다. 예를 들어 `@foo/bar.ts` 는
`foo/bar.ts` 로 쓰입니다. `components/@ui/button.tsx` 처럼 중간에 낀 자리표시자도
평범한 경로로 봅니다.

<Callout>
  `utils` 는 디렉터리가 아니라 파일을 가리키므로 `@utils/` 는 지원하지 않습니다.
</Callout>

### tailwind

**더 이상 쓰지 않습니다.** Tailwind v4 프로젝트에서는 `cssVars.theme` 을 쓰세요.

`tailwind` 로 `theme`·`plugins`·`content` 같은 tailwind 설정을 적습니다.

`tailwind.config` 로 항목에 색·애니메이션·플러그인을 더할 수 있습니다.

```json title="registry-item.json" showLineNumbers
{
  "tailwind": {
    "config": {
      "theme": {
        "extend": {
          "colors": {
            "brand": "hsl(var(--brand))"
          },
          "keyframes": {
            "wiggle": {
              "0%, 100%": { "transform": "rotate(-3deg)" },
              "50%": { "transform": "rotate(3deg)" }
            }
          },
          "animation": {
            "wiggle": "wiggle 1s ease-in-out infinite"
          }
        }
      }
    }
  }
}
```

### cssVars

항목의 CSS 변수를 정의할 때 씁니다.

```json title="registry-item.json" showLineNumbers
{
  "cssVars": {
    "theme": {
      "font-heading": "Poppins, sans-serif"
    },
    "light": {
      "brand": "20 14.3% 4.1%",
      "radius": "0.5rem"
    },
    "dark": {
      "brand": "20 14.3% 4.1%"
    }
  }
}
```

### css

`css` 로 프로젝트 CSS 파일에 규칙을 더합니다. `@layer base`·`@layer components`·`@utility`·`@keyframes`·`@plugin` 등을 쓸 수 있습니다.

```json title="registry-item.json" showLineNumbers
{
  "css": {
    "@plugin @tailwindcss/typography": {},
    "@plugin foo": {},
    "@layer base": {
      "body": {
        "font-size": "var(--text-base)",
        "line-height": "1.5"
      }
    },
    "@layer components": {
      "button": {
        "background-color": "var(--color-primary)",
        "color": "var(--color-white)"
      }
    },
    "@utility text-magic": {
      "font-size": "var(--text-base)",
      "line-height": "1.5"
    },
    "@keyframes wiggle": {
      "0%, 100%": {
        "transform": "rotate(-3deg)"
      },
      "50%": {
        "transform": "rotate(3deg)"
      }
    }
  }
}
```

### envVars

`envVars` 로 항목에 환경 변수를 더합니다.

```json title="registry-item.json" showLineNumbers
{
  "envVars": {
    "NEXT_PUBLIC_APP_URL": "http://localhost:4000",
    "DATABASE_URL": "postgresql://postgres:postgres@localhost:5432/postgres",
    "OPENAI_API_KEY": ""
  }
}
```

환경 변수는 `.env.local` 이나 `.env` 에 추가됩니다. 기존 변수는 덮어쓰지 않습니다.

<Callout>

**중요:** `envVars` 는 개발용이나 예시 변수를 넣는 용도입니다. 운영 변수를 넣지 마세요.

</Callout>

### font

`registry:font` 에는 `font` 가 반드시 필요합니다. 폰트 계열·제공자·import 이름·CSS 변수, 그리고 Next.js 가 아닌 프로젝트에 설치할 npm 패키지를 정합니다.

```json title="registry-item.json" showLineNumbers
{
  "font": {
    "family": "'Inter Variable', sans-serif",
    "provider": "google",
    "import": "Inter",
    "variable": "--font-sans",
    "subsets": ["latin"],
    "dependency": "@fontsource-variable/inter"
  }
}
```

| Property     | Type       | Required | Description                                                                           |
| ------------ | ---------- | -------- | ------------------------------------------------------------------------------------- |
| `family`     | `string`   | Yes      | CSS font-family 값입니다.                                                             |
| `provider`   | `string`   | Yes      | 폰트 제공자입니다. 지금은 `google` 만 지원합니다.                                     |
| `import`     | `string`   | Yes      | `next/font/google` 에서 가져올 이름입니다.                                            |
| `variable`   | `string`   | Yes      | 폰트에 쓸 CSS 변수 이름입니다(예: `--font-sans`·`--font-mono`).                       |
| `weight`     | `string[]` | No       | 포함할 폰트 굵기 배열입니다.                                                          |
| `subsets`    | `string[]` | No       | 포함할 폰트 서브셋 배열입니다.                                                        |
| `selector`   | `string`   | No       | 폰트를 적용할 CSS 선택자입니다. 기본값은 `html` 입니다.                               |
| `dependency` | `string`   | No       | Next.js 가 아닌 프로젝트에 설치할 npm 패키지입니다(예: `@fontsource-variable/inter`). |

### docs

`docs` 로 CLI 설치 시 보여 줄 안내나 메시지를 담습니다.

```json title="registry-item.json" showLineNumbers
{
  "docs": "To get an OPENAI_API_KEY, sign up for an account at https://platform.openai.com."
}
```

### categories

`categories` 로 항목을 갈래별로 정리합니다.

```json title="registry-item.json" showLineNumbers
{
  "categories": ["sidebar", "dashboard"]
}
```

### meta

`meta` 로 항목에 메타데이터를 더합니다. 원하는 키·값을 자유롭게 담을 수 있습니다.

```json title="registry-item.json" showLineNumbers
{
  "meta": { "foo": "bar" }
}
```
