`shadcn` CLI 로 직접 코드 레지스트리를 운영할 수 있습니다. 그러면 직접 만든 컴포넌트·훅·페이지·설정·규칙 같은 파일을 어떤 프로젝트로든 나를 수 있습니다.

<Callout>
  **참고:** 레지스트리는 프로젝트 종류와 프레임워크를 가리지 않습니다. React
  전용이 아닙니다.
</Callout>
