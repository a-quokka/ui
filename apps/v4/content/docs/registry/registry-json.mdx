`registry.json` 스키마로 직접 만든 컴포넌트 레지스트리를 정의합니다.

```json title="registry.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry.json",
  "name": "shadcn",
  "homepage": "https://ui.shadcn.com",
  "items": [
    {
      "name": "hello-world",
      "type": "registry:block",
      "title": "Hello World",
      "description": "A simple hello world component.",
      "registryDependencies": [
        "button",
        "@acme/input-form",
        "https://example.com/r/foo"
      ],
      "dependencies": ["is-even@3.0.0", "motion"],
      "files": [
        {
          "path": "registry/default/hello-world/hello-world.tsx",
          "type": "registry:component"
        }
      ]
    }
  ]
}
```

레지스트리가 크다면 `include` 로 여러 `registry.json` 에 나눠 정리할 수
있습니다.

{/* prettier-ignore */}
```json title="registry.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry.json",
  "name": "acme",
  "homepage": "https://acme.com",
  "include": [
    "components/ui/registry.json",
    "hooks/registry.json"
  ]
}
```

공개 GitHub 저장소도 같은 원본 형식을 씁니다. CLI 가 루트 `registry.json` 을
읽고 `include` 를 풀어 저장소의 파일을 설치합니다. 자세한 내용은
[GitHub 레지스트리](/docs/registry/github) 문서를 보세요.

## Definitions

`registry.json` 의 JSON 스키마는 [여기](https://ui.shadcn.com/schema/registry.json)에서 볼 수 있습니다.

### $schema

`$schema` 속성으로 `registry.json` 이 따를 스키마를 지정합니다.

```json title="registry.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry.json"
}
```

### name

`name` 으로 레지스트리 이름을 지정합니다. 데이터 속성과 메타데이터에 쓰입니다.

```json title="registry.json" showLineNumbers
{
  "name": "acme"
}
```

### homepage

레지스트리의 홈페이지입니다. 데이터 속성과 메타데이터에 쓰입니다.

```json title="registry.json" showLineNumbers
{
  "homepage": "https://acme.com"
}
```

### include

`include` 로 다른 `registry.json` 을 엮어 레지스트리를 구성합니다.

{/* prettier-ignore */}
```json title="registry.json" showLineNumbers
{
  "include": [
    "components/ui/registry.json",
    "hooks/registry.json"
  ]
}
```

include 경로는 `registry.json` 파일을 직접 가리키는 상대 경로여야 합니다.
폴더만 적는 축약은 지원하지 않습니다.

{/* prettier-ignore */}
```json title="registry.json" showLineNumbers
{
  "include": [
    "components/ui/registry.json"
  ]
}
```

포함되는 `registry.json` 은 `name` 과 `homepage` 를 생략해도 됩니다. 이 필드는
루트 `registry.json` 에만 필요합니다.

```json title="components/ui/registry.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry.json",
  "items": [
    {
      "name": "button",
      "type": "registry:ui",
      "files": [
        {
          "path": "button.tsx",
          "type": "registry:ui"
        }
      ]
    }
  ]
}
```

`shadcn build` 가 include 를 풀 때 파일 경로는 그 항목을 선언한
`registry.json` 기준으로 읽습니다. 생성된 결과는 평평하게 펴져 있고 `include` 가
들어 있지 않습니다.

항목 이름은 포함된 파일까지 통틀어 레지스트리 전체에서 겹치지 않아야 합니다.

### items

레지스트리의 `items` 입니다. 각 항목은 [registry-item 스키마 규격](https://ui.shadcn.com/schema/registry-item.json)을 따라야 합니다.

```json title="registry.json" showLineNumbers
{
  "items": [
    {
      "name": "hello-world",
      "type": "registry:block",
      "title": "Hello World",
      "description": "A simple hello world component.",
      "registryDependencies": [
        "button",
        "@acme/input-form",
        "https://example.com/r/foo"
      ],
      "dependencies": ["is-even@3.0.0", "motion"],
      "files": [
        {
          "path": "registry/default/hello-world/hello-world.tsx",
          "type": "registry:component"
        }
      ]
    }
  ]
}
```

루트 `registry.json` 에는 `items` 나 `include` 중 하나는 있어야 합니다. `items`
를 생략하면 빈 배열로 봅니다.

자세한 내용은 [registry-item 스키마 문서](/docs/registry/registry-item-json)를 보세요.
