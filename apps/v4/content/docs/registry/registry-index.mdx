---
title: 레지스트리 디렉터리
description: 오픈소스 레지스트리 색인
---

오픈소스 레지스트리 색인은 별도 설정 없이 바로 쓸 수 있는 오픈소스 레지스트리 목록입니다.

`shadcn add` 나 `shadcn search` 를 돌리면 CLI 가 색인에서 그 레지스트리를 찾아 `components.json` 에 추가합니다.

전체 목록은 [https://ui.shadcn.com/r/registries.json](https://ui.shadcn.com/r/registries.json) 에서 볼 수 있습니다.

공개 GitHub 레지스트리를 `owner/repo/item` 주소로 쓰는 데는 디렉터리 등록이
필요 없습니다. 디렉터리는 `@acme` 같은 네임스페이스를 위한 것입니다.

## Adding a Registry

1. [`apps/v4/registry/directory.json`](https://github.com/shadcn-ui/ui/blob/main/apps/v4/registry/directory.json) 에 레지스트리를 추가합니다
2. `pnpm validate:registries` 로 디렉터리를 검증합니다
3. https://github.com/shadcn-ui/ui 에 풀 리퀘스트를 올립니다

요청을 올리면 팀이 검증하고 검토합니다.

## Requirements

1. 레지스트리가 오픈소스이고 공개돼 있어야 합니다.
2. [registry 스키마 규격](/docs/registry/registry-json)을 따르는 올바른 JSON 이어야 합니다.
3. 중첩 없이 평평한 구조여야 합니다. 즉 `/registry.json` 과 `/component-name.json` 이 레지스트리 루트에 있어야 합니다.
4. `files` 배열이 있다면 `content` 속성을 담아서는 안 됩니다.

올바른 레지스트리 예시입니다.

```json title="registry.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry.json",
  "name": "acme",
  "homepage": "https://acme.com",
  "items": [
    {
      "name": "login-form",
      "type": "registry:component",
      "title": "Login Form",
      "description": "A login form component.",
      "files": [
        {
          "path": "registry/new-york/auth/login-form.tsx",
          "type": "registry:component"
        }
      ]
    },
    {
      "name": "example-login-form",
      "type": "registry:component",
      "title": "Example Login Form",
      "description": "An example showing how to use the login form component.",
      "files": [
        {
          "path": "registry/new-york/examples/example-login-form.tsx",
          "type": "registry:component"
        }
      ]
    }
  ]
}
```
