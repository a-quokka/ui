## registry:style

### Custom style that extends Dropshot UI

아래 항목은 Dropshot UI 를 확장하는 커스텀 스타일입니다. `npx shadcn init` 을 돌리면 이런 일이 일어납니다.

- `@tabler/icons-react` 를 의존성으로 설치합니다.
- `login-01` 블록과 `calendar` 컴포넌트를 프로젝트에 넣습니다.
- 원격 레지스트리에서 `editor` 를 가져옵니다.
- `font-sans` 변수를 `Inter, sans-serif` 로 지정합니다.
- 라이트·다크 모드에 `brand` 색을 넣습니다.

```json title="example-style.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "example-style",
  "type": "registry:style",
  "dependencies": ["@tabler/icons-react"],
  "registryDependencies": [
    "login-01",
    "calendar",
    "https://example.com/r/editor.json"
  ],
  "cssVars": {
    "theme": {
      "font-sans": "Inter, sans-serif"
    },
    "light": {
      "brand": "20 14.3% 4.1%"
    },
    "dark": {
      "brand": "20 14.3% 4.1%"
    }
  }
}
```

### Custom style from scratch

아래 항목은 Dropshot UI 를 확장하지 않는 커스텀 스타일입니다. `extends: none` 필드를 보세요.

커스텀 컴포넌트·CSS 변수·의존성까지 스타일을 처음부터 새로 만들 때 씁니다.

`npx shadcn add` 를 돌리면 이런 일이 일어납니다.

- `tailwind-merge` 와 `clsx` 를 의존성으로 설치합니다.
- Dropshot UI 레지스트리에서 `utils` 항목을 가져옵니다.
- 원격 레지스트리에서 `button`·`input`·`label`·`select` 를 가져옵니다.
- 새 CSS 변수 `main`·`bg`·`border`·`text`·`ring` 을 넣습니다.

```json title="example-style.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "extends": "none",
  "name": "new-style",
  "type": "registry:style",
  "dependencies": ["tailwind-merge", "clsx"],
  "registryDependencies": [
    "utils",
    "https://example.com/r/button.json",
    "https://example.com/r/input.json",
    "https://example.com/r/label.json",
    "https://example.com/r/select.json"
  ],
  "cssVars": {
    "theme": {
      "font-sans": "Inter, sans-serif"
    },
    "light": {
      "main": "#88aaee",
      "bg": "#dfe5f2",
      "border": "#000",
      "text": "#000",
      "ring": "#000"
    },
    "dark": {
      "main": "#88aaee",
      "bg": "#272933",
      "border": "#000",
      "text": "#e6e6e6",
      "ring": "#fff"
    }
  }
}
```

### Install a block and override primitives

Dropshot UI 레지스트리의 블록을 설치하면서 프리미티브만 직접 만든 것으로 바꿀 수 있습니다.

`npx shadcn add` 를 돌리면 이런 일이 일어납니다.

- Dropshot UI 레지스트리에서 `login-01` 블록을 가져옵니다.
- `button`·`input`·`label` 프리미티브를 원격 레지스트리의 것으로 바꿉니다.

```json title="example-style.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "custom-login",
  "type": "registry:block",
  "registryDependencies": [
    "login-01",
    "https://example.com/r/button.json",
    "https://example.com/r/input.json",
    "https://example.com/r/label.json"
  ]
}
```

## registry:lib

### Utility library

`registry:lib` 는 유틸리티 라이브러리입니다. 헬퍼 함수·상수처럼 컴포넌트가 아닌 코드를 나눌 때 씁니다.

```json title="utils.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "utils",
  "type": "registry:lib",
  "dependencies": ["clsx", "tailwind-merge"],
  "files": [
    {
      "path": "lib/utils.ts",
      "content": "import { clsx, type ClassValue } from \"clsx\"\nimport { twMerge } from \"tailwind-merge\"\n\nexport function cn(...inputs: ClassValue[]) {\n  return twMerge(clsx(inputs))\n}",
      "type": "registry:lib"
    }
  ]
}
```

## Target Placeholders

사용자가 설정한 shadcn 디렉터리 아래에 파일을 설치해야 한다면 `files[].target`
자리표시자를 쓰세요. `@components/`·`@ui/`·`@lib/`·`@hooks/` 를 쓸 수 있습니다.

자리표시자는 `components.json` 을 보고 풀리므로, `@/` 를 쓰든 커스텀 TypeScript
별칭·패키지 import·워크스페이스 exports 를 쓰든 같은 항목이 그대로 동작합니다.

자리표시자 뒤는 그대로 유지됩니다. 예를 들어 `@ui/ai/prompt-input.tsx` 는
사용자가 설정한 `ui` 디렉터리 아래 `ai/prompt-input.tsx` 로 설치됩니다.

```json title="alias-child.json" showLineNumbers {9,15,21}
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "alias-child",
  "type": "registry:item",
  "files": [
    {
      "path": "registry/new-york/alias/target-alias-button.tsx",
      "type": "registry:ui",
      "target": "@ui/target-alias-button.tsx",
      "content": "..."
    },
    {
      "path": "registry/new-york/alias/target-alias-helper.ts",
      "type": "registry:lib",
      "target": "@lib/target-alias-helper.ts",
      "content": "..."
    },
    {
      "path": "registry/new-york/alias/prompt-input.tsx",
      "type": "registry:ui",
      "target": "@ui/ai/prompt-input.tsx",
      "content": "..."
    }
  ]
}
```

레지스트리 의존성도 자리표시자를 쓸 수 있습니다. 아래 예시에서 자식 항목은 UI
컴포넌트와 헬퍼를, 부모 항목은 앱 컴포넌트와 훅을 설치합니다.

```json title="alias-parent.json" showLineNumbers {7,13}
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "alias-parent",
  "type": "registry:item",
  "registryDependencies": ["https://example.com/r/alias-child.json"],
  "files": [
    {
      "path": "registry/new-york/alias/target-alias-panel.tsx",
      "type": "registry:component",
      "target": "@components/target-alias-panel.tsx",
      "content": "..."
    },
    {
      "path": "registry/new-york/alias/use-target-alias.ts",
      "type": "registry:hook",
      "target": "@hooks/use-target-alias.ts",
      "content": "..."
    }
  ]
}
```

파일이 어디에 쓰일지는 `target` 이 정합니다. 파일 `type` 과 달라도 `target` 이
우선입니다.

```json title="type-mismatch.json" showLineNumbers {9}
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "type-mismatch",
  "type": "registry:item",
  "files": [
    {
      "path": "registry/new-york/example/format-date.ts",
      "type": "registry:ui",
      "target": "@lib/format-date.ts",
      "content": "..."
    }
  ]
}
```

## registry:font

### Custom font

`registry:font` 는 Google Font 를 설치합니다. `font` 필드는 필수이고 폰트 계열·제공자·import 이름·CSS 변수를 정합니다.

```json title="font-inter.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "font-inter",
  "type": "registry:font",
  "font": {
    "family": "'Inter Variable', sans-serif",
    "provider": "google",
    "import": "Inter",
    "variable": "--font-sans",
    "subsets": ["latin"],
    "dependency": "@fontsource-variable/inter"
```

```json title="font-lora.json" showLineNumbers
}
```

### Font with custom selector

폰트를 `html` 전체가 아니라 특정 선택자에만 적용하려면 `selector` 필드를 쓰세요. 제목용 폰트처럼 일부에만 적용할 때 유용합니다.

```json title="font-playfair-display.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "font-playfair-display",
  "type": "registry:font",
  "font": {
    "family": "'Playfair Display Variable', serif",
    "provider": "google",
    "import": "Playfair_Display",
    "variable": "--font-heading",
    "subsets": ["latin"],
    "selector": "h1, h2, h3, h4, h5, h6",
    "dependency": "@fontsource-variable/playfair-display"
  }
}
```

`selector` 를 지정하면 폰트 유틸리티 클래스(예: `font-heading`)가 `<html>` 에 붙는 대신 `@layer base` 안에서 그 선택자에 `@apply` 로 적용됩니다. CSS 변수는 여전히 `<html>` 에 주입되므로 전역에서 쓸 수 있습니다.

## registry:base

### Custom base

`registry:base` 는 디자인 시스템의 토대 전체입니다. 프로젝트에 필요한 의존성·CSS 변수·설정을 모두 정의합니다. `config` 필드는 `registry:base` 에만 있습니다.

`config` 필드는 아래 속성을 받습니다(모두 선택).

| Property             | Type                                                                         | Description                                                          |
| -------------------- | ---------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| `style`              | `string`                                                                     | 이 토대의 스타일 이름입니다.                                         |
| `iconLibrary`        | `string`                                                                     | 쓸 아이콘 라이브러리입니다(예: `lucide`).                            |
| `rsc`                | `boolean`                                                                    | React Server Components 를 켤지 여부입니다. 기본값은 `false` 입니다. |
| `tsx`                | `boolean`                                                                    | TypeScript 를 쓸지 여부입니다. 기본값은 `true` 입니다.               |
| `rtl`                | `boolean`                                                                    | 오른쪽에서 왼쪽 배치를 켤지 여부입니다. 기본값은 `false` 입니다.     |
| `menuColor`          | `"default" \| "inverted" \| "default-translucent" \| "inverted-translucent"` | 메뉴 색 구성입니다. 기본값은 `"default"` 입니다.                     |
| `menuAccent`         | `"subtle" \| "bold"`                                                         | 메뉴 강조 스타일입니다. 기본값은 `"subtle"` 입니다.                  |
| `tailwind.baseColor` | `string`                                                                     | 기준 색 이름입니다(예: `neutral`·`slate`·`zinc`).                    |
| `tailwind.css`       | `string`                                                                     | Tailwind CSS 파일의 경로입니다.                                      |
| `tailwind.prefix`    | `string`                                                                     | 모든 Tailwind 클래스에 붙일 접두사입니다.                            |
| `aliases.components` | `string`                                                                     | 컴포넌트의 import 별칭입니다.                                        |
| `aliases.utils`      | `string`                                                                     | 유틸리티의 import 별칭입니다.                                        |
| `aliases.ui`         | `string`                                                                     | UI 컴포넌트의 import 별칭입니다.                                     |
| `aliases.lib`        | `string`                                                                     | lib 의 import 별칭입니다.                                            |
| `aliases.hooks`      | `string`                                                                     | hooks 의 import 별칭입니다.                                          |
| `registries`         | `Record<string, string \| object>`                                           | 직접 쓰는 레지스트리 주소입니다. 키는 `@` 로 시작해야 합니다.        |

```json title="custom-base.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "custom-base",
  "type": "registry:base",
  "config": {
    "style": "custom-base",
    "iconLibrary": "lucide",
    "tailwind": {
      "baseColor": "neutral"
    }
  },
  "dependencies": [
    "class-variance-authority",
    "tw-animate-css",
    "lucide-react"
  ],
  "registryDependencies": ["utils", "font-inter"],
  "cssVars": {
    "light": {
      "background": "oklch(1 0 0)",
      "foreground": "oklch(0.141 0.005 285.823)",
      "primary": "oklch(0.21 0.006 285.885)",
      "primary-foreground": "oklch(0.985 0 0)"
    },
    "dark": {
      "background": "oklch(0.141 0.005 285.823)",
      "foreground": "oklch(0.985 0 0)",
      "primary": "oklch(0.985 0 0)",
      "primary-foreground": "oklch(0.21 0.006 285.885)"
    }
  },
  "css": {
    "@import \"tw-animate-css\"": {},
    "@layer base": {
      "*": {
        "@apply border-border outline-ring/50": {}
      },
      "body": {
        "@apply bg-background text-foreground": {}
      }
    }
  }
}
```

### Metadata

`meta` 필드로 항목에 원하는 메타데이터를 붙일 수 있습니다. 직접 만든 도구나 스크립트가 쓸 데이터를 담아 두면 됩니다.

```json title="example-item.json" showLineNumbers {5-8}
  "name": "custom-component",
  "type": "registry:ui",

    }
  ]
```
```json title="example-functional.json" showLineNumbers
}
```

## Add CSS imports

`@import` 로 항목에 CSS import 를 넣습니다. import 는 CSS 파일 맨 위에 놓입니다.

### Basic import

```json title="example-import.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "custom-import",
  "type": "registry:component",
  "css": {
    "@import \"tailwindcss\"": {},
    "@import \"./styles/base.css\"": {}
  }
}
```

### Import with url() syntax

```json title="example-url-import.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "font-import",
  "type": "registry:item",
  "css": {
    "@import url(\"https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&display=swap\")": {},
    "@import url('./local-styles.css')": {}
  }
}
```

### Import with media queries

```json title="example-media-import.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "responsive-import",
  "type": "registry:item",
  "css": {
    "@import \"print-styles.css\" print": {},
    "@import url(\"mobile.css\") screen and (max-width: 768px)": {}
  }
}
```

## Add custom plugins

`@plugin` 으로 항목에 Tailwind 플러그인을 넣습니다. 플러그인은 import 뒤, 다른 내용 앞에 자동으로 놓입니다.

**중요:** npm 패키지의 플러그인을 쓴다면 `dependencies` 배열에도 넣어야 합니다.

### Basic plugin usage

```json title="example-plugin.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "custom-plugin",
  "type": "registry:item",
  "css": {
    "@plugin \"@tailwindcss/typography\"": {},
    "@plugin \"foo\"": {}
  }
}
```

### Plugin with npm dependency

`@tailwindcss/typography` 처럼 npm 패키지의 플러그인을 쓸 때는 의존성에도 넣으세요.

```json title="example-typography.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "typography-component",
  "type": "registry:item",
  "dependencies": ["@tailwindcss/typography"],
  "css": {
    "@plugin \"@tailwindcss/typography\"": {},
    "@layer components": {
      ".prose": {
        "max-width": "65ch"
      }
    }
  }
}
```

### Scoped and file-based plugins

```json title="example-scoped-plugin.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "scoped-plugins",
  "type": "registry:component",
  "css": {
    "@plugin \"@headlessui/tailwindcss\"": {},
    "@plugin \"tailwindcss/plugin\"": {},
    "@plugin \"./custom-plugin.js\"": {}
  }
}
```

### Multiple plugins with automatic ordering

플러그인을 여러 개 넣으면 자동으로 한데 묶이고 중복이 제거됩니다.

```json title="example-multiple-plugins.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "multiple-plugins",
  "type": "registry:item",
  "dependencies": [
    "@tailwindcss/typography",
    "@tailwindcss/forms",
    "tw-animate-css"
  ],
  "css": {
    "@plugin \"@tailwindcss/typography\"": {},
    "@plugin \"@tailwindcss/forms\"": {},
    "@plugin \"tw-animate-css\"": {}
  }
}
```

## Combined imports and plugins

`@import` 와 `@plugin` 을 함께 쓰면 import 가 먼저, 그다음 플러그인, 그다음 나머지 CSS 가 놓입니다.

```json title="example-combined.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "combined-example",
  "type": "registry:item",
  "dependencies": ["@tailwindcss/typography", "tw-animate-css"],
  "css": {
    "@import \"tailwindcss\"": {},
    "@import url(\"https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&display=swap\")": {},
    "@plugin \"@tailwindcss/typography\"": {},
    "@plugin \"tw-animate-css\"": {},
    "@layer base": {
      "body": {
        "font-family": "Inter, sans-serif"
      }
    },
    "@utility content-auto": {
      "content-visibility": "auto"
    }
  }
}
```

## Add custom animations

참고: 애니메이션을 쓰려면 css 의 `@keyframes` 와 cssVars 의 `theme` 을 모두 정의해야 합니다.

```json title="example-component.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "custom-component",
  "type": "registry:component",
  "cssVars": {
    "theme": {
      "--animate-wiggle": "wiggle 1s ease-in-out infinite"
    }
  },
  "css": {
    "@keyframes wiggle": {
      "0%, 100%": {
        "transform": "rotate(-3deg)"
      },
      "50%": {
        "transform": "rotate(3deg)"
      }
    }
  }
}
```

## Add environment variables

`envVars` 필드로 환경 변수를 넣을 수 있습니다.

```json title="example-item.json" showLineNumbers {5-9}
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "custom-item",
  "type": "registry:item",
  "envVars": {
    "NEXT_PUBLIC_APP_URL": "http://localhost:4000",
    "DATABASE_URL": "postgresql://postgres:postgres@localhost:5432/postgres",
    "OPENAI_API_KEY": ""
  }
}
```

환경 변수는 `.env.local` 이나 `.env` 에 추가됩니다. 기존 변수는 덮어쓰지 않습니다.

<Callout>

**중요:** `envVars` 는 개발용이나 예시 변수를 넣는 용도입니다. 운영 변수를 넣지 마세요.

</Callout>

## Universal Items

`2.9.0` 부터는 프레임워크 감지나 components.json 없이 설치되는 범용 항목을 만들 수 있습니다.

항목을 범용, 즉 프레임워크를 가리지 않게 만들려면 항목의 모든 파일에 대상이 명시돼 있어야 합니다.

_python_ 용 Cursor 규칙을 설치하는 항목 예시입니다.

```json title=".cursor/rules/custom-python.mdc" showLineNumbers {9}
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "python-rules",
  "type": "registry:item",
  "files": [
    {
      "path": "/path/to/your/registry/default/custom-python.mdc",
      "type": "registry:file",
      "target": "~/.cursor/rules/custom-python.mdc",
      "content": "..."
    }
  ]
}
```

직접 만든 ESLint 설정을 설치하는 예시입니다.

```json title=".eslintrc.json" showLineNumbers {9}
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "my-eslint-config",
  "type": "registry:item",
  "files": [
    {
      "path": "/path/to/your/registry/default/custom-eslint.json",
      "type": "registry:file",
      "target": "~/.eslintrc.json",
      "content": "..."
    }
  ]
}
```

파일을 여러 개 설치하는 범용 항목도 만들 수 있습니다.

```json title="my-custom-starter-template.json" showLineNumbers {9}
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "my-custom-starter-template",
  "type": "registry:item",
  "dependencies": ["better-auth"],
  "files": [
    {
      "path": "/path/to/file-01.json",
      "type": "registry:file",
      "target": "~/file-01.json",
      "content": "..."
    },
    {
      "path": "/path/to/file-02.vue",
      "type": "registry:file",
      "target": "~/pages/file-02.vue",
      "content": "..."
    }
  ]
}
```
