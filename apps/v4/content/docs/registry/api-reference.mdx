---

`shadcn` 패키지는 CLI 말고도 코드에서 쓸 수 있는 API 를 제공합니다. 이것으로
레지스트리 항목을 가져오고 풀고 설치하거나, 레지스트리 JSON 을 검증하거나,
레지스트리 위에 직접 도구를 만들 수 있습니다.

각 API 는 전용 하위 경로로 import 합니다.

```ts
import { getRegistryItems } from "shadcn/registry"
import { registryItemSchema } from "shadcn/schema"
```

<Callout className="mt-6">
  CLI 명령 자체는 공개 API 가 아닙니다. 아래 문서에 있는 import 만 안정적인
  것으로 봅니다.
</Callout>

## shadcn/registry

설정된 레지스트리에서 항목을 가져오고 풀어냅니다.

대부분의 함수는 옵션 객체를 받습니다. 아래 두 옵션은 모든 함수에 공통입니다.
이어지는 예시에서 `config` 가 이 값을 가리키며, 생략하면 내장 레지스트리를
씁니다.

### config

- **타입:** `Partial<Config>`
- **기본값:** 내장 레지스트리만

쓸 레지스트리 설정입니다. `registries` 필드가 네임스페이스(예: `@acme`)를
주소와, 거기에 닿는 데 필요한 인증 헤더나 환경 변수에 연결합니다. 프로젝트에서
불러오려면 [`getRegistriesConfig`](#getregistriesconfig) 를 쓰세요.

```ts showLineNumbers
import { getRegistryItems } from "shadcn/registry"

const items = await getRegistryItems(["@acme/login-form"], {
  config: {
    registries: {
      "@acme": "https://acme.com/r/{name}.json",
    },
  },
})
```

### useCache

- **타입:** `boolean`
- **기본값:** `true`

레지스트리 응답은 해석된 주소를 키로 삼아 **프로세스가 사는 동안 메모리에**
캐시됩니다. 진행 중인 promise 도 캐시되므로 같은 주소로 동시에 들어온 요청은
하나의 fetch 로 합쳐집니다.

한 번 돌리고 마는 스크립트나 CLI 에서는 켜 두세요. 서버·워처·MCP 서버처럼
오래 도는 프로세스에서는 요청 사이에 레지스트리가 바뀔 수 있으니 `false` 로
두고 매번 새로 받으세요.

```ts
const fresh = await getRegistry("@shadcn", { useCache: false })
```

### getRegistriesConfig

프로젝트 디렉터리에서 레지스트리 설정을 읽습니다. `components.json` 이 있으면
그것을, 없으면 `package.json` 최상위의 `registries` 필드를 읽습니다.

```ts showLineNumbers
import { getRegistriesConfig } from "shadcn/registry"

const config = await getRegistriesConfig(process.cwd())
```

### getRegistry

이름으로 레지스트리 하나를 가져옵니다.

```ts showLineNumbers
import { getRegistry } from "shadcn/registry"

const registry = await getRegistry("@acme", {
  config, // optional Partial<Config>
  useCache: true,
})
```

### getRegistryItems

정규화된 이름으로 레지스트리 항목을 하나 이상 가져옵니다.

```ts showLineNumbers
import { getRegistryItems } from "shadcn/registry"

const items = await getRegistryItems(["@acme/button", "@acme/card"], {
  config,
  useCache: true,
})
```

레지스트리 항목 배열을 돌려줍니다.

```json showLineNumbers
[
  {
    "name": "button",
    "type": "registry:ui",
    "dependencies": ["@radix-ui/react-slot"],
    "files": [
      {
        "path": "ui/button.tsx",
        "type": "registry:ui",
        "content": "..."
      }
    ]
  }
]
```

### resolveRegistryItems

여러 항목과 그 레지스트리 의존성을 함께 풀어 하나의 트리로 합칩니다. 항목을
목록으로 돌려주는 [`getRegistryItems`](#getregistryitems) 와 달리, 각 항목의
`registryDependencies` 를 따라가며 파일·의존성·CSS 변수를 모두 평평하게 펴서
설치 가능한 객체 하나로 만듭니다.

```ts showLineNumbers
import { resolveRegistryItems } from "shadcn/registry"

const tree = await resolveRegistryItems(
  ["@acme/button", "@acme/card", "@acme/dialog"],
  { config }
)
```

합쳐진 트리 하나를 돌려줍니다.

```json showLineNumbers
{
  "dependencies": ["@radix-ui/react-slot", "@radix-ui/react-dialog"],
  "files": [
    { "path": "ui/button.tsx", "type": "registry:ui", "content": "..." },
    { "path": "ui/card.tsx", "type": "registry:ui", "content": "..." },
    { "path": "ui/dialog.tsx", "type": "registry:ui", "content": "..." }
  ],
  "cssVars": {
    "theme": {
      "font-heading": "Poppins, sans-serif"
    },
    "light": {
      "brand": "oklch(0.205 0.015 18)"
    },
    "dark": {
      "brand": "oklch(0.205 0.015 18)"
    }
  },
  "docs": ""
}
```

### addRegistryItems

레지스트리 항목을 풀어 기존 프로젝트에 설치합니다. `shadcn add` 를 코드로
부르는 것과 같고, 항목이 선언한 파일·패키지 의존성·환경 변수·CSS·Tailwind
설정을 적용합니다.

```ts showLineNumbers
import { addRegistryItems, getRegistriesConfig } from "shadcn/registry"

const cwd = process.cwd()
const config = await getRegistriesConfig(cwd)

await addRegistryItems(["@acme/agent"], {
  cwd,
  config,
  overwrite: false,
  silent: true,
})
```

`addRegistryItems` 는 프로젝트 설정 파일을 스스로 읽지 않습니다.
[`getRegistriesConfig`](#getregistriesconfig) 의 결과를 넘기거나 `config` 를 직접
주세요. 요청한 항목과 의존성이 모두 범용이라면, 즉 파일마다 대상이 명시된
`registry:item` 이나 `registry:file` 뿐이라면 `registries` 만 담은 설정으로도
충분합니다. 그 밖의 항목은 별칭과 `resolvedPaths` 를 포함한 완전한 프로젝트
설정이 필요합니다. 항목이나 의존성이 참조하는 커스텀 네임스페이스는 모두
`config` 에 있어야 합니다.

이 함수는 프로세스를 끝내는 대신 오류를 던지며 아무것도 묻지 않습니다.
`overwrite` 를 켜지 않으면 기존 파일은 건너뛰고, React 19 peer dependency 충돌이
있으면 npm 은 `--force` 를 씁니다.

### getRegistries

레지스트리 디렉터리를 가져옵니다.

```ts showLineNumbers
import { getRegistries } from "shadcn/registry"

const registries = await getRegistries({ useCache: true })
```

레지스트리 항목 목록을 돌려줍니다.

```json
[
  {
    "name": "@shadcn",
    "url": "https://ui.shadcn.com/r/{name}.json",
    "homepage": "https://ui.shadcn.com"
  }
]
```

### searchRegistries

하나 이상의 레지스트리를 흐린 일치로 검색합니다.

```ts showLineNumbers
import { searchRegistries } from "shadcn/registry"

const results = await searchRegistries(["@shadcn"], {
  query: "button",
  types: ["registry:component"],
  limit: 100,
  offset: 0,
  config,
  continueOnError: true, // skip (don't throw on) registries that fail to load
})
```

맞는 항목을 페이지 정보와 함께 돌려줍니다.

```json
{
  "pagination": { "total": 1, "offset": 0, "limit": 100, "hasMore": false },
  "items": [
    {
      "name": "button",
      "title": "Button",
      "type": "registry:ui",
      "description": "A button component.",
      "registry": "@shadcn",
      "addCommandArgument": "@shadcn/button"
    }
  ]
}
```

### loadRegistry

디스크에 있는 `registry.json` 을 읽고 `include` 참조까지 풀어 카탈로그를
돌려줍니다.

```ts showLineNumbers
import { loadRegistry } from "shadcn/registry"

const catalog = await loadRegistry({
  cwd: process.cwd(), // defaults to process.cwd()
  registryFile: "registry.json", // defaults to "registry.json"
})
```

돌려주는 카탈로그에는 모든 항목이 들어 있지만 **파일 내용은 빠져 있습니다.**
빌드된 `registry.json` 색인과 같습니다.

<Callout className="mt-6" title="How is this different from getRegistry?">
  [`getRegistry`](#getregistry) 는 네임스페이스·주소·GitHub 주소로 **원격**
  레지스트리를 네트워크에서 가져오며, 카탈로그가 이미 평평하게 펴져 있어야
  합니다. `include` 가 남아 있으면 거부합니다. `loadRegistry` 는 디스크의
  **로컬** `registry.json` 을 읽고 `include` 를 직접 풀어 냅니다.
</Callout>

### loadRegistryItem

로컬 `registry.json` 에서 이름으로 항목 하나를 읽고, 파일 내용을 디스크에서
읽어 함께 담아 돌려줍니다.

```ts showLineNumbers
import { loadRegistryItem } from "shadcn/registry"

const item = await loadRegistryItem("login-form", { cwd: process.cwd() })
```

파일 내용까지 모두 채워진 레지스트리 항목을 돌려줍니다.

```json
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "login-form",
  "type": "registry:component",
  "files": [
    {
      "path": "registry/new-york/login-form.tsx",
      "type": "registry:component",
      "content": "..."
    }
  ]
}
```

<Callout className="mt-6" title="How is this different from getRegistryItems?">
  [`getRegistryItems`](#getregistryitems) 는 **원격** 레지스트리에서 항목을 풀어
  옵니다. `loadRegistryItem` 은 **로컬** 소스 파일을 디스크에서 읽어 항목 하나를
  그때그때 만듭니다. `registry-item.json` 을 내보내는 동적 라우트에 쓰세요.
</Callout>

### Errors

모든 레지스트리 함수는 `RegistryError` 를 상속한 타입 있는 오류를 던집니다.
`RegistryErrorCode` enum 이나 `instanceof` 로 구분해 처리하세요.

```ts showLineNumbers
import { RegistryError, RegistryNotFoundError } from "shadcn/registry"

try {
  await getRegistry("@unknown")
} catch (error) {
  if (error instanceof RegistryNotFoundError) {
    // handle missing registry
  }
}
```

쓸 수 있는 오류 클래스입니다.

- `RegistryError`
- `RegistryNotFoundError`
- `RegistryUnauthorizedError`
- `RegistryForbiddenError`
- `RegistryFetchError`
- `RegistryNotConfiguredError`
- `RegistryLocalFileError`
- `RegistryParseError`
- `RegistryValidationError`
- `RegistryItemNotFoundError`
- `RegistriesIndexParseError`
- `RegistryMissingEnvironmentVariablesError`
- `RegistryInvalidNamespaceError`

## shadcn/schema

`registry.json`·`registry-item.json`·`components.json` 을 검증하는 Zod 스키마입니다.
직접 만든 도구에서 레지스트리 데이터를 검증할 때 씁니다.

```ts
import { registryItemSchema, registrySchema } from "shadcn/schema"

const result = registryItemSchema.safeParse(json)
if (!result.success) {
  console.error(result.error)
}
```

주요 스키마입니다.

- `registrySchema`
- `registryItemSchema`
- `registryItemFileSchema`
- `registryItemTypeSchema`
- `registryItemCssVarsSchema`
- `registryItemTailwindSchema`
- `registryBaseColorSchema`
- `configSchema`
- `presetSchema`

여기서 추론한 타입도 함께 내보냅니다.

- `Registry`
- `RegistryItem`
- `RegistryBaseItem`
- `RegistryFontItem`
- `Preset`
- `ConfigJson`

## shadcn/preset

테마 프리셋을 인코딩·디코딩·검증하고, 테마 편집기가 쓰는 프리셋 옵션 상수도
제공합니다.

### encodePreset

`Partial<PresetConfig>` 를 짧고 주소에 넣기 좋은 프리셋 코드로 바꿉니다.
빠뜨린 필드는 `DEFAULT_PRESET_CONFIG` 값을 씁니다.

```ts showLineNumbers
import { encodePreset } from "shadcn/preset"

const code = encodePreset({
  style: "vega",
  baseColor: "stone",
  theme: "blue",
  radius: "large",
  font: "geist",
})
```

버전 접두가 붙은 문자열을 돌려줍니다.

```ts showLineNumbers
"bJ4FLU0"
```

### decodePreset

프리셋 코드를 온전한 `PresetConfig` 로 되돌립니다. 코드가 없거나 잘못됐으면
`null` 을 돌려줍니다.

```ts showLineNumbers
import { decodePreset } from "shadcn/preset"

const config = decodePreset("bJ4FLU0")
```

풀어낸 설정을 돌려줍니다. 빠뜨린 필드는 기본값으로 채워집니다.

```json
{
  "style": "vega",
  "baseColor": "stone",
  "theme": "blue",
  "chartColor": "neutral",
  "iconLibrary": "lucide",
  "font": "geist",
  "fontHeading": "inherit",
  "radius": "large",
  "menuAccent": "subtle",
  "menuColor": "default"
}
```

```ts
decodePreset("not-a-code") // null
```
