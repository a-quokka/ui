레지스트리가 공개 주소로 열려 있다면 `https://v0.dev/chat/api/open?url=[URL]` 로 항목을 v0 에서 열 수 있습니다.

eg. [https://v0.dev/chat/api/open?url=https://ui.shadcn.com/r/styles/new-york/login-01.json](https://v0.dev/chat/api/open?url=https://ui.shadcn.com/r/styles/new-york/login-01.json)

<Callout className="mt-6">
  **중요:** `Open in v0` 는 `cssVars`·`css`·`envVars` 와 네임스페이스
  레지스트리, 그리고 복잡한 인증 방식을 지원하지 않습니다.
</Callout>

## Authentication

Open in v0 는 쿼리 파라미터 인증만 지원합니다. 네임스페이스 레지스트리나 헤더의 Bearer 토큰·API 키 같은 방식은 지원하지 않습니다.

### Using Query Parameter Authentication

Open in v0 를 위해 인증을 붙이려면 `token` 쿼리 파라미터를 쓰세요.

```
https://registry.company.com/r/hello-world.json?token=your_secure_token_here
```

레지스트리 서버에서는 이렇게 구현합니다.

1. `token` 쿼리 파라미터가 있는지 확인합니다
2. 인증 체계로 토큰을 검증합니다
3. 토큰이 없거나 잘못됐으면 `401 Unauthorized` 를 돌려줍니다
4. shadcn CLI 와 Open in v0 모두 401 을 알아서 처리해 사용자에게 알맞은 메시지를 보여 줍니다

### Example Implementation

```typescript
// Next.js API route example
export async function GET(request: NextRequest) {
  const token = request.nextUrl.searchParams.get("token")

  if (!isValidToken(token)) {
    return NextResponse.json(
      {
        error: "Unauthorized",
        message: "Invalid or missing token",
      },
      { status: 401 }
    )
  }

  // Return the registry item
  return NextResponse.json(registryItem)
}
```
