[shadcn MCP 서버](/docs/mcp)는 shadcn 규격을 따르는 레지스트리라면 그대로 동작합니다. MCP 를 켜려고 따로 할 일은 없습니다.

---

## Prerequisites

MCP 서버는 레지스트리 색인을 요청해 동작합니다. 레지스트리 루트에 `registry` 라는 이름의 항목 파일이 있어야 합니다.

예를 들어 레지스트리가 `https://acme.com/r/[name].json` 에 있다면 `https://acme.com/r/registry.json` 에 파일이 있어야 합니다. 확장자를 쓰지 않는다면 `https://acme.com/r/registry` 입니다.

이 파일은 [registry 스키마](/docs/registry/registry-json)를 따르는 올바른 JSON 이어야 합니다.

---

## Best Practices

MCP 와 잘 맞는 레지스트리를 만들 때 지킬 것들입니다.

1. **명확한 설명**: 그 항목이 무엇이고 어떻게 쓰는지 AI 어시스턴트가 알 수 있도록 간결하고 알찬 설명을 답니다.
2. **정확한 의존성**: MCP 가 자동으로 설치할 수 있도록 `dependencies` 를 빠짐없이 적습니다.
3. **레지스트리 의존성**: 항목 사이의 관계는 `registryDependencies` 로 나타냅니다.
4. **일관된 이름**: 컴포넌트 이름에 kebab-case 를 쓰고 레지스트리 전체에서 일관되게 유지합니다.
