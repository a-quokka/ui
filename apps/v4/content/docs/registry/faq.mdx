## Frequently asked questions

### What does a complex component look like?

페이지 하나, 컴포넌트 둘, 훅 하나, format-date 유틸, 설정 파일을 한꺼번에 설치하는 복합 컴포넌트 예시입니다.

```json showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "hello-world",
  "title": "Hello World",
  "type": "registry:block",
  "description": "A complex hello world component",
  "files": [
    {
      "path": "registry/new-york/hello-world/page.tsx",
      "type": "registry:page",
      "target": "app/hello/page.tsx"
    },
    {
      "path": "registry/new-york/hello-world/components/hello-world.tsx",
      "type": "registry:component"
    },
    {
      "path": "registry/new-york/hello-world/components/formatted-message.tsx",
      "type": "registry:component"
    },
    {
      "path": "registry/new-york/hello-world/hooks/use-hello.ts",
      "type": "registry:hook"
    },
    {
      "path": "registry/new-york/hello-world/lib/format-date.ts",
      "type": "registry:lib"
    },
    {
      "path": "registry/new-york/hello-world/hello.config.ts",
      "type": "registry:file",
      "target": "~/hello.config.ts"
    }
  ]
}
```

### How do I add a new Tailwind color?

새 색을 넣으려면 `cssVars` 의 `light` 와 `dark` 아래에 추가하세요.

```json showLineNumbers {10-18}
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "hello-world",
  "title": "Hello World",
  "type": "registry:block",
  "description": "A complex hello world component",
  "files": [
    // ...
  ],
  "cssVars": {
    "light": {
      "brand-background": "oklch(0.205 0.015 18)",
      "brand-accent": "oklch(0.205 0.015 18)"
    },
    "dark": {
      "brand-background": "oklch(0.205 0.015 18)",
      "brand-accent": "oklch(0.205 0.015 18)"
    }
  }
}
```

CLI 가 프로젝트 CSS 파일을 갱신합니다. 그러면 `bg-brand`·`text-brand-accent` 같은 유틸리티 클래스로 새 색을 쓸 수 있습니다.

### Why does `button` in `registryDependencies` not resolve to my GitHub repository?

이름만 적은 레지스트리 의존성은 기존 shadcn 동작을 따릅니다. `button` 은 내장
shadcn `button` 항목을 뜻합니다.

GitHub 저장소의 의존성이라면 전체 GitHub 항목 주소를 쓰세요.

```json title="registry-item.json" showLineNumbers
{
  "registryDependencies": ["acme/ui/button"]
}
```

### How do I pin a GitHub registry item?

GitHub 항목 주소에 `#ref` 를 붙입니다. ref 에는 브랜치·태그·전체 커밋 SHA 를
쓸 수 있습니다.

```bash
npx shadcn@latest add acme/ui/button#v1.2.0
```

배포하는 레지스트리라면 태그나 전체 커밋 SHA 를 쓰는 편이 낫습니다.

### Can GitHub registry addresses use private repositories?

지금은 안 됩니다. GitHub 레지스트리 주소는 공개 `github.com` 저장소만
지원합니다. 비공개라면 인증이 걸린 주소를 네임스페이스로 쓰세요.

### How do I add or override a Tailwind theme variable?

테마 변수를 넣거나 덮어쓰려면 `cssVars.theme` 아래 원하는 키에 추가하세요.

```json showLineNumbers {10-15}
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "hello-world",
  "title": "Hello World",
  "type": "registry:block",
  "description": "A complex hello world component",
  "files": [
    // ...
  ],
  "cssVars": {
    "theme": {
      "text-base": "3rem",
      "ease-in-out": "cubic-bezier(0.4, 0, 0.2, 1)",
      "font-heading": "Poppins, sans-serif"
    }
  }
}
```
