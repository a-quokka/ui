## Installation

`npx shadcn@latest init` 으로 프로젝트를 잡았다면 `shimmer` 는 이미 있습니다. `shadcn` 패키지에 들어 있고 CLI 가 전역 CSS 파일에서 불러옵니다.

그렇지 않다면 `shadcn` 패키지를 설치하세요.

```bash
npm install shadcn
```

그다음 전역 CSS 파일에서 공용 유틸리티를 불러옵니다.

```css
@import "tailwindcss";
@import "shadcn/tailwind.css";
```

## Usage

| Class                         | Styles                                                                                               |
| ----------------------------- | ---------------------------------------------------------------------------------------------------- |
| `shimmer`                     | `background-clip: text;` <br /> `animation: tw-shimmer var(--shimmer-duration, 2s) linear infinite;` |
| `shimmer-once`                | `animation-iteration-count: 1;`                                                                      |
| `shimmer-reverse`             | `animation-direction: reverse;`                                                                      |
| `shimmer-none`                | `--shimmer-image: none;` <br /> `--shimmer-text-fill: currentColor;`                                 |
| `shimmer-color-<color>`       | `--shimmer-color: <color>;`                                                                          |
| `shimmer-color-[<value>]`     | `--shimmer-color: <value>;`                                                                          |
| `shimmer-color-<color>/<pct>` | `--shimmer-color: color-mix(in oklch, <color> <pct>, transparent);`                                  |
| `shimmer-duration-<number>`   | `--shimmer-duration: calc(<number> * 1ms);`                                                          |
| `shimmer-spread-<number>`     | `--shimmer-spread: calc(var(--spacing) * <number>);`                                                 |
| `shimmer-spread-[<value>]`    | `--shimmer-spread: <value>;`                                                                         |
| `shimmer-angle-<number>`      | `--shimmer-angle: calc(<number> * 1deg);`                                                            |

글자 요소에 `shimmer` 를 붙입니다.

```tsx
<p className="shimmer text-muted-foreground">Generating response&hellip;</p>
```

반짝임은 `currentColor` 를 바탕으로 하므로 요소에 맞춰 따라옵니다.

- 강조 색이 글자 색에서 나오므로 따로 설정할 게 없습니다.
- `text-muted-foreground` 부터 브랜드 색까지 어떤 색에서도 동작합니다.
- 다크 모드에서는 강조가 자동으로 밝아져 계속 보입니다.

순수 CSS 로 만든 효과입니다. `background-clip: text` 로 글자를 칠하고 그 위로 강조가 이음매 없이 돌며 지나갑니다.

## With Marker

글자를 그리는 컴포넌트라면 무엇과도 조합됩니다. 어시스턴트가 일하는 동안 상태를 보여 주는 [Marker](/docs/components/marker) 가 흔한 예입니다.

<ComponentPreview styleName="base-rhea" name="shimmer-marker" />

```tsx
<Marker role="status">
  <MarkerIcon>
    <Spinner />
  </MarkerIcon>
  <MarkerContent className="shimmer">Thinking&hellip;</MarkerContent>
</Marker>
```

## Color

강조 색을 직접 정하려면 `shimmer-color-<color>` 를 씁니다. 테마 색과 불투명도 수식어, 또는 임의의 색 값을 받습니다.

<ComponentPreview styleName="base-rhea" name="shimmer-color" />

```tsx
<p className="shimmer shimmer-color-blue-500/60">Generating response&hellip;</p>
<p className="shimmer shimmer-color-[#378ADD]">Generating response&hellip;</p>
```

## Duration

한 번 지나가는 시간을 밀리초로 정하려면 `shimmer-duration-<number>` 를 씁니다. 기본값은 `2000`, 즉 `2s` 입니다.

<ComponentPreview styleName="base-rhea" name="shimmer-duration" />

```tsx
<p className="shimmer shimmer-duration-1000">Generating response&hellip;</p>
```

## Spread

강조 띠의 너비를 간격 스케일로 정하려면 `shimmer-spread-<number>` 를 씁니다. 기본값은 `calc(3ch + 40px)` 로, 고정 값에 글자 크기를 따라가는 `3ch` 를 더한 것입니다.

<ComponentPreview styleName="base-rhea" name="shimmer-spread" />

```tsx
<p className="shimmer shimmer-spread-24">Generating response&hellip;</p>
```

한 번만 쓰는 값이라면 임의 길이나 백분율을 쓰세요.

```tsx
<p className="shimmer shimmer-spread-[5rem]">Generating response&hellip;</p>
```

## Angle

강조 띠의 기울기를 도 단위로 정하려면 `shimmer-angle-<number>` 를 씁니다. 기본값은 `20` 입니다.

<ComponentPreview styleName="base-rhea" name="shimmer-angle" />

```tsx
<p className="shimmer shimmer-angle-45">Generating response&hellip;</p>
```

## Reverse

강조가 반대 방향으로 지나가게 하려면 `shimmer-reverse` 를 씁니다. RTL 배치에서는 이미 읽는 방향을 따릅니다. [RTL](#rtl) 을 보세요.

```tsx
<p className="shimmer shimmer-reverse">Generating response&hellip;</p>
```

## Play Once

반복하지 않고 한 번만 지나가게 하려면 `shimmer-once` 를 씁니다. 스트리밍이 끝났을 때 마무리 효과로 쓰기 좋습니다. `shimmer-duration-<number>` 와 함께 쓰면 지나가는 시간을 정할 수 있습니다.

<ComponentPreview styleName="base-rhea" name="shimmer-once" />

```tsx
<p className="shimmer shimmer-duration-1100 shimmer-once">
  Response generated.
</p>
```

## Disabling the Shimmer

효과를 끄고 글자를 평범하게 그리려면 `shimmer-none` 을 씁니다. 클래스 순서와 무관하게 동작하므로 보통 반응형이나 상태별로 씁니다.

<ComponentPreview styleName="base-rhea" name="shimmer-none" />

```tsx
<p className="shimmer md:shimmer-none">Generating response&hellip;</p>
```

## Fallback

반짝임은 [상대 색 문법](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_colors/Relative_colors)과 `color-mix()` 같은 최신 색 기능 위에 만들었고, 현재 브라우저에서는 모두 동작합니다. 지원하지 않는 예전 브라우저에서는 강조 그러데이션이 빠지고 글자가 투명하게 보일 수 있습니다. 예전 브라우저를 고려한다면 `supports-*` variant 로 `shimmer` 를 조건부로 붙이세요.

```tsx
<p className="supports-[color:oklch(from_white_l_c_h)]:shimmer">
  Generating response&hellip;
</p>
```

## Reduced Motion

사용자가 모션 줄이기를 선호하면 애니메이션이 자동으로 꺼지고 글자가 평범하게 그려집니다. 따로 설정할 것은 없습니다.

## RTL

Dropshot UI 에서 RTL 을 켜려면 [RTL 설정 가이드](/docs/rtl)를 확인하세요.

강조는 읽는 방향을 따라 LTR 에서는 왼쪽에서 오른쪽으로, RTL 에서는 오른쪽에서 왼쪽으로 지나갑니다. 클래스를 더 붙일 필요는 없습니다. 방향을 직접 뒤집으려면 `shimmer-reverse` 를 쓰세요.
