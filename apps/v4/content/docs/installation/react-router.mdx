## Use the CLI

<Steps>

### Create Project

`init` 명령으로 새 React Router 프로젝트를 만듭니다. 물어보는 대로 base·프리셋·모노레포 등을 정하세요.

```bash
npx shadcn@latest init -t react-router
```

**모노레포라면 `--monorepo` 플래그를 씁니다.**

```bash
npx shadcn@latest init -t react-router --monorepo
```

### Add Components

프로젝트에 `Card` 컴포넌트를 추가합니다.

```bash
npx shadcn@latest add card
```

모노레포로 만들었다면 `apps/web` 에서 명령을 돌리거나 저장소 루트에서 워크스페이스를 지정하세요.

```bash
npx shadcn@latest add card -c apps/web
```

위 명령으로 `Card` 컴포넌트가 프로젝트에 추가됩니다. 이렇게 가져다 쓰면 됩니다.

```tsx showLineNumbers title="app/routes/home.tsx"
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "~/components/ui/card"

export default function Home() {
  return (
    <Card className="max-w-sm">
      <CardHeader>
        <CardTitle>Project Overview</CardTitle>
        <CardDescription>
          Track progress and recent activity for your React Router app.
        </CardDescription>
      </CardHeader>
      <CardContent>
        Your design system is ready. Start building your next component.
      </CardContent>
    </Card>
  )
}
```

모노레포로 만들었다면 `apps/web/app/routes/home.tsx` 를 고치고 `@workspace/ui/components/card` 에서 가져오세요.

</Steps>

## Existing Project

<Steps>

### Create Project

새 React Router 프로젝트가 필요하면 먼저 만드세요. 아니라면 이 단계는 건너뜁니다.

```bash
npm create react-router@latest
```

`create-react-router` 가 Tailwind CSS 와 기본 `~/*` import 별칭을 함께 설정해 줍니다. 예전 버전이거나 직접 꾸린 React Router 앱에 붙인다면 둘 다 설정돼 있는지 먼저 확인하세요.

### Run the CLI

`shadcn` init 명령으로 프로젝트에 Dropshot UI 를 설정합니다.

```bash
npx shadcn@latest init
```

### Add Components

이제 프로젝트에 컴포넌트를 추가할 수 있습니다.

```bash
npx shadcn@latest add button
```

위 명령으로 `Button` 컴포넌트가 프로젝트에 추가됩니다. 이렇게 가져다 쓰면 됩니다.

```tsx showLineNumbers title="app/routes/home.tsx"
import { Button } from "~/components/ui/button"

export default function Home() {
  return (
    <div className="flex min-h-svh flex-col items-center justify-center">
      <Button>Click me</Button>
    </div>
  )
}
```

</Steps>
