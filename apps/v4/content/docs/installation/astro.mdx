## Use the CLI

<Steps>

### Create Project

`init` 명령으로 새 Astro 프로젝트를 만듭니다. 물어보는 대로 base·프리셋·모노레포 등을 정하세요.

```bash
npx shadcn@latest init -t astro
```

**모노레포라면 `--monorepo` 플래그를 씁니다.**

```bash
npx shadcn@latest init -t astro --monorepo
```

### Add Components

프로젝트에 `Card` 컴포넌트를 추가합니다.

```bash
npx shadcn@latest add card
```

모노레포로 만들었다면 `apps/web` 에서 명령을 돌리거나 저장소 루트에서 워크스페이스를 지정하세요.

```bash
npx shadcn@latest add card -c apps/web
```

위 명령으로 `Card` 컴포넌트가 프로젝트에 추가됩니다. 이렇게 가져다 쓰면 됩니다.

```astro title="src/pages/index.astro" showLineNumbers
---
import Layout from "@/layouts/main.astro"
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"
---

<Layout>
  <Card className="max-w-sm">
    <CardHeader>
      <CardTitle>Project Overview</CardTitle>
      <CardDescription>
        Track progress and recent activity for your Astro app.
      </CardDescription>
    </CardHeader>
    <CardContent>
      Your design system is ready. Start building your next component.
    </CardContent>
  </Card>
</Layout>
```

모노레포로 만들었다면 `apps/web/src/pages/index.astro` 를 고치고 `@workspace/ui/components/card` 에서 가져오세요. `apps/web/src/layouts/main.astro` 레이아웃이 `@workspace/ui/globals.css` 를 이미 불러옵니다.

</Steps>

## Existing Project

<Steps>

### Create Project

새 Astro 프로젝트가 필요하면 먼저 만드세요. 아니라면 이 단계는 건너뜁니다.

```bash
npm create astro@latest astro-app -- --template with-tailwindcss --install --add react --git
```

이 명령이 Tailwind CSS 와 React 연동을 함께 설정해 줍니다. 예전 버전이거나 직접 꾸린 Astro 앱에 붙인다면 둘 다 설정돼 있는지 먼저 확인하세요.

Tailwind 스타터는 `src/layouts/main.astro` 를 통해 전역 스타일시트를 불러옵니다. 그 레이아웃을 그대로 두거나, 페이지에서 `@/styles/global.css` 를 직접 불러오세요.

### Edit tsconfig.json file

프로젝트에 `@/*` 별칭이 이미 설정돼 있다면 이 단계는 건너뛰세요.

경로를 풀 수 있도록 `tsconfig.json` 에 아래를 추가합니다.

```ts title="tsconfig.json" {4-9} showLineNumbers
{
  "compilerOptions": {
    // ...
    "baseUrl": ".",
    "paths": {
      "@/*": [
        "./src/*"
      ]
    }
    // ...
  }
}
```

### Run the CLI

`shadcn` init 명령으로 프로젝트를 설정합니다.

```bash
npx shadcn@latest init
```

### Add Components

이제 프로젝트에 컴포넌트를 추가할 수 있습니다.

```bash
npx shadcn@latest add button
```

위 명령으로 `Button` 컴포넌트가 프로젝트에 추가됩니다. 이렇게 가져다 쓰면 됩니다.

```astro title="src/pages/index.astro" showLineNumbers
---
import Layout from "@/layouts/main.astro"
import { Button } from "@/components/ui/button"
---

<Layout>
  <div class="grid h-screen place-items-center content-center">
    <Button>Button</Button>
  </div>
</Layout>
```

</Steps>
