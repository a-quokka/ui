<Callout>

**참고:** 이 문서는 Remix 기준입니다. React Router 는 [React Router](/docs/installation/react-router) 문서를 보세요.

</Callout>

<Steps>

### Create project

`create-remix` 로 새 Remix 프로젝트를 만드는 것부터 시작합니다.

```bash
npx create-remix@latest my-app
```

### Run the CLI

`shadcn` init 명령으로 프로젝트를 설정합니다.

```bash
npx shadcn@latest init
```

### That's it

이제 프로젝트에 컴포넌트를 추가할 수 있습니다.

```bash
npx shadcn@latest add button
```

위 명령으로 `Button` 컴포넌트가 프로젝트에 추가됩니다. 이렇게 가져다 쓰면 됩니다.

```tsx {1,6} showLineNumbers title="app/routes/index.tsx"
import { Button } from "~/components/ui/button"

export default function Home() {
  return (
    <div>
      <Button>Click me</Button>
    </div>
  )
}
```

</Steps>
