shadcn CLI 는 Laravel 앱을 새로 만들어 주지 않습니다. React 스타터 킷으로 Laravel 앱을 먼저 만든 뒤 설정 방법을 고르세요.

<Steps>

### Create Project

Laravel 인스톨러로 새 Laravel 앱을 만듭니다.

```bash
laravel new my-app
```

React 와 Inertia 가 설정된 Laravel 앱이 이미 있다면 이 단계는 건너뛰세요.

물어보면 **React** 스타터 킷을 고르세요. 자세한 내용은 [Laravel 프런트엔드 문서](https://laravel.com/docs/12.x/frontend)를 보세요.

그다음 프로젝트 디렉터리로 이동합니다.

```bash
cd my-app
```

</Steps>

## Use the CLI

<Steps>

### Run the CLI

Laravel 앱 루트에서 `shadcn` init 명령을 돌립니다.

```bash
npx shadcn@latest init
```

`components.json` 과 컴포넌트를 덮어쓸지 물으면 `Yes` 를 고르세요.

### Add Components

프로젝트에 `Switch` 컴포넌트를 추가합니다.

```bash
npx shadcn@latest add switch
```

위 명령으로 `Switch` 컴포넌트가 `resources/js/components/ui/switch.tsx` 에 추가됩니다. 이렇게 가져다 쓰면 됩니다.

```tsx title="resources/js/pages/index.tsx" showLineNumbers {1,6}
import { Switch } from "@/components/ui/switch"

const MyPage = () => {
  return (
    <div>
      <Switch />
    </div>
  )
}

export default MyPage
```

</Steps>
