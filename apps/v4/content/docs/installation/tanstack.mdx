## Use shadcn/create

<Steps>

### Build Your Preset

shadcn/create 를 열어 프리셋을 눈으로 보며 만듭니다. 스타일·색·폰트·아이콘을 고르면 됩니다.

<Button asChild size="sm">
  <Link
    href="/create?template=start"
    target="_blank"
    rel="noopener noreferrer"
    className="mt-6 no-underline!"
  >
    shadcn/create 열기
  </Link>
</Button>

### Create Project

`Create Project` 를 누르고 패키지 매니저를 고른 뒤 만들어진 명령을 복사하세요.

만들어진 명령은 대체로 이런 모양입니다.

```bash
npx shadcn@latest init --preset [CODE] --template start
```

실제 명령에는 고른 옵션(`--base`·`--monorepo`·`--rtl` 등)이 함께 들어갑니다.

### Add Components

프로젝트에 `Card` 컴포넌트를 추가합니다.

```bash
npx shadcn@latest add card
```

모노레포로 만들었다면 `apps/web` 에서 명령을 돌리거나 저장소 루트에서 워크스페이스를 지정하세요.

```bash
npx shadcn@latest add card -c apps/web
```

위 명령으로 `Card` 컴포넌트가 프로젝트에 추가됩니다. 이렇게 가져다 쓰면 됩니다.

```tsx showLineNumbers title="src/routes/index.tsx"
import { createFileRoute } from "@tanstack/react-router"

import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"

export const Route = createFileRoute("/")({
  component: App,
})

function App() {
  return (
    <Card className="max-w-sm">
      <CardHeader>
        <CardTitle>Project Overview</CardTitle>
        <CardDescription>
          Track progress and recent activity for your TanStack Start app.
        </CardDescription>
      </CardHeader>
      <CardContent>
        Your design system is ready. Start building your next component.
      </CardContent>
    </Card>
  )
}
```

모노레포로 만들었다면 `apps/web/src/routes/index.tsx` 를 고치고 `@workspace/ui/components/card` 에서 가져오세요.

</Steps>

## Use the CLI

<Steps>

### Create Project

`init` 명령으로 새 TanStack Start 프로젝트를 만듭니다. 물어보는 대로 base·프리셋·모노레포 등을 정하세요.

```bash
npx shadcn@latest init -t start
```

**모노레포라면 `--monorepo` 플래그를 씁니다.**

```bash
npx shadcn@latest init -t start --monorepo
```

### Add Components

프로젝트에 `Card` 컴포넌트를 추가합니다.

```bash
npx shadcn@latest add card
```

모노레포로 만들었다면 `apps/web` 에서 명령을 돌리거나 저장소 루트에서 워크스페이스를 지정하세요.

```bash
npx shadcn@latest add card -c apps/web
```

위 명령으로 `Card` 컴포넌트가 프로젝트에 추가됩니다. 이렇게 가져다 쓰면 됩니다.

```tsx showLineNumbers title="src/routes/index.tsx"
import { createFileRoute } from "@tanstack/react-router"

import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,

export const Route = createFileRoute("/")({

      <CardHeader>
        <CardTitle>Project Overview</CardTitle>
        <CardDescription>
          Track progress and recent activity for your TanStack Start app.
        </CardDescription>
      </CardHeader>
      <CardContent>

      </CardContent>
    </Card>
  )
}
```

모노레포로 만들었다면 `apps/web/src/routes/index.tsx` 를 고치고 `@workspace/ui/components/card` 에서 가져오세요.

</Steps>

## Existing Project

<Steps>

### Create Project

새 TanStack Start 프로젝트가 필요하면 먼저 만드세요. 아니라면 이 단계는 건너뜁니다.

```bash
npx @tanstack/cli@latest create
```

TanStack Start 와 React 프레임워크, 그리고 권장 기본값을 고르면 Tailwind CSS 와 `@/*` import 별칭이 함께 설정됩니다.

<Callout className="mt-6">

물어볼 때 `shadcn` 애드온은 넣지 마세요. 이 문서 뒤쪽에서 `shadcn` CLI 가 설정합니다.

</Callout>

TanStack CLI 가 Tailwind CSS 와 기본 `@/*` import 별칭을 함께 설정해 줍니다. 예전 버전이거나 직접 꾸린 TanStack Start 앱에 붙인다면 둘 다 설정돼 있는지 먼저 확인하세요.

### Run the CLI

`shadcn` init 명령으로 프로젝트에 Dropshot UI 를 설정합니다.

```bash
npx shadcn@latest init
```

### Add Components

이제 프로젝트에 컴포넌트를 추가할 수 있습니다.

```bash
npx shadcn@latest add button
```

위 명령으로 `Button` 컴포넌트가 프로젝트에 추가됩니다. 이렇게 가져다 쓰면 됩니다.

```tsx showLineNumbers title="src/routes/index.tsx"
import { createFileRoute } from "@tanstack/react-router"

import { Button } from "@/components/ui/button"

export const Route = createFileRoute("/")({
  component: App,
})

function App() {
  return (
    <div className="flex min-h-svh items-center justify-center p-6">
      <Button>Click me</Button>
    </div>
  )
}
```

</Steps>
