## Use shadcn/create

<Steps>

### Build Your Preset

shadcn/create 를 열어 프리셋을 눈으로 보며 만듭니다. 스타일·색·폰트·아이콘을 고르면 됩니다.

<Button asChild size="sm">
  <Link
    href="/create?template=next"
    target="_blank"
    rel="noopener noreferrer"
    className="mt-6 no-underline!"
  >
    shadcn/create 열기
  </Link>
</Button>

### Create Project

`Create Project` 를 누르고 패키지 매니저를 고른 뒤 만들어진 명령을 복사하세요.

만들어진 명령은 대체로 이런 모양입니다.

```bash
npx shadcn@latest init --preset [CODE] --template next
```

실제 명령에는 고른 옵션(`--base`·`--monorepo`·`--rtl` 등)이 함께 들어갑니다.

### Add Components

프로젝트에 `Card` 컴포넌트를 추가합니다.

```bash
npx shadcn@latest add card
```

모노레포로 만들었다면 `apps/web` 에서 명령을 돌리거나 저장소 루트에서 워크스페이스를 지정하세요.

```bash
npx shadcn@latest add card -c apps/web
```

위 명령으로 `Card` 컴포넌트가 프로젝트에 추가됩니다. 이렇게 가져다 쓰면 됩니다.

```tsx showLineNumbers title="app/page.tsx"
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"

export default function Home() {
  return (
    <Card className="max-w-sm">
      <CardHeader>
        <CardTitle>Project Overview</CardTitle>
        <CardDescription>
          Track progress and recent activity for your Next.js app.
        </CardDescription>
      </CardHeader>
      <CardContent>
        Your design system is ready. Start building your next component.
      </CardContent>
    </Card>
  )
}
```

모노레포로 만들었다면 `apps/web/app/page.tsx` 를 고치고 `@workspace/ui/components/card` 에서 가져오세요.

</Steps>

## Use the CLI

<Steps>

### Create Project

`init` 명령으로 새 Next.js 프로젝트를 만듭니다. 물어보는 대로 base·프리셋·모노레포 등을 정하세요.

```bash
npx shadcn@latest init -t next
```

**모노레포라면 `--monorepo` 플래그를 씁니다.**

```bash
npx shadcn@latest init -t next --monorepo
```

### Add Components


## Existing Project

<Steps>

### Create Project

새 Next.js 프로젝트가 필요하면 `create-next-app` 으로 만드세요. 아니라면 이 단계는 건너뜁니다.

```bash
npx create-next-app@latest
```

권장 기본값을 고르면 Tailwind CSS, App Router, 기본 `@/*` import 별칭이 함께 설정됩니다.

`src/` 디렉터리를 쓰고 싶다면 `--src-dir` 을 주거나 물어볼 때 `Yes` 를 고르세요.

```bash
npx create-next-app@latest --src-dir
```

`--src-dir` 을 쓰면 Next.js 가 앱을 `src/app` 에 두고 `@/*` 별칭이 `./src/*` 를 가리키게 합니다.

### Configure Tailwind CSS and Import Aliases

`create-next-app` 권장 기본값으로 프로젝트를 만들었다면 이 단계는 건너뛰어도 됩니다.

예전 버전이거나 직접 꾸린 Next.js 앱에 붙인다면 Tailwind CSS 가 먼저 설치돼 있어야 합니다. [Next.js 설치 문서](https://nextjs.org/docs/app/getting-started)를 따라가면 됩니다.

그다음 `tsconfig.json` 에 `@/*` import 별칭이 있는지 확인하세요.

```json title="tsconfig.json" showLineNumbers
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./*"]
    }
  }
}
```

`--src-dir` 을 썼다면 별칭이 `./src/*` 를 가리키게 하세요.

### Run the CLI

`shadcn` init 명령으로 프로젝트에 Dropshot UI 를 설정합니다.

```bash
npx shadcn@latest init
```

### Add Components

이제 프로젝트에 컴포넌트를 추가할 수 있습니다.

```bash
npx shadcn@latest add button
```

위 명령으로 `Button` 컴포넌트가 프로젝트에 추가됩니다. 이렇게 가져다 쓰면 됩니다.

```tsx showLineNumbers title="app/page.tsx"
import { Button } from "@/components/ui/button"

export default function Home() {
  return (
    <div className="flex min-h-svh items-center justify-center">
      <Button>Click me</Button>
    </div>
  )
}
```

`--src-dir` 을 썼다면 컴포넌트를 `src/app/page.tsx` 에 넣으세요.

</Steps>
