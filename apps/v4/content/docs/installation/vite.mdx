## Use shadcn/create

<Steps>

### Build Your Preset

shadcn/create 를 열어 프리셋을 눈으로 보며 만듭니다. 스타일·색·폰트·아이콘을 고르면 됩니다.

<Button asChild size="sm">
  <Link
    href="/create?template=vite"
    target="_blank"
    rel="noopener noreferrer"
    className="mt-6 no-underline!"
  >
    shadcn/create 열기
  </Link>
</Button>

### Create Project

`Create Project` 를 누르고 패키지 매니저를 고른 뒤 만들어진 명령을 복사하세요.

만들어진 명령은 대체로 이런 모양입니다.

```bash
npx shadcn@latest init --preset [CODE] --template vite
```

실제 명령에는 고른 옵션(`--base`·`--monorepo`·`--rtl` 등)이 함께 들어갑니다.

### Add Components

프로젝트에 `Card` 컴포넌트를 추가합니다.

```bash
npx shadcn@latest add card
```

모노레포로 만들었다면 `apps/web` 에서 명령을 돌리거나 저장소 루트에서 워크스페이스를 지정하세요.

```bash
npx shadcn@latest add card -c apps/web
```

위 명령으로 `Card` 컴포넌트가 프로젝트에 추가됩니다. 이렇게 가져다 쓰면 됩니다.

```tsx showLineNumbers title="src/App.tsx"
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"

function App() {
  return (
    <Card className="max-w-sm">
      <CardHeader>
        <CardTitle>Project Overview</CardTitle>
        <CardDescription>
          Track progress and recent activity for your Vite app.
        </CardDescription>
      </CardHeader>
      <CardContent>
        Your design system is ready. Start building your next component.
      </CardContent>
    </Card>
  )
}

export default App
```

모노레포로 만들었다면 `apps/web/src/App.tsx` 를 고치고 `@workspace/ui/components/card` 에서 가져오세요.

</Steps>

## Use the CLI

<Steps>

### Create Project

`init` 명령으로 새 Vite 프로젝트를 만듭니다. 물어보는 대로 base·프리셋·모노레포 등을 정하세요.

```bash
npx shadcn@latest init -t vite
```

**모노레포라면 `--monorepo` 플래그를 씁니다.**

```bash
npx shadcn@latest init -t vite --monorepo
```

## Existing Project

<Steps>

### Create Project

새 Vite 프로젝트가 필요하면 먼저 만들고 **React + TypeScript** 템플릿을 고르세요. 아니라면 이 단계는 건너뜁니다.

```bash
npm create vite@latest
```

### Add Tailwind CSS

프로젝트에 Tailwind CSS 가 이미 설정돼 있다면 이 단계는 건너뛰세요.

```bash
npm install tailwindcss @tailwindcss/vite
```

`src/index.css` 의 내용을 아래로 전부 바꿉니다.

```css title="src/index.css"
@import "tailwindcss";
```

### Edit tsconfig.json file

프로젝트에 `@/*` 별칭이 이미 설정돼 있다면 이 단계는 건너뛰세요.

Vite 는 TypeScript 설정을 여러 파일로 나눕니다. `tsconfig.json` 과 `tsconfig.app.json` 의 `compilerOptions` 에 `baseUrl` 과 `paths` 를 추가하세요.

```ts title="tsconfig.json" {11-16} showLineNumbers
{
  "files": [],
  "references": [
    {
      "path": "./tsconfig.app.json"
    },
    {
      "path": "./tsconfig.node.json"
    }
  ],
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

### Edit tsconfig.app.json file

편집기가 import 를 풀 수 있도록 `tsconfig.app.json` 에도 같은 별칭을 추가합니다.

```ts title="tsconfig.app.json" {4-9} showLineNumbers
{
  "compilerOptions": {
    // ...
    "baseUrl": ".",
    "paths": {
      "@/*": [
        "./src/*"
      ]
    }
    // ...
  }
}
```

### Update vite.config.ts

Vite 가 `@` 별칭을 풀 수 있도록 `@types/node` 를 설치하고 `vite.config.ts` 를 고칩니다.

```bash
npm install -D @types/node
```

```typescript title="vite.config.ts" showLineNumbers {1,2,8-13}
import path from "path"
import tailwindcss from "@tailwindcss/vite"
import react from "@vitejs/plugin-react"
import { defineConfig } from "vite"

// https://vite.dev/config/
export default defineConfig({
  plugins: [react(), tailwindcss()],
  resolve: {
    alias: {
      "@": path.resolve(__dirname, "./src"),
    },
  },
})
```

### Run the CLI

`shadcn` init 명령으로 프로젝트에 shadcn/ui 를 설정합니다.

```bash
npx shadcn@latest init
```

### Add Components

이제 프로젝트에 컴포넌트를 추가할 수 있습니다.

```bash
npx shadcn@latest add button
```

위 명령으로 `Button` 컴포넌트가 프로젝트에 추가됩니다. 이렇게 가져다 쓰면 됩니다.

```tsx showLineNumbers title="src/App.tsx"
import { Button } from "@/components/ui/button"

function App() {
  return (
    <div className="flex min-h-svh flex-col items-center justify-center">
      <Button>Click me</Button>
    </div>
  )
}

export default App
```

</Steps>
