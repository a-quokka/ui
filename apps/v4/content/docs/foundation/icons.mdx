아이콘 원본은 aiStudio CDN 에 있습니다.

```
https://cdn.aistudio.dropshot.io/public/icons/ic_<이름>.svg
```

제품 코드에서는 `getIconAttributes` 가 이름 앞에 `ic_` 를 붙여 주소를 만듭니다.
그래서 코드에 적는 이름에는 접두사가 없습니다.

```tsx
import { getIconAttributes } from "@stock/web/utils/icon"

<Image {...getIconAttributes({ iconName: "twinkle_filled", size: 24 })} />
```

<Callout>
  이 문서의 아이콘은 CDN 을 부르지 않고 저장소 안에 인라인해 두었습니다. 제품은
  CSS `filter` 로 색을 입히지만 인라인 SVG 에서는 그 방식이 맞지 않아 `fill` 과
  `stroke` 를 `currentColor` 로 바꿨습니다. 부모의 `color` 가 그대로 아이콘 색이
  됩니다.
</Callout>

## Grid

아이콘은 **viewBox 24×24 의 단색 fill 패스**입니다. stroke 로 그린 것이 아니므로
굵기를 바꿀 수는 없고, 표시 크기만 `width`·`height` 로 정합니다.

이름을 누르면 복사됩니다.

## 없는 아이콘

CDN 에 없는 이름을 부르면 S3 가 404 가 아니라 **403** 을 돌려줍니다. 권한 문제가
아니라 그 이름이 없다는 뜻으로 읽으면 됩니다.

레포가 참조하는데도 CDN 에 없는 것이 있습니다. 확인한 것은 `bytedance`,
`dropshot_stock`, `facebook`, `flux-kontext-pro`, `kling`, `openai`, `twitter`,
`video_add` 여덟 개입니다. 대부분 외부 서비스 로고라 저작권 때문에 CDN 에
올리지 않은 것으로 보입니다.

없는 아이콘이 필요하면 24×24 viewBox 에 fill 패스로 직접 그립니다. stroke 로
그리면 제품 아이콘 옆에서 결이 눈에 띄게 다릅니다. 이모지나 딩벳으로 대체하지
않습니다.

## 배너·워드마크

`doubleweek_wordmark_desktop`, `seoria_logo`, `studio_logo-v2`, `superweek_banner_bg`
같은 것들은 아이콘 이름을 달고 있지만 캠페인 그래픽이나 로고입니다. viewBox 가
제각각이고 아이콘 체계에 속하지 않으므로 이 문서에서는 다루지 않습니다.
