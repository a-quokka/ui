본문 폰트는 Dropshot Sans 입니다. `cdn.dropshot.io` 에서 400·500·700 세 웨이트를
`@font-face` 로 받습니다.

| 웨이트 | 파일                          | 크기     |
| ------ | ----------------------------- | -------- |
| 400    | `Dropshot_Sans-Regular.woff2` | 약 224KB |
| 500    | `Dropshot_Sans-Medium.woff2`  | 약 244KB |
| 700    | `Dropshot_Sans-Bold.woff2`    | 약 250KB |

한글은 상용 2,350자(KS X 1001)를 담고 있어 이 문서의 본문은 전부 커버됩니다.
그 밖의 글자는 `Apple SD Gothic Neo` → `Malgun Gothic` → 시스템 폰트 순으로
떨어집니다.

<Callout>
  세 파일 합계가 약 735KB 입니다. 서브셋은 아직 만들지 않았습니다.
</Callout>

## 변수로 대체되지 않는 이유

램프 한 클래스가 크기·행간·굵기·자간 **네 값을 한꺼번에** 정합니다. shadcn 은 이
네 가지를 `text-sm`, `leading-none`, `font-medium`, `tracking-widest` 처럼 따로
조합하기 때문에, CSS 변수 교체만으로는 램프에 맞출 수 없습니다. 그래서 램프를
`@utility` 로 옮겨 두었습니다.

| shadcn 조합                | Dropshot 램프    | 값            |
| -------------------------- | ---------------- | ------------- |
| `text-sm`                  | `font-body3`     | 14 / 24 / 400 |
| `text-sm font-medium`      | `font-subtitle4` | 14 / 22 / 500 |
| `text-xs`                  | `font-caption1`  | 12 / 20 / 400 |
| `text-xs font-medium`      | `font-button4`   | 12 / 20 / 500 |
| `text-base font-medium`    | `font-subtitle3` | 16 / 24 / 500 |
| 버튼 `text-sm font-medium` | `font-button3`   | 14 / 22 / 500 |
| 사이드바 활성 항목         | `font-subtitle1` | 16 / 24 / 700 |

<Callout>
  **램프는 아직 컴포넌트에 적용하지 않았습니다.** 유틸리티로 쓸 수 있게만 해
  두었습니다. 컴포넌트 41곳의 클래스를 갈아 끼우는 작업이라 별도 결정이
  필요합니다.
