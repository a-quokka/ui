Dropshot 은 다크 전용 시스템입니다. 면을 밝기로 네 단계 나누고, 그 위에 보라 강조
하나를 얹는 것이 전부입니다. 아래 값은 `apps/v4/app/globals.css` 의 `.dark` 블록에
그대로 들어 있습니다.

## 면 위계

면은 뒤에서 앞으로 갈수록 밝아집니다. 페이지가 가장 어둡고, 그 위에 카드,
그 위에 드롭다운이 놓입니다.

글자는 두 단계만 씁니다. 본문은 `grayscale-200`, 라벨은 `grayscale-500` 입니다.

| 변수                     | 값        | Dropshot      | 쓰이는 곳        |
| ------------------------ | --------- | ------------- | ---------------- |
| `--foreground`           | `#E5E8ED` | grayscale-200 | 본문             |
| `--muted-foreground`     | `#8E97A4` | grayscale-500 | 라벨·보조 문구   |
| `--accent-foreground`    | `#F0F3F6` | grayscale-100 | hover 면 위 글자 |
| `--secondary-foreground` | `#FFFFFF` | white         | 보조 버튼 글자   |

## Light mode

<Callout>
  **라이트 팔레트는 Dropshot 에 없습니다.** 같은 grayscale 램프를 뒤집어 파생한
  값이고, `primary` 와 차트만 원본을 씁니다. 확정값이 아닙니다. 문서 사이트는
  다크를 기본값으로 열립니다.
</Callout>

| 변수                   | 라이트    | 근거                           |
| ---------------------- | --------- | ------------------------------ |
| `--background`         | `#FFFFFF` | 흰 면                          |
| `--foreground`         | `#15191E` | grayscale-900 을 글자로 뒤집음 |
| `--muted`              | `#F4F7F9` | grayscale-75                   |
| `--muted-foreground`   | `#5E656F` | grayscale-600                  |
| `--border` · `--input` | `#E5E8ED` | grayscale-200                  |
| `--destructive`        | `#DF1B36` | 밝은 면 대비를 위해 red-500    |

## Radius

Dropshot 의 `rounded-N` 은 **N × 4px** 입니다. Tailwind 기본 스케일과 값이 다르므로
배수 계산을 걷어내고 실제 사용 값을 직접 지정했습니다.

| Tailwind                      | 값     | Dropshot 이름 | 쓰이는 곳          |
| ----------------------------- | ------ | ------------- | ------------------ |
| `--radius-sm`                 | `4px`  | `rounded-1`   | 프로그레스         |
| `--radius-md` · `--radius-lg` | `8px`  | `rounded-2`   | 카드·모달·드롭다운 |
| `--radius-xl`                 | `12px` | `rounded-3`   | 구독권·크레딧 카드 |
| `--radius-2xl`                | `16px` | `rounded-4`   | 배지               |
| `--radius-3xl`                | `20px` | `rounded-5`   |                    |
| `--radius-4xl`                | `24px` | `rounded-6`   |                    |

원본 이름인 `rounded-1` 부터 `rounded-6` 까지도 유틸리티로 함께 쓸 수 있습니다.

<Callout>
  텍스트 버튼의 완전 pill(`69px`)은 변수로 표현되지 않습니다. 버튼 소스를 고쳐야
  하는 자리라 아직 적용하지 않았습니다.
</Callout>
