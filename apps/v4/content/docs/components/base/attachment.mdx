`Attachment`는 파일이나 이미지 첨부와 그 미디어·이름·메타데이터를 보여 주고, 동작 버튼과 업로드 상태를 함께 둘 수 있습니다. 채팅 입력창, 메시지 스레드, 업로드 목록의 파일과 이미지에 씁니다.

## Usage

```tsx
import {
  Attachment,
  AttachmentAction,
  AttachmentActions,
  AttachmentContent,
  AttachmentDescription,
  AttachmentMedia,
  AttachmentTitle,
} from "@/components/ui/attachment"
```

```tsx
<Attachment>
  <AttachmentMedia>
    <FileTextIcon />
  </AttachmentMedia>
  <AttachmentContent>
    <AttachmentTitle>sales-dashboard.pdf</AttachmentTitle>
    <AttachmentDescription>PDF · 2.4 MB</AttachmentDescription>
  </AttachmentContent>
  <AttachmentActions>
    <AttachmentAction aria-label="Remove sales-dashboard.pdf">
      <XIcon />
    </AttachmentAction>
  </AttachmentActions>
</Attachment>
```

## Composition

아래 구조로 첨부를 만듭니다.

```text
Attachment
├── AttachmentMedia
├── AttachmentContent
│   ├── AttachmentTitle
│   └── AttachmentDescription
├── AttachmentActions
│   └── AttachmentAction
└── AttachmentTrigger
```

여러 첨부를 가로로 스크롤되는 줄에 놓으려면 `AttachmentGroup`을 씁니다.

```text
AttachmentGroup
├── Attachment
└── Attachment
```

## Features

- `AttachmentMedia`로 아이콘과 이미지 미디어 표시
- 업로드 상태 `idle`·`uploading`·`processing`·`error`·`done`. 스타일이 함께 들어 있고 진행 중에는 반짝임 효과가 붙습니다
- 세 가지 크기와 가로·세로 배치
- 카드 전체를 덮는 `AttachmentTrigger`. 링크나 다이얼로그를 열면서도 동작 버튼은 따로 눌립니다
- 가장자리가 흐려지는 스크롤·스냅 `AttachmentGroup`
- 모든 파트에서 `className` prop으로 스타일을 바꿀 수 있습니다

## Accessibility

`AttachmentAction`은 `Button`을, `AttachmentTrigger`는 진짜 `<button>`(또는 `render`로 넘긴 요소)을 그립니다. 둘 다 조작할 수 있고 읽히도록 아래 내용을 따르세요.

### Label icon-only actions

`AttachmentAction`은 보통 아이콘만 있으므로, 무엇을 어디에 하는 동작인지 설명하는 `aria-label`을 각각 주세요.

```tsx showLineNumbers
<AttachmentAction aria-label="Remove sales-dashboard.pdf">
  <XIcon />
</AttachmentAction>
```

### Label the trigger

`AttachmentTrigger`는 자기 텍스트 없이 카드를 덮으므로, 누르면 무슨 일이 일어나는지 `aria-label`로 알려 주세요.

```tsx showLineNumbers
<AttachmentTrigger
  render={
    <a
      href={url}
      target="_blank"
      rel="noreferrer"
      aria-label="Open workspace.png"
    />
  }
/>
```

트리거는 쌓임 순서상 동작 버튼 뒤에 있어서 `AttachmentAction`과 `AttachmentTrigger`가 서로를 가리지 않습니다. 둘 다 따로 포커스되고 눌립니다.

### Keyboard scrolling

`AttachmentGroup`은 가로로 스크롤됩니다. 첨부에 트리거나 동작 버튼이 있다면 키보드 사용자는 탭으로 화면 밖 항목까지 갈 수 있습니다. 누를 수 없는 첨부만 늘어놓은 줄이라면 그룹 자체에 `tabIndex={0}`·`role="group"`·`aria-label`을 붙여 포커스와 스크롤이 되게 하세요.

### Meaning beyond color

`error` 상태는 경고 색을 씁니다. 색만으로 상태가 전달되지 않도록 실패 이유를 `AttachmentDescription`에 적어 두세요.

## API Reference

### Attachment

첨부의 루트 컨테이너입니다.

| Prop          | Type                                                         | Default        | Description                                      |
| ------------- | ------------------------------------------------------------ | -------------- | ------------------------------------------------ |
| `state`       | `"idle" \| "uploading" \| "processing" \| "error" \| "done"` | `"done"`       | 업로드 상태입니다. 스타일과 반짝임을 결정합니다. |
| `size`        | `"default" \| "sm" \| "xs"`                                  | `"default"`    | 첨부 크기입니다.                                 |
| `orientation` | `"horizontal" \| "vertical"`                                 | `"horizontal"` | 미디어를 내용 옆에 둘지 위에 둘지 정합니다.      |
| `className`   | `string`                                                     | -              | 루트 요소에 덧붙일 클래스입니다.                 |

### AttachmentMedia

아이콘이나 이미지 미리보기가 들어가는 미디어 자리입니다.

| Prop        | Type                | Default  | Description                                                 |
| ----------- | ------------------- | -------- | ----------------------------------------------------------- |
| `variant`   | `"icon" \| "image"` | `"icon"` | 미디어에 아이콘이 들어가는지 `<img>`가 들어가는지 정합니다. |
| `className` | `string`            | -        | 미디어 자리에 덧붙일 클래스입니다.                          |

### AttachmentContent

제목과 설명을 감쌉니다.

| Prop        | Type     | Default | Description                      |
| ----------- | -------- | ------- | -------------------------------- |
| `className` | `string` | -       | 내용 자리에 덧붙일 클래스입니다. |

### AttachmentTitle

첨부 이름입니다. `uploading`이나 `processing` 중에는 반짝입니다.

| Prop        | Type     | Default | Description                 |
| ----------- | -------- | ------- | --------------------------- |
| `className` | `string` | -       | 제목에 덧붙일 클래스입니다. |

### AttachmentDescription

파일 형식·크기·업로드 상태 같은 부가 정보입니다.

| Prop        | Type     | Default | Description                 |
| ----------- | -------- | ------- | --------------------------- |
| `className` | `string` | -       | 설명에 덧붙일 클래스입니다. |

### AttachmentActions

동작 버튼을 담는 컨테이너입니다. 첨부의 끝 쪽에 붙습니다.

| Prop        | Type     | Default | Description                      |
| ----------- | -------- | ------- | -------------------------------- |
| `className` | `string` | -       | 동작 영역에 덧붙일 클래스입니다. |

### AttachmentAction

동작 버튼입니다. [`Button`](/docs/components/button)을 그리고 그 prop을 모두 받습니다.

| Prop       | Type                                  | Default     | Description                             |
| ---------- | ------------------------------------- | ----------- | --------------------------------------- |
| `size`     | `Button["size"]`                      | `"icon-xs"` | 버튼 크기입니다.                        |
| `...props` | `React.ComponentProps<typeof Button>` | -           | 내부 `Button`으로 전달되는 prop 입니다. |

### AttachmentTrigger

첨부를 실행하는 카드 전체 오버레이입니다. 기본값은 `<button>` 입니다.

| Prop       | Type                             | Default | Description                         |
| ---------- | -------------------------------- | ------- | ----------------------------------- |
| `render`   | `ReactElement \| function`       | -       | 링크처럼 다른 요소로 그립니다.      |
| `...props` | `React.ComponentProps<"button">` | -       | 트리거 요소로 전달되는 prop 입니다. |

### AttachmentGroup

첨부를 가로로 스크롤·스냅되는 줄에 배치합니다.

| Prop        | Type     | Default | Description                 |
| ----------- | -------- | ------- | --------------------------- |
| `className` | `string` | -       | 그룹에 덧붙일 클래스입니다. |
