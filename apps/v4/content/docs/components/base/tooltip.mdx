## Usage

```tsx showLineNumbers
import {
  Tooltip,
  TooltipContent,
  TooltipTrigger,
} from "@/components/ui/tooltip"
```

```tsx showLineNumbers
<Tooltip>
  <TooltipTrigger>Hover</TooltipTrigger>
  <TooltipContent>
    <p>라이브러리에 추가</p>
  </TooltipContent>
</Tooltip>
```

## Composition

아래 구조로 `Tooltip`을 만듭니다.

```text
Tooltip
├── TooltipTrigger
└── TooltipContent
```
