## Usage

```tsx showLineNumbers
import {
  InputGroup,
  InputGroupAddon,
  InputGroupButton,
  InputGroupInput,
  InputGroupText,
  InputGroupTextarea,
} from "@/components/ui/input-group"
```

```tsx showLineNumbers
<InputGroup>
  <InputGroupInput placeholder="검색..." />
  <InputGroupAddon>
    <SearchIcon />
  </InputGroupAddon>
</InputGroup>
```

## Composition

아래 구조로 `InputGroup`을 만듭니다.

```text
InputGroup
├── InputGroupInput or InputGroupTextarea
├── InputGroupAddon
├── InputGroupButton
└── InputGroupText
```

## API Reference

### InputGroup

입력과 애드온을 감싸는 기본 컴포넌트입니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<InputGroup>
  <InputGroupInput />
  <InputGroupAddon />
</InputGroup>
```

### InputGroupAddon

입력 옆에 아이콘·글자·버튼 같은 내용을 보여 줍니다.

<Callout icon={<IconInfoCircle />} title="Focus Navigation">
  포커스가 제대로 이동하려면 `InputGroupAddon`은 입력 뒤에 와야 합니다. 보이는
  위치는 `align` prop으로 정하세요.
</Callout>

| Prop        | Type                                                             | Default          |
| ----------- | ---------------------------------------------------------------- | ---------------- |
| `align`     | `"inline-start" \| "inline-end" \| "block-start" \| "block-end"` | `"inline-start"` |
| `className` | `string`                                                         |                  |

```tsx
<InputGroupAddon align="inline-end">
  <SearchIcon />
</InputGroupAddon>
```

**`<InputGroupInput />` 에는 `inline-start`나 `inline-end`, `<InputGroupTextarea />` 에는 `block-start`나 `block-end`를 쓰세요.**

`InputGroupAddon` 안에는 `InputGroupButton`과 아이콘을 여러 개 둘 수 있습니다.

```tsx
<InputGroupAddon>
  <InputGroupButton>Button</InputGroupButton>
  <InputGroupButton>Button</InputGroupButton>
</InputGroupAddon>
```

### InputGroupButton

입력 그룹 안에 버튼을 보여 줍니다.

| Prop        | Type                                                                          | Default   |
| ----------- | ----------------------------------------------------------------------------- | --------- |
| `size`      | `"xs" \| "icon-xs" \| "sm" \| "icon-sm"`                                      | `"xs"`    |
| `variant`   | `"default" \| "destructive" \| "outline" \| "secondary" \| "ghost" \| "link"` | `"ghost"` |
| `className` | `string`                                                                      |           |

```tsx
<InputGroupButton>Button</InputGroupButton>
<InputGroupButton size="icon-xs" aria-label="Copy">
  <CopyIcon />
</InputGroupButton>
```

### InputGroupInput

입력 그룹을 만들 때 `<Input />` 대신 쓰는 컴포넌트입니다. 입력 그룹 스타일이 미리 적용돼 있고, 포커스 상태 처리를 위해 공통 `data-slot="input-group-control"`을 씁니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

나머지 prop은 내부 `<Input />`으로 그대로 전달됩니다.

```tsx
<InputGroup>
  <InputGroupInput placeholder="내용을 입력하세요..." />
  <InputGroupAddon>
    <SearchIcon />
  </InputGroupAddon>
</InputGroup>
```

### InputGroupTextarea

입력 그룹을 만들 때 `<Textarea />` 대신 쓰는 컴포넌트입니다. textarea 그룹 스타일이 미리 적용돼 있고, 포커스 상태 처리를 위해 공통 `data-slot="input-group-control"`을 씁니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

나머지 prop은 내부 `<Textarea />`로 그대로 전달됩니다.

```tsx
<InputGroup>
  <InputGroupTextarea placeholder="메시지를 입력하세요..." />
  <InputGroupAddon align="block-end">
    <InputGroupButton>Send</InputGroupButton>
  </InputGroupAddon>
</InputGroup>
```
