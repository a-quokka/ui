## Checked State

제어하지 않는 체크박스에는 `defaultChecked`를, 상태를 제어하려면 `checked`와 `onCheckedChange`를 씁니다.

```tsx showLineNumbers
import * as React from "react"

export function Example() {
  const [checked, setChecked] = React.useState(false)

  return <Checkbox checked={checked} onCheckedChange={setChecked} />
}
```

## Invalid State

오류 스타일을 보이려면 체크박스에 `aria-invalid`를, 감싸는 field에 `data-invalid`를 지정합니다.
