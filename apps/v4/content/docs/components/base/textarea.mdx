## Disabled

`disabled` prop으로 textarea를 비활성화합니다. 비활성 상태를 꾸미려면 `Field` 컴포넌트에 `data-disabled` 속성을 붙이세요.

<ComponentPreview
  styleName="base-nova"
  name="textarea-disabled"
  previewClassName="*:max-w-xs"
/>

## Invalid

`aria-invalid` prop으로 textarea를 오류 상태로 표시합니다. 오류 상태를 꾸미려면 `Field` 컴포넌트에 `data-invalid` 속성을 붙이세요.

<ComponentPreview
  styleName="base-nova"
  name="textarea-invalid"
  previewClassName="*:max-w-xs"
/>
