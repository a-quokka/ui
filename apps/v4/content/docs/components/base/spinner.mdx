## Customization

`Spinner` 컴포넌트를 고쳐 기본 아이콘을 다른 아이콘으로 바꿀 수 있습니다.

<ComponentPreview styleName="base-nova" name="spinner-custom" />

```tsx showLineNumbers title="components/ui/spinner.tsx"
import { LoaderIcon } from "lucide-react"

import { cn } from "@/lib/utils"

function Spinner({ className, ...props }: React.ComponentProps<"svg">) {
  return (
    <LoaderIcon
      role="status"
      aria-label="Loading"
      className={cn("size-4 animate-spin", className)}
      {...props}
    />
  )
}

export { Spinner }
```

## Button

버튼에 스피너를 넣어 로딩 상태를 알립니다. 앞쪽에 두려면 `data-icon="inline-start"`를 붙여 라벨 앞에, 뒤쪽에 두려면 `data-icon="inline-end"`를 붙여 라벨 뒤에 `<Spinner />`를 놓습니다.
