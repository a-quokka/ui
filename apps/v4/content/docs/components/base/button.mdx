## Cursor

Tailwind v4부터 버튼의 기본값이 `cursor: pointer`에서 `cursor: default`로 [바뀌었습니다](https://tailwindcss.com/docs/upgrade-guide#buttons-use-the-default-cursor).

`cursor: pointer`를 그대로 쓰고 싶다면 CSS 파일에 아래를 추가하세요.

프로젝트를 만들 때 `npx shadcn@latest init --pointer`로 켤 수도 있습니다.

```css showLineNumbers title="globals.css"
@layer base {
  button:not(:disabled),
  [role="button"]:not(:disabled) {
    cursor: pointer;
  }
}
```

## As Link

`buttonVariants` 헬퍼로 링크를 버튼처럼 보이게 만들 수 있습니다.

**링크에 `<Button render={<a />} nativeButton={false} />`를 쓰지 마세요.** Base UI의 `Button`은 항상 `role="button"`을 붙이기 때문에 `<a>`의 링크 역할이 덮어씌워집니다. 대신 평범한 `<a>` 태그에 `buttonVariants`를 쓰세요.

## API Reference

### Button

`Button`은 `button` 요소를 감싸 여러 스타일과 기능을 더한 컴포넌트입니다.

| Prop      | Type                                                                                 | Default     |
| --------- | ------------------------------------------------------------------------------------ | ----------- |
| `variant` | `"default" \| "outline" \| "ghost" \| "destructive" \| "secondary" \| "link"`        | `"default"` |
| `size`    | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"default"` |
