`Message`는 대화 속 메시지 한 줄을 배치합니다. 메시지 표면 주변의 아바타·정렬·헤더·푸터를 맡습니다.

AI 앱이라면 추론 과정, 도구 호출, 어시스턴트 메시지를 `Message`로 그릴 수 있습니다.

## Usage

```tsx showLineNumbers
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar"
import { Bubble, BubbleContent } from "@/components/ui/bubble"
import { Message, MessageAvatar, MessageContent } from "@/components/ui/message"
```

```tsx showLineNumbers
<Message>
  <MessageAvatar>
    <Avatar>
      <AvatarImage src="https://github.com/shadcn.png" alt="@shadcn" />
      <AvatarFallback>CN</AvatarFallback>
    </Avatar>
  </MessageAvatar>
  <MessageContent>
    <Bubble>
      <BubbleContent>무엇을 도와드릴까요?</BubbleContent>
    </Bubble>
  </MessageContent>
</Message>
```

**참고:** `Message`는 아바타·정렬·헤더·푸터 같은 줄 배치를 맡습니다. 눈에 보이는 메시지 표면은 그 안에 [`Bubble`](/docs/components/bubble)로 그리세요. 대화를 감싸는 스크롤 컨테이너는 [`MessageScroller`](/docs/components/message-scroller)를 씁니다.

## Composition

아래 구조로 메시지를 만듭니다.

```text
Message
├── MessageAvatar
└── MessageContent
    ├── MessageHeader
    ├── Bubble
    └── MessageFooter
```

같은 사람이 연달아 보낸 메시지는 `MessageGroup`으로 쌓습니다.

```text
MessageGroup
├── Message
└── Message
```

## Features

- `align` prop으로 보내는 쪽과 받는 쪽 줄을 start·end로 정렬
- 메시지 아래쪽에 붙되 푸터를 피해 가는 아바타 자리
- 보낸 사람 이름·상태·메시지 동작을 위한 헤더와 푸터 자리
- 푸터는 메시지 쪽을 따라가고, `align="end"` 줄에서도 동작 버튼 정렬이 유지됩니다
- 같은 사람이 연달아 보낸 메시지를 쌓는 그룹 래퍼
- 모든 파트에서 `className` prop으로 스타일을 바꿀 수 있습니다

## Avatar

`MessageAvatar`로 메시지 옆에 아바타를 그립니다. 메시지에 `align="end"`를 주면 아바타도 끝 쪽에 붙습니다.

## Accessibility

`Message`는 배치만 담당하는 래퍼입니다. 접근성은 그 안에 넣는 내용에서 나옵니다.

### Label icon-only actions

`MessageFooter`의 동작 버튼은 보통 아이콘만 있으므로 각각 `aria-label`을 주세요.

```tsx showLineNumbers
<MessageFooter>
  <Button variant="ghost" size="icon" aria-label="Copy">
    <CopyIcon />
  </Button>
</MessageFooter>
```

### Status updates

진행 중인 메시지에는 `role="status"`를 준 [`Marker`](/docs/components/marker)를 써서 보조 기술이 상태 변화를 바로 읽어 주게 하세요.

```tsx showLineNumbers
<Message>
  <Marker role="status">
    <MarkerIcon>
      <Spinner />
    </MarkerIcon>
    <MarkerContent>로그를 확인하는 중...</MarkerContent>
  </Marker>
</Message>
```

## API Reference

### Message

메시지 줄을 감싸는 래퍼입니다.

| Prop        | Type               | Default   | Description                   |
| ----------- | ------------------ | --------- | ----------------------------- |
| `align`     | `"start" \| "end"` | `"start"` | 대화에서 메시지의 정렬입니다. |
| `className` | `string`           | -         | 줄에 덧붙일 클래스입니다.     |

### MessageGroup

같은 사람이 연달아 보낸 메시지를 묶습니다.

| Prop        | Type     | Default | Description                      |
| ----------- | -------- | ------- | -------------------------------- |
| `className` | `string` | -       | 그룹 루트에 덧붙일 클래스입니다. |

### MessageAvatar

메시지 아래쪽에 맞춰 붙는 아바타 자리입니다. 메시지에 `MessageFooter`가 있으면 아바타가 위로 올라가 푸터가 아니라 메시지 표면에 맞춰집니다.

| Prop        | Type     | Default | Description                        |
| ----------- | -------- | ------- | ---------------------------------- |
| `className` | `string` | -       | 아바타 자리에 덧붙일 클래스입니다. |

### MessageContent

헤더·메시지 표면·푸터를 감쌉니다.

| Prop        | Type     | Default | Description                      |
| ----------- | -------- | ------- | -------------------------------- |
| `className` | `string` | -       | 내용 자리에 덧붙일 클래스입니다. |

### MessageHeader

보낸 사람 이름처럼 메시지 위에 놓이는 내용입니다. `align`과 상관없이 항상 시작 쪽에 붙습니다.

| Prop        | Type     | Default | Description                 |
| ----------- | -------- | ------- | --------------------------- |
| `className` | `string` | -       | 헤더에 덧붙일 클래스입니다. |

### MessageFooter

상태나 동작처럼 메시지 아래에 놓이는 내용입니다. 메시지 쪽을 따라 정렬됩니다.

| Prop        | Type     | Default | Description                 |
| ----------- | -------- | ------- | --------------------------- |
| `className` | `string` | -       | 푸터에 덧붙일 클래스입니다. |
