## Usage

```tsx showLineNumbers
import {
  Field,
  FieldContent,
  FieldDescription,
  FieldError,
  FieldGroup,
  FieldLabel,
  FieldLegend,
  FieldSeparator,
  FieldSet,
  FieldTitle,
} from "@/components/ui/field"
```

```tsx showLineNumbers
<FieldSet>
  <FieldLegend>Profile</FieldLegend>
  <FieldDescription>청구서와 이메일에 표시됩니다.</FieldDescription>
  <FieldGroup>
    <Field>
      <FieldLabel htmlFor="name">이름</FieldLabel>
      <Input id="name" autoComplete="off" placeholder="Evil Rabbit" />
      <FieldDescription>청구서와 이메일에 표시됩니다.</FieldDescription>
    </Field>
    <Field>
      <FieldLabel htmlFor="username">Username</FieldLabel>
      <Input id="username" autoComplete="off" aria-invalid />
      <FieldError>다른 사용자 이름을 골라 주세요.</FieldError>
    </Field>
    <Field orientation="horizontal">
      <Switch id="newsletter" />
      <FieldLabel htmlFor="newsletter">뉴스레터 구독</FieldLabel>
    </Field>
  </FieldGroup>
</FieldSet>
```

## Composition

### Field

라벨·도움말·검증이 붙는 입력 한 칸입니다.

```text
Field
├── FieldLabel
├── Input / Textarea / Switch / Select
├── FieldDescription
└── FieldError
```

### FieldGroup

관련된 입력을 한 그룹으로 묶습니다. 구획을 나눌 때는 사이에 `FieldSeparator`를 넣습니다.

```text
FieldGroup
├── Field
│   ├── FieldLabel
│   ├── Input / Textarea / Switch / Select
│   ├── FieldDescription
│   └── FieldError
├── FieldSeparator
└── Field
    ├── FieldLabel
    └── Input / Textarea / Switch / Select
```

### FieldSet

legend와 설명으로 의미상 묶는 단위입니다. 보통 안에 `FieldGroup`이 들어갑니다.

```text
FieldSet
├── FieldLegend
├── FieldDescription
└── FieldGroup
    ├── Field
    │   ├── FieldLabel
    │   ├── Input / Textarea / Switch / Select
    │   ├── FieldDescription
    │   └── FieldError
    └── Field
        ├── FieldLabel
        └── Input / Textarea / Switch / Select
```

## Anatomy

`Field` 계열은 접근성 있는 폼을 조합하기 위한 것입니다. 보통 이런 구조를 씁니다.

```tsx showLineNumbers
<Field>
  <FieldLabel htmlFor="input-id">Label</FieldLabel>
  {/* Input, Select, Switch, etc. */}
  <FieldDescription>선택 도움말입니다.</FieldDescription>
  <FieldError>검증 메시지입니다.</FieldError>
</Field>
```

- `Field`는 입력 한 칸을 감싸는 기본 래퍼입니다.
- `FieldContent`는 라벨과 설명을 묶는 flex 세로 컨테이너입니다. 설명이 없다면 필요 없습니다.
- 관련된 입력은 `FieldGroup`으로 묶고, 의미상 묶을 때는 `FieldSet`과 `FieldLegend`를 씁니다.

## Responsive Layout

- **세로 배치:** 기본값은 라벨·입력·도움말을 세로로 쌓습니다. 모바일을 먼저 생각한 화면에 알맞습니다.
- **가로 배치:** `Field`에 `orientation="horizontal"`을 주면 라벨과 입력이 나란히 놓입니다. `FieldContent`와 함께 쓰면 설명 줄도 맞춰집니다.
- **반응형 배치:** `orientation="responsive"`를 주면 컨테이너 크기에 따라 자동으로 열이 잡힙니다. `FieldGroup`에 `@container/field-group` 클래스를 붙이면 원하는 브레이크포인트에서 배치가 바뀝니다.

## Validation and Errors

- `Field`에 `data-invalid`를 붙이면 블록 전체가 오류 상태로 바뀝니다.
- 보조 기술을 위해 입력 자체에는 `aria-invalid`를 붙입니다.
- 오류 메시지가 입력과 나란히 놓이도록 `FieldError`는 입력 바로 뒤나 `FieldContent` 안에 그립니다.

```tsx showLineNumbers /data-invalid/ /aria-invalid/
<Field data-invalid>
  <FieldLabel htmlFor="email">Email</FieldLabel>
  <Input id="email" type="email" aria-invalid />
  <FieldError>올바른 이메일 주소를 입력하세요.</FieldError>
</Field>
```

## Accessibility

- `FieldSet`과 `FieldLegend`는 관련된 입력을 묶어 키보드 사용자와 보조 기술 사용자에게 도움을 줍니다.
- `Field`는 `role="group"`을 내보내므로 함께 쓰면 안쪽 입력이 `FieldLabel`과 `FieldLegend`의 라벨을 물려받습니다.
- `FieldSeparator`는 꼭 필요한 곳에만 써서 스크린 리더가 구획 경계를 분명하게 만나게 하세요.

## API Reference

### FieldSet

여백 기본값이 들어간 의미상의 `fieldset`을 그리는 컨테이너입니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<FieldSet>
  <FieldLegend>Delivery</FieldLegend>
  <FieldGroup>{/* Fields */}</FieldGroup>
</FieldSet>
```

### FieldLegend

`FieldSet`의 legend 요소입니다. `label` variant로 바꾸면 라벨 크기에 맞춰집니다.

| Prop        | Type                  | Default    |
| ----------- | --------------------- | ---------- |
| `variant`   | `"legend" \| "label"` | `"legend"` |
| `className` | `string`              |            |

```tsx
<FieldLegend variant="label">알림 설정</FieldLegend>
```

`FieldLegend` 에는 `legend`와 `label` 두 가지 variant가 있습니다. `label` variant는 라벨 크기와 정렬을 따릅니다. `FieldSet`이 중첩될 때 쓰기 좋습니다.

### FieldGroup

`Field`를 쌓고 반응형 배치를 위해 컨테이너 쿼리를 켜 주는 배치 래퍼입니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<FieldGroup className="@container/field-group flex flex-col gap-6">
  <Field>{/* ... */}</Field>
  <Field>{/* ... */}</Field>
</FieldGroup>
```

### Field

입력 한 칸을 감싸는 기본 래퍼입니다. 배치 방향, 오류 상태 스타일, 여백을 맡습니다.

| Prop           | Type                                         | Default      |
| -------------- | -------------------------------------------- | ------------ |
| `orientation`  | `"vertical" \| "horizontal" \| "responsive"` | `"vertical"` |
| `className`    | `string`                                     |              |
| `data-invalid` | `boolean`                                    |              |

```tsx
<Field orientation="horizontal">
  <FieldLabel htmlFor="remember">로그인 상태 유지</FieldLabel>
  <Switch id="remember" />
</Field>
```

### FieldContent

라벨이 입력 옆에 놓일 때 입력과 설명을 묶는 flex 세로 컨테이너입니다. 설명이 없다면 필요 없습니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<Field>
  <Checkbox id="notifications" />
  <FieldContent>
    <FieldLabel htmlFor="notifications">Notifications</FieldLabel>
    <FieldDescription>이메일·문자·푸시 설정입니다.</FieldDescription>
  </FieldContent>
</Field>
```

### FieldLabel

입력에 바로 붙일 때도, `Field`를 안에 중첩할 때도 쓸 수 있는 라벨입니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<FieldLabel htmlFor="email">Email</FieldLabel>
```

### FieldTitle

`FieldContent` 안에서 라벨 스타일로 제목을 그립니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<FieldContent>
  <FieldTitle>Touch ID 켜기</FieldTitle>
  <FieldDescription>기기를 더 빠르게 잠금 해제합니다.</FieldDescription>
</FieldContent>
```

### FieldDescription

도움말 자리입니다. 가로 배치에서 긴 줄을 알아서 고르게 나눕니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<FieldDescription>이메일은 어디에도 공유하지 않습니다.</FieldDescription>
```

### FieldSeparator

`FieldGroup` 안의 구획을 나누는 구분선입니다. 가운데에 내용을 넣을 수도 있습니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<FieldSeparator>또는 다음으로 계속</FieldSeparator>
```

### FieldError

접근성을 갖춘 오류 컨테이너입니다. 자식 요소나 `errors` 배열(예: `react-hook-form`)을 받습니다.

| Prop        | Type                                       | Default |
| ----------- | ------------------------------------------ | ------- |
| `errors`    | `Array<{ message?: string } \| undefined>` |         |
| `className` | `string`                                   |         |

```tsx
<FieldError errors={errors.username} />
```

`errors` 배열에 메시지가 여러 개면 자동으로 목록으로 그립니다.

`FieldError`는 [Standard Schema](https://standardschema.dev/)를 구현한 검증 라이브러리가 만든 issue도 받습니다. Zod·Valibot·ArkType이 여기에 해당합니다. 스키마 결과의 `issues` 배열을 그대로 넘기면 라이브러리와 상관없이 같은 형태의 오류 목록이 그려집니다.
