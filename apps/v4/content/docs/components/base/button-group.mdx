## Usage

```tsx
import {
  ButtonGroup,
  ButtonGroupSeparator,
  ButtonGroupText,
} from "@/components/ui/button-group"
```

```tsx
<ButtonGroup>
  <Button>Button 1</Button>
  <Button>Button 2</Button>
</ButtonGroup>
```

## Composition

아래 구조로 `ButtonGroup`을 만듭니다.

```text
ButtonGroup
├── Button or Input
├── ButtonGroupSeparator
└── ButtonGroupText
```

## Accessibility

- `ButtonGroup`은 `role` 속성이 `group`으로 지정돼 있습니다.
- 그룹 안 버튼 사이는 <Kbd>Tab</Kbd> 으로 이동합니다.
- 버튼 그룹에는 `aria-label`이나 `aria-labelledby`로 이름을 주세요.

```tsx showLineNumbers
<ButtonGroup aria-label="Button group">
  <Button>Button 1</Button>
  <Button>Button 2</Button>
</ButtonGroup>
```

## ButtonGroup vs ToggleGroup

- 동작을 실행하는 버튼을 묶을 때는 `ButtonGroup`을 씁니다.
- 상태를 켜고 끄는 버튼을 묶을 때는 `ToggleGroup`을 씁니다.

## API Reference

### ButtonGroup

`ButtonGroup`은 관련된 버튼을 같은 스타일로 묶는 컨테이너입니다.

| Prop          | Type                         | Default        |
| ------------- | ---------------------------- | -------------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |

```tsx
<ButtonGroup>
  <Button>Button 1</Button>
  <Button>Button 2</Button>
</ButtonGroup>
```

버튼 그룹을 중첩하면 사이가 벌어진 복잡한 배치를 만들 수 있습니다. 자세한 내용은 [nested](#nested) 예제를 보세요.

```tsx
<ButtonGroup>
  <ButtonGroup />
  <ButtonGroup />
</ButtonGroup>
```

### ButtonGroupSeparator

`ButtonGroupSeparator`는 그룹 안 버튼을 시각적으로 나눕니다.

| Prop          | Type                         | Default      |
| ------------- | ---------------------------- | ------------ |
| `orientation` | `"horizontal" \| "vertical"` | `"vertical"` |

```tsx
<ButtonGroup>
  <Button>Button 1</Button>
  <ButtonGroupSeparator />
  <Button>Button 2</Button>
</ButtonGroup>
```

### ButtonGroupText

버튼 그룹 안에 글자를 보여 줄 때 씁니다.

| Prop     | Type                 | Default |
| -------- | -------------------- | ------- |
| `render` | `React.ReactElement` |         |

```tsx
<ButtonGroup>
  <ButtonGroupText>Text</ButtonGroupText>
  <Button>Button</Button>
</ButtonGroup>
```

`render` prop으로 라벨처럼 원하는 컴포넌트를 글자 자리에 그립니다.

```tsx showLineNumbers
import { ButtonGroupText } from "@/components/ui/button-group"
import { Label } from "@/components/ui/label"

export function ButtonGroupTextDemo() {
  return (
    <ButtonGroup>
      <ButtonGroupText render={<Label htmlFor="name" />}>Text</ButtonGroupText>
      <Input placeholder="Type something here..." id="name" />
    </ButtonGroup>
  )
}
```
