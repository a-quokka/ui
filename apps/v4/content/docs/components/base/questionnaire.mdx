## Usage

```tsx
import {
  Questionnaire,
  QuestionnaireActions,
  QuestionnaireChoice,
  QuestionnaireChoices,
  QuestionnaireDescription,
  QuestionnaireError,
  QuestionnaireInput,
  QuestionnaireItem,
  QuestionnaireNext,
  QuestionnairePrevious,
  QuestionnaireProgress,
  QuestionnaireSkip,
  QuestionnaireSubmit,
  QuestionnaireTitle,
} from "@/components/ui/questionnaire"
```

```tsx
const items = [
  {
    name: "direction",
    required: true,
    prompt: "What should we prototype next?",
    description: "Choose a direction or write your own.",
    choices: [
      {
        value: "delegation",
        label: "Delegation",
        description: "Show how work moves to a specialist.",
      },
      {
        value: "questions",
        label: "Question prompts",
        description: "Show choices while the interface waits.",
      },
      { value: "both", label: "Both together" },
    ],
    input: { label: "Another answer", placeholder: "Type another answer…" },
  },
  {
    name: "detail",
    required: false,
    prompt: "How much detail should it include?",
    description: "Skip this if you are not sure yet.",
    choices: [
      { value: "focused", label: "Focused" },
      { value: "complete", label: "Complete flow" },
    ],
  },
] as const
```

항목 모음은 한 번만 정의합니다. `Questionnaire`에 넘기면 진행률·동작·단축키가 서버에서 그려지고, 그다음 각 파트로 나눠 그립니다.

```tsx
<Questionnaire items={items} onSubmit={handleSubmit}>
  <QuestionnaireProgress />
  {items.map((question) => (
    <QuestionnaireItem
      key={question.name}
      name={question.name}
      required={question.required}
    >
      <QuestionnaireTitle>{question.prompt}</QuestionnaireTitle>
      <QuestionnaireDescription>
        {question.description}
      </QuestionnaireDescription>
      <QuestionnaireChoices>
        {question.choices.map((choice) => (
          <QuestionnaireChoice key={choice.value} value={choice.value}>
            <span className="font-medium">{choice.label}</span>
            {"description" in choice ? (
              <span className="text-muted-foreground">
                {choice.description}
              </span>
            ) : null}
          </QuestionnaireChoice>
        ))}
        {"input" in question ? (
          <QuestionnaireInput
            aria-label={question.input.label}
            placeholder={question.input.placeholder}
          />
        ) : null}
      </QuestionnaireChoices>
      <QuestionnaireError />
    </QuestionnaireItem>
  ))}
  <QuestionnaireActions>
    <QuestionnairePrevious />
    <QuestionnaireSkip />
    <QuestionnaireNext />
    <QuestionnaireSubmit />
  </QuestionnaireActions>
</Questionnaire>
```

```tsx
function handleSubmit(event: React.FormEvent<HTMLFormElement>) {
  event.preventDefault()
  const answers = new FormData(event.currentTarget)
  // answers.get("direction"), answers.getAll(...) for multiple items.
}
```

## Composition

```text
Questionnaire
├── QuestionnaireProgress
├── QuestionnaireItem
│   ├── QuestionnaireTitle
│   ├── QuestionnaireDescription
│   ├── QuestionnaireChoices
│   │   ├── QuestionnaireChoice
│   │   └── QuestionnaireInput
│   └── QuestionnaireError
└── QuestionnaireActions
    ├── QuestionnairePrevious
    ├── QuestionnaireSkip
    ├── QuestionnaireNext
    └── QuestionnaireSubmit
```

Questionnaire는 항목 순서, 현재 항목, 답변 상태, 검증, 진행률, 이동을 맡습니다. 이를 감싸는 페이지·카드·다이얼로그·drawer는 닫기와 취소, 저장, 전송, 분기를 맡습니다.

## Server Rendering

`items`를 넘기면 현재 항목·진행률·동작·답변 단축키가 서버에서 그려집니다. 전체 동작은 [headless Questionnaire](/docs/react/questionnaire)를 보세요.

## Accessibility

`QuestionnaireItem`은 `fieldset`을, `QuestionnaireTitle`은 그 `legend`를 그립니다. 설명과 현재 오류는 현재 항목에 연결되고, 잘못된 항목과 답변 컨트롤에는 `aria-invalid`가 붙습니다.

정해진 선택지는 네이티브 radio·checkbox 동작을 그대로 씁니다. 진행률은 이름이 붙은 progressbar로 노출되고, 이동에는 진짜 button을 쓰며, 현재가 아닌 항목과 동작은 감춰지고 조작되지 않습니다. 이동에 성공하면 새로 활성화된 항목에 포커스가 가고, 검증에 실패하면 조작 가능한 답변 컨트롤에 포커스가 갑니다.

`QuestionnaireInput` 에는 눈에 보이는 라벨이나 `aria-label`·`aria-labelledby`로 접근성 이름을 꼭 주세요. placeholder는 라벨이 아닙니다. 직접 조합할 때의 라벨 지정과 전체 키보드 동작은 [Questionnaire 접근성 가이드](/docs/react/questionnaire#accessibility)를 보세요.

## Unstyled

`Questionnaire`의 동작은 `@shadcn/react` 패키지에서 옵니다. 직접 만든 마크업과 스타일에 바로 쓰려면 @shadcn/react의 [Questionnaire](/docs/react/questionnaire)를 보세요.

## API Reference

각 파트의 prop, 데이터 속성, render 상태는 [@shadcn/react Questionnaire](/docs/react/questionnaire#api-reference) 페이지에 정리돼 있습니다. 스타일 컴포넌트는 대응하는 스타일 없는 prop을 그대로 물려받습니다. 이동 컴포넌트는 Button의 `size`와 `variant` prop도 받고, `QuestionnaireActions`는 스타일 버전에만 있는 배치 도우미입니다.
