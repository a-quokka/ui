사이드바는 만들기 가장 까다로운 컴포넌트 중 하나입니다. 애플리케이션의 중심에 놓이고 움직이는 부분도 많습니다.

이제 그 위에 쌓아 올릴 단단한 토대가 생겼습니다. 조합할 수 있고, 테마를 입힐 수 있고, 원하는 대로 고칠 수 있습니다.

## Usage

```tsx showLineNumbers title="app/layout.tsx"
import { SidebarProvider, SidebarTrigger } from "@/components/ui/sidebar"
import { AppSidebar } from "@/components/app-sidebar"

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <SidebarProvider>
      <AppSidebar />
      <main>
        <SidebarTrigger />
        {children}
      </main>
    </SidebarProvider>
  )
}
```

```tsx showLineNumbers title="components/app-sidebar.tsx"
import {
  Sidebar,
  SidebarContent,
  SidebarFooter,
  SidebarGroup,
  SidebarHeader,

  return (

      <SidebarContent>
        <SidebarGroup />
        <SidebarGroup />
      </SidebarContent>
      <SidebarFooter />
    </Sidebar>
  )
}
```

## Structure

- **SidebarProvider** — 접힘 상태를 관리하고 하위 컴포넌트에 사이드바 컨텍스트를 넘깁니다.
- **Sidebar** — 접히는 사이드바 본체입니다.
- **SidebarHeader** — 위쪽에 고정됩니다. 브랜딩, 제목, 워크스페이스 전환에 씁니다.
- **SidebarFooter** — 아래쪽에 고정됩니다. 사용자 메뉴, 설정, 동작 버튼에 씁니다.
- **SidebarContent** — 헤더와 푸터 사이의 스크롤 영역입니다.
- **SidebarGroup** — 관련된 내비게이션을 묶습니다. 라벨·액션·콘텐츠 영역은 선택입니다.
- **SidebarMenu** / **SidebarMenuItem** — 링크·배지·액션·중첩 서브메뉴를 담는 메뉴 구조입니다.
- **SidebarRail** — 사이드바 너비를 조절하는 손잡이입니다.
- **SidebarInset** — `inset` variant를 쓸 때 본문을 감쌉니다.
- **SidebarTrigger** — 사이드바를 열고 접는 컨트롤입니다.

## SidebarProvider

`SidebarProvider`는 `Sidebar`에 사이드바 컨텍스트를 넘깁니다. 애플리케이션은 항상 `SidebarProvider`로 감싸세요.

### Props

| Name           | Type                      | Description                               |
| -------------- | ------------------------- | ----------------------------------------- |
| `defaultOpen`  | `boolean`                 | 사이드바의 기본 열림 상태입니다.          |
| `open`         | `boolean`                 | 사이드바 열림 상태입니다(제어 모드).      |
| `onOpenChange` | `(open: boolean) => void` | 사이드바 열림 상태를 바꿉니다(제어 모드). |

### Width

사이드바가 하나뿐이라면 `sidebar.tsx`의 `SIDEBAR_WIDTH`와 `SIDEBAR_WIDTH_MOBILE` 변수로 너비를 정합니다.

```tsx showLineNumbers title="components/ui/sidebar.tsx"
const SIDEBAR_WIDTH = "16rem"
const SIDEBAR_WIDTH_MOBILE = "18rem"
```

사이드바가 여럿이라면 `style` prop에 `--sidebar-width`와 `--sidebar-width-mobile` CSS 변수를 넣습니다.

```tsx showLineNumbers
<SidebarProvider
  style={
    {
      "--sidebar-width": "20rem",
      "--sidebar-width-mobile": "20rem",
    } as React.CSSProperties
  }
>
  <Sidebar />
</SidebarProvider>
```

### Keyboard Shortcut

사이드바는 맥에서 `cmd+b`, 윈도우에서 `ctrl+b`로 엽니다.

```tsx showLineNumbers title="components/ui/sidebar.tsx"
const SIDEBAR_KEYBOARD_SHORTCUT = "b"
```

## Sidebar

접히는 사이드바를 그리는 `Sidebar` 본체입니다.

### Props

| Property      | Type                              | Description                 |
| ------------- | --------------------------------- | --------------------------- |
| `side`        | `left` or `right`                 | 사이드바가 붙는 방향입니다. |
| `variant`     | `sidebar`, `floating`, or `inset` | 사이드바 variant 입니다.    |
| `collapsible` | `offcanvas`, `icon`, or `none`    | 사이드바 접힘 방식입니다.   |

| Prop        | Description                                              |
| ----------- | -------------------------------------------------------- |
| `offcanvas` | 왼쪽이나 오른쪽에서 밀려 들어오며 접히는 사이드바입니다. |
| `icon`      | 아이콘만 남기고 접히는 사이드바입니다.                   |
| `none`      | 접히지 않는 사이드바입니다.                              |

<Callout>
  **참고:** `inset` variant를 쓴다면 본문을 `SidebarInset` 컴포넌트로 감싸야
  합니다.
</Callout>

```tsx showLineNumbers
<SidebarProvider>
  <Sidebar variant="inset" />
  <SidebarInset>
    <main>{children}</main>
  </SidebarInset>
</SidebarProvider>
```

## useSidebar

`useSidebar` 훅으로 사이드바를 제어합니다.

```tsx showLineNumbers
import { useSidebar } from "@/components/ui/sidebar"

export function AppSidebar() {
  const {
    state,
    open,
    setOpen,
    openMobile,
    setOpenMobile,
    isMobile,
    toggleSidebar,
  } = useSidebar()
}
```

| Property        | Type                      | Description                                               |
| --------------- | ------------------------- | --------------------------------------------------------- |
| `state`         | `expanded` or `collapsed` | 사이드바의 현재 상태입니다.                               |
| `open`          | `boolean`                 | 사이드바가 열려 있는지 여부입니다.                        |
| `setOpen`       | `(open: boolean) => void` | 사이드바 열림 상태를 바꿉니다.                            |
| `openMobile`    | `boolean`                 | 모바일에서 사이드바가 열려 있는지 여부입니다.             |
| `setOpenMobile` | `(open: boolean) => void` | 모바일에서 사이드바 열림 상태를 바꿉니다.                 |
| `isMobile`      | `boolean`                 | 모바일 화면인지 여부입니다.                               |
| `toggleSidebar` | `() => void`              | 사이드바를 토글합니다. 데스크톱과 모바일 모두 적용됩니다. |

## SidebarGroup

`SidebarGroup`으로 사이드바 안에 구획을 만듭니다.

`SidebarGroup`은 `SidebarGroupLabel`과 `SidebarGroupContent`로 이루어지고, `SidebarGroupAction`은 선택입니다.

```tsx showLineNumbers
<SidebarGroup>
  <SidebarGroupLabel>Application</SidebarGroupLabel>
  <SidebarGroupAction>
    <Plus /> <span className="sr-only">Add Project</span>
  </SidebarGroupAction>
  <SidebarGroupContent></SidebarGroupContent>
</SidebarGroup>
```

`SidebarGroup`을 접으려면 `Collapsible`로 감쌉니다.

```tsx showLineNumbers
<Collapsible defaultOpen className="group/collapsible">
  <SidebarGroup>
    <SidebarGroupLabel render={<CollapsibleTrigger />}>
      Help
      <ChevronDown className="ml-auto transition-transform group-data-open/collapsible:rotate-180" />
    </SidebarGroupLabel>
    <CollapsibleContent>
      <SidebarGroupContent />
    </CollapsibleContent>
  </SidebarGroup>
</Collapsible>
```

## SidebarMenuButton

`SidebarMenuButton`은 `SidebarMenuItem` 안의 메뉴 버튼을 그립니다.

기본값은 button 이지만 `render` prop으로 `Link`나 `a` 태그처럼 다른 컴포넌트로 바꿀 수 있습니다.

`isActive` prop으로 현재 메뉴 항목을 활성 상태로 표시합니다.

```tsx showLineNumbers
<SidebarMenuButton render={<a href="#" />} isActive>
  Home
</SidebarMenuButton>
```

## SidebarTrigger

## Controlled Sidebar

`open`과 `onOpenChange` prop으로 사이드바를 제어합니다.

```tsx showLineNumbers
export function AppSidebar() {
  const [open, setOpen] = React.useState(false)

  return (
    <SidebarProvider open={open} onOpenChange={setOpen}>
      <Sidebar />
    </SidebarProvider>
  )
}
```

## Changelog

### RTL Support

이전 버전 `Sidebar`를 쓰고 있다면 RTL을 지원하기 위해 아래를 적용해야 합니다.

<Steps>

<Step>Sidebar 컴포넌트에 `dir` prop을 추가합니다.</Step>

구조 분해한 props에 `dir`을 추가하고 모바일에서는 `SheetContent`로 넘깁니다.

```diff
    variant = "sidebar",
    collapsible = "offcanvas",
    className,
    children,
+   dir,
    ...props

```

그다음 모바일 뷰의 `SheetContent`에 넘깁니다.

```diff
  <Sheet open={openMobile} onOpenChange={setOpenMobile} {...props}>
    <SheetContent
+     dir={dir}
      data-sidebar="sidebar"
      data-slot="sidebar"
      data-mobile="true"
```

<Step>사이드바 컨테이너에 `data-side` 속성을 추가합니다.</Step>

사이드바 컨테이너 요소에 `data-side={side}`를 추가합니다.

```diff
  <div
```

<Step>사이드바 컨테이너의 위치 클래스를 고칩니다.</Step>

자바스크립트 삼항 조건 클래스를 CSS 데이터 속성 선택자로 바꿉니다.

<Step>SidebarTrigger 아이콘에 RTL 반전을 추가합니다.</Step>

RTL에서 아이콘이 뒤집히도록 `SidebarTrigger`의 아이콘에 `className="rtl:rotate-180"`을 추가합니다.

```diff
  <Button ...>
-   <PanelLeftIcon />
+   <PanelLeftIcon className="rtl:rotate-180" />

  </Button>
```

</Steps>

여기까지 적용하면 `dir` prop으로 방향을 지정할 수 있습니다.

```tsx

</Sidebar>
```

사이드바가 LTR과 RTL 모두에서 알맞은 위치에 놓이고 정상적으로 동작합니다.
