## Usage

```tsx showLineNumbers
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar"
```

```tsx showLineNumbers
<Avatar>
  <AvatarImage src="https://github.com/shadcn.png" />
  <AvatarFallback>CN</AvatarFallback>
</Avatar>
```

## Composition

아래 구조로 `Avatar`를 만듭니다.

```text
Avatar
├── AvatarImage
├── AvatarFallback
└── AvatarBadge
```

아래 구조로 `AvatarGroup`을 만듭니다.

```text
AvatarGroup
├── Avatar
│   ├── AvatarImage
│   ├── AvatarFallback
│   └── AvatarBadge
├── Avatar
│   ├── AvatarImage
│   ├── AvatarFallback
│   └── AvatarBadge
└── AvatarGroupCount
```

색이나 크기 같은 스타일은 `className` prop으로 바꿉니다.

```tsx showLineNumbers
<Avatar>
  <AvatarImage src="https://github.com/shadcn.png" alt="@shadcn" />
  <AvatarFallback>CN</AvatarFallback>
  <AvatarBadge className="bg-green-600 dark:bg-green-800" />
</Avatar>
```

## API Reference

### Avatar

`Avatar`는 아바타 이미지와 대체 표시를 감싸는 루트 컴포넌트입니다.

| Prop        | Type                        | Default     |
| ----------- | --------------------------- | ----------- |
| `size`      | `"default" \| "sm" \| "lg"` | `"default"` |
| `className` | `string`                    | -           |

### AvatarImage

`AvatarImage`는 아바타 이미지를 보여 줍니다. Base UI Avatar Image의 prop을 모두 받습니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `src`       | `string` | -       |
| `alt`       | `string` | -       |
| `className` | `string` | -       |

### AvatarFallback

`AvatarFallback`은 이미지를 불러오지 못했을 때 대신 보여 줍니다. Base UI Avatar Fallback의 prop을 모두 받습니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### AvatarBadge

`AvatarBadge`는 아바타에 상태 배지를 보여 줍니다. 보통 오른쪽 아래에 놓입니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### AvatarGroup

`AvatarGroup`은 아바타를 겹쳐 놓아 여러 개를 함께 보여 줍니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### AvatarGroupCount

`AvatarGroupCount`는 아바타 그룹에 개수를 보여 줍니다. 보통 나머지 아바타가 몇 개인지 나타냅니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

Base UI Avatar의 prop은 [Base UI 문서](https://base-ui.com/react/components/avatar#api-reference)를 보세요.
