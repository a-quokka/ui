## Usage

```tsx
import { toast } from "@/components/ui/toast"
```

```tsx
toast.add({
  title: "Event created",
  description: "Sunday, December 3 at 9:00 AM",
})
```

## Types

`type` 옵션을 지정하면 상태 아이콘이 그려집니다. 기본 렌더러는 `success`·`info`·`warning`·`error`·`loading`을 알아봅니다.

<ComponentPreview styleName="base-nova" name="toast-types" />

## Action

`actionProps`에 버튼 prop을 넘겨 동작 버튼을 그립니다.

```tsx
const id = toast.add({
  title: "Event created",
  actionProps: {
    children: "Undo",
    onClick() {
      toast.close(id)
    },
  },
})
```

## Promise

`toast.promise`를 쓰면 비동기 작업이 로딩·성공·실패로 넘어가는 동안 토스트 하나가 계속 갱신됩니다.
