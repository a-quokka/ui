## API

state와 `setApi` prop으로 캐러셀 API 인스턴스를 얻습니다.

<ComponentPreview
  styleName="base-nova"
  name="carousel-api"
  previewClassName="sm:h-[32rem]"
/>

```tsx showLineNumbers {1,4,22}
import { type CarouselApi } from "@/components/ui/carousel"

export function Example() {
  const [api, setApi] = React.useState<CarouselApi>()
  const [current, setCurrent] = React.useState(0)
  const [count, setCount] = React.useState(0)

  React.useEffect(() => {
    if (!api) {
      return
    }

    setCount(api.scrollSnapList().length)
    setCurrent(api.selectedScrollSnap() + 1)

    api.on("select", () => {
      setCurrent(api.selectedScrollSnap() + 1)
    })
  }, [api])

  return (
    <Carousel setApi={setApi}>
      <CarouselContent>
        <CarouselItem>...</CarouselItem>
        <CarouselItem>...</CarouselItem>
        <CarouselItem>...</CarouselItem>
      </CarouselContent>
    </Carousel>
  )
}
```

## Events

`setApi`로 받은 api 인스턴스로 이벤트를 들을 수 있습니다.

```tsx showLineNumbers {1,4-14,16}
import { type CarouselApi } from "@/components/ui/carousel"

export function Example() {
  const [api, setApi] = React.useState<CarouselApi>()

  React.useEffect(() => {
    if (!api) {
      return
    }

    api.on("select", () => {
      // Do something on select.
    })
  }, [api])

  return (
    <Carousel setApi={setApi}>
      <CarouselContent>
        <CarouselItem>...</CarouselItem>
        <CarouselItem>...</CarouselItem>
        <CarouselItem>...</CarouselItem>
      </CarouselContent>
    </Carousel>
  )
}
```

이벤트 사용법은 [Embla Carousel 문서](https://www.embla-carousel.com/api/events/)를 보세요.

## RTL

Dropshot UI에서 RTL을 켜려면 [RTL 설정 가이드](/docs/rtl)를 확인하세요.

<ComponentPreview
  styleName="base-nova"
  name="carousel-rtl"
  direction="rtl"
  previewClassName="h-80 sm:h-[32rem]"
/>

RTL 언어로 캐러셀을 옮길 때는 `opts` prop의 `direction` 옵션을 텍스트 방향에 맞춰야 합니다. 그래야 캐러셀이 올바른 방향으로 넘어갑니다.

```tsx showLineNumbers {2-5}
<Carousel
  dir={dir}
  opts={{
    direction: dir,
  }}
>
  <CarouselContent>
    <CarouselItem>...</CarouselItem>
    <CarouselItem>...</CarouselItem>
    <CarouselItem>...</CarouselItem>
  </CarouselContent>
  <CarouselPrevious className="rtl:rotate-180" />
  <CarouselNext className="rtl:rotate-180" />
</Carousel>
```

`direction` 옵션은 `"ltr"` 또는 `"rtl"`을 받고 `dir` prop 값과 같아야 합니다. 이동 버튼도 방향이 맞도록 `rtl:rotate-180` 클래스로 돌려 주는 편이 좋습니다.
