## Usage

```tsx showLineNumbers
import {
  Drawer,
  DrawerClose,
  DrawerContent,
  DrawerDescription,
  DrawerFooter,
  DrawerHeader,
  DrawerTitle,
  DrawerTrigger,
} from "@/components/ui/drawer"
```

```tsx showLineNumbers
<Drawer>
  <DrawerTrigger render={<Button variant="outline" />}>Open</DrawerTrigger>
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle>Are you absolutely sure?</DrawerTitle>
      <DrawerDescription>This action cannot be undone.</DrawerDescription>
    </DrawerHeader>
    <div className="p-4">{/* Content here */}</div>
    <DrawerFooter>
      <Button>Submit</Button>
      <DrawerClose render={<Button variant="outline" />}>Cancel</DrawerClose>
    </DrawerFooter>
  </DrawerContent>
</Drawer>
```

## Composition

아래 구조로 `Drawer`를 만듭니다.

```text
Drawer
├── DrawerTrigger
└── DrawerContent
    ├── DrawerHeader
    │   ├── DrawerTitle
    │   └── DrawerDescription
    └── DrawerFooter
```

`DrawerContent`는 Base UI의 portal·overlay·viewport·popup을 조합한 것입니다. 더 낮은 수준으로 다루고 싶다면 `DrawerPortal`·`DrawerOverlay`·`DrawerSwipeHandle`도 내보내고 있습니다.

## Custom Sizes

세로 drawer는 내용에 맞춰 커지고 기본 상한은 `calc(100dvh - 6rem)` 입니다. 가로 drawer는 화면 너비의 `75%`, 큰 화면에서는 `24rem`을 씁니다.

세로 drawer의 높이는 `DrawerContent`에 `h-*`·`max-h-*` 유틸리티로 바꿉니다.

```tsx
<DrawerContent className="h-[50vh]">
```

가로 drawer의 너비는 `DrawerContent`에 `w-*`·`max-w-*` 유틸리티로 바꿉니다.

```tsx
<DrawerContent className="w-96">
```

같은 컴포넌트를 여러 방향으로 그린다면 `data-[swipe-axis=*]` variant로 한쪽 축에만 값을 덮어씌우세요.

```tsx
<DrawerContent className="data-[swipe-axis=y]:max-h-[50vh] data-[swipe-axis=x]:w-96">
```

drawer 안의 특정 영역을 스크롤되게 하려면 그 스크롤 컨테이너를 flex 아이템으로 만드세요. 내용에 맞춰 크기가 정해지는 drawer 안에서는 `h-full`이 풀리지 않으니 피합니다.

```tsx
<DrawerContent>
  <DrawerHeader>...</DrawerHeader>
  <div className="flex-1 overflow-y-auto p-4">{/* Scrollable content */}</div>
  <DrawerFooter>...</DrawerFooter>
</DrawerContent>
```

## Styling

drawer는 스타일을 조정할 CSS 변수를 제공합니다. 크기 변수는 `DrawerContent`에, 오버레이 변수는 CSS의 `[data-slot=drawer-overlay]`에 지정하세요.

| Variable                       | Default                | Description                                                               |
| ------------------------------ | ---------------------- | ------------------------------------------------------------------------- |
| `--drawer-inset`               | `0px`                  | 화면 가장자리에서 drawer를 띄웁니다.                                      |
| `--drawer-bleed-background`    | `var(--color-popover)` | 스와이프가 넘칠 때 drawer 뒤 빈틈을 채웁니다.                             |
| `--drawer-overlay-min-opacity` | `0`                    | 오버레이의 최소 불투명도입니다. 스냅 포인트를 쓰면 기본값은 `0.5` 입니다. |

drawer는 데이터 속성도 지정합니다. `DrawerContent`에 `data-[swipe-direction=down]:`을, 그 하위 요소에 `group-data-[swipe-axis=y]/drawer-popup:` 같은 variant를 걸 수 있습니다.

| Attribute                 | Values                        | Set when                              |
| ------------------------- | ----------------------------- | ------------------------------------- |
| `data-swipe-direction`    | `up`, `right`, `down`, `left` | Always.                               |
| `data-swipe-axis`         | `x`, `y`                      | Always.                               |
| `data-snap-points`        | Present                       | The drawer has snap points.           |
| `data-expanded`           | Present                       | The drawer is at the full snap point. |
| `data-swiping`            | Present                       | A swipe is in progress.               |
| `data-nested-drawer-open` | Present                       | A nested drawer is open on top.       |

## Non Modal

`modal={false}`를 주면 drawer가 열려 있어도 페이지의 나머지를 조작할 수 있습니다. `disablePointerDismissal`과 함께 쓰면 바깥을 눌러도 닫히지 않습니다. `modal="trap-focus"`는 스크롤과 포인터 조작은 열어 두면서 포커스만 drawer 안에 가둡니다.

## Snap Points

`snapPoints`로 drawer를 정해진 높이에 맞춰 멈춥니다. `0`과 `1` 사이 숫자는 화면 대비 비율이고, `1`보다 크면 픽셀 값으로 봅니다. 문자열은 `px`와 `rem` 단위를 지원합니다. 스냅 포인트는 세로 drawer 에만 적용됩니다.

현재 스냅 포인트는 `snapPoint`와 `onSnapPointChange` prop으로 제어하며 추적합니다. 가장 큰 스냅 포인트에서는 drawer에 `data-expanded` 속성이 붙어 `data-expanded:` variant로 꾸밀 수 있습니다.

## Migrating from Vaul

base drawer는 이제 Vaul 대신 [Base UI](https://base-ui.com/react/components/drawer)를 씁니다. 이전 base drawer를 설치했다면 Base UI API에 맞게 고치세요.

<Steps>

<Step>의존성을 바꿉니다.</Step>

```diff
- npm install vaul
+ npm install @base-ui/react
```

<Step>`direction`을 `swipeDirection`으로 바꿉니다.</Step>

`bottom` 대신 `down`, `top` 대신 `up`을 씁니다. `left`와 `right`는 그대로입니다.

```diff
- <Drawer direction="bottom">
+ <Drawer swipeDirection="down">
```

<Step>`asChild`를 `render`로 바꿉니다.</Step>

`DrawerTrigger`는 트리거 요소를 `render` prop으로 넘깁니다.

```diff
- <DrawerTrigger asChild>
-   <Button variant="outline">Open</Button>
- </DrawerTrigger>
+ <DrawerTrigger render={<Button variant="outline" />}>
+   Open
+ </DrawerTrigger>
```

`DrawerClose`는 닫기 요소를 `render` prop으로 넘깁니다.

```diff
- <DrawerClose asChild>
-   <Button variant="outline">Cancel</Button>
- </DrawerClose>
+ <DrawerClose render={<Button variant="outline" />}>
+   Cancel
+ </DrawerClose>
```

<Step>스냅 포인트 prop을 고칩니다.</Step>

스냅 포인트를 쓴다면 제어용 스냅 포인트 prop과 순차 스냅 포인트 prop의 이름을 바꾸세요.

```diff
  <Drawer
    snapPoints={[0.25, 0.5, 1]}
-   activeSnapPoint={snapPoint}
-   setActiveSnapPoint={setSnapPoint}
-   snapToSequentialPoint
+   snapPoint={snapPoint}
+   onSnapPointChange={setSnapPoint}
+   snapToSequentialPoints
  >
```

<Step>애니메이션과 포커스 prop을 고칩니다.</Step>

```diff
- <Drawer onAnimationEnd={(open) => setDone(open)}>
+ <Drawer onOpenChangeComplete={(open) => setDone(open)}>
```

```diff
- <DrawerContent onOpenAutoFocus={(event) => event.preventDefault()}>
+ <DrawerContent initialFocus={false}>
```

<Step>Vaul 전용 prop을 점검합니다.</Step>

`handleOnly`·`repositionInputs`·`shouldScaleBackground` 같은 Vaul prop은 base drawer API에 일대일로 대응하는 것이 없습니다. 필요한 동작에 맞춰 `disablePointerDismissal`·`modal`·`snapPoints`나 제어되는 `open` 상태 같은 Base UI prop을 쓰세요.

```diff
- <Drawer handleOnly repositionInputs={false} shouldScaleBackground>
+ <Drawer>
```

```diff
- <Drawer dismissible={false}>
+ <Drawer disablePointerDismissal>
```

<Step>직접 쓰던 데이터 속성 선택자를 고칩니다.</Step>

Vaul의 `data-vaul-drawer-direction` 선택자를 Base UI의 `data-swipe-direction` 선택자로 바꿉니다.

```diff
- <DrawerContent className="data-[vaul-drawer-direction=bottom]:max-h-[50vh]">
+ <DrawerContent className="data-[swipe-direction=down]:max-h-[50vh]">
```

Base UI는 스와이프와 전환 상태를 위해 `data-swiping`·`data-starting-style`·`data-ending-style` 같은 속성도 제공합니다. `DrawerContent` 안의 하위 요소는 `group-data-[swipe-axis=x]/drawer-popup`과 `group-data-[swipe-axis=y]/drawer-popup`으로 축별 스타일을 줄 수 있습니다.

</Steps>
