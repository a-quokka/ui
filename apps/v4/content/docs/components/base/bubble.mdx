`Bubble`은 대화 내용을 감싸 보여 줍니다. 채팅 텍스트, 짧은 구조화 출력, 인용 답변, 제안, 반응에 씁니다.

본격적인 채팅 화면에는 [`Message`](/docs/components/message) 컴포넌트를 쓰세요. `Bubble`은 말풍선 표면만 다루도록 범위를 좁혀 두었습니다. 아바타·이름·시각·메타데이터·메시지 단위 동작은 [`Message`](/docs/components/message)에 둡니다.

## Usage

```tsx showLineNumbers
import { Bubble, BubbleContent, BubbleReactions } from "@/components/ui/bubble"
```

```tsx showLineNumbers
<Bubble>
  <BubbleContent>
    I checked the registry output and removed the stale route.
  </BubbleContent>
  <BubbleReactions>
    <span>👍</span>
  </BubbleReactions>
</Bubble>
```

## Composition

아래 구조로 말풍선을 만듭니다.

```text
Bubble
├── BubbleContent
└── BubbleReactions
```

같은 사람이 연달아 보낸 말풍선은 `BubbleGroup`으로 묶습니다.

```text
BubbleGroup
├── Bubble
│   └── BubbleContent
└── Bubble
    └── BubbleContent
```

## Features

- 강한 primary부터 테두리 없는 ghost까지 일곱 가지 시각 변형
- 보내는 쪽과 받는 쪽을 위한 start·end 정렬
- 말풍선 가장자리에 붙는 반응. 방향과 정렬을 지정할 수 있습니다
- 말풍선은 내용에 맞춰 커지고 컨테이너 너비의 80% 까지 넓어집니다
- `render`로 링크나 버튼 말풍선을 만들 수 있습니다
- 모든 파트에서 `className` prop으로 스타일을 바꿀 수 있습니다

## Variants

`variant`로 말풍선의 시각 처리를 바꿉니다.

<ComponentPreview
  styleName="base-rhea"
  name="bubble-variants"
  previewClassName="h-auto theme-blue"
/>

| Variant       | Description                                                         |
| ------------- | ------------------------------------------------------------------- |
| `default`     | 강한 primary 말풍선입니다. 보통 현재 사용자에게 씁니다.             |
| `secondary`   | 대화 내용에 쓰는 기본 말풍선입니다.                                 |
| `muted`       | 강조를 낮춘 말풍선입니다. 조용히 거드는 내용에 씁니다.              |
| `tinted`      | primary 색을 옅게 입힌 말풍선입니다.                                |
| `outline`     | 테두리가 있는 말풍선입니다. 보조 내용이나 풍부한 콘텐츠에 씁니다.   |
| `ghost`       | 테두리 없는 내용입니다. 어시스턴트 텍스트나 풍부한 콘텐츠에 씁니다. |
| `destructive` | 오류나 실패한 동작을 알리는 말풍선입니다.                           |

말풍선은 내용에 맞춰 커지고 컨테이너 너비의 80% 까지 넓어집니다. `ghost` variant는 최대 너비를 없애서 어시스턴트 텍스트나 풍부한 콘텐츠가 한 줄을 다 쓸 수 있습니다.

## Alignment

`Bubble`의 `align`으로 말풍선을 대화의 시작 쪽이나 끝 쪽에 붙입니다.

<ComponentPreview
  styleName="base-rhea"
  name="bubble-alignment"
  previewClassName="h-auto theme-blue"
/>

| align   | Description                         |
| ------- | ----------------------------------- |
| `start` | 말풍선을 대화의 시작 쪽에 붙입니다. |
| `end`   | 말풍선을 대화의 끝 쪽에 붙입니다.   |

**참고:** 채팅 화면을 만든다면 정렬은 `Bubble`이 아니라 `Message` 컴포넌트에 주는 편이 좋습니다. `Message`의 `role` prop을 쓰면 말풍선이 알아서 시작 쪽이나 끝 쪽에 붙습니다.

## Accessibility

`Bubble`은 메시지 표면만 그립니다. 대화 단위의 의미 구조는 바깥 컨테이너에 두고 아래 내용을 따르세요.

### Labeling Reactions

반응은 이모지가 한 줄로 늘어선 모양입니다. 스크린 리더는 각 글자를 맥락 없이 읽고 `+8` 같은 숫자도 그대로 읽습니다. 줄 전체를 이미지 하나로 묶고 설명이 담긴 `aria-label`을 주면 한 번만 읽힙니다. `role="img"`를 쓰면 개별 이모지가 보조 기술에서 감춰지므로 `aria-hidden`은 따로 필요 없습니다.

```tsx showLineNumbers
<BubbleReactions role="img" aria-label="Reactions: thumbs up, fire, and 8 more">
  <span>👍</span>
  <span>🔥</span>
  <span>+8</span>
</BubbleReactions>
```

반응을 누를 수 있게 만들 때는 버튼으로 그리고, 아이콘만 있는 버튼에는 `aria-label`을 주세요.

```tsx showLineNumbers
<BubbleReactions>
  <Button aria-label="Thumbs up" variant="secondary" size="icon-xs">
    <ThumbsUpIcon />
  </Button>
</BubbleReactions>
```

### Interactive Bubbles

말풍선을 누를 수 있게 만들 때는 `render` prop으로 진짜 `<button>`이나 `<a>`를 그리세요. 그래야 포커스가 가고 역할도 올바르게 전달됩니다. `BubbleContent`는 상호작용 요소에 눈에 보이는 포커스 링을 제공하고, 접근성 이름은 말풍선 텍스트에서 옵니다. 라벨을 따로 붙일 필요는 없습니다.

```tsx showLineNumbers
<Bubble variant="muted" align="end">
  <BubbleContent render={<button type="button" onClick={onReply} />}>
    I forgot my password
  </BubbleContent>
</Bubble>
```

### Meaning Beyond Color

말풍선 variant는 색으로 역할과 어조를 나타냅니다. 색만으로 뜻이 전달되지 않도록 텍스트·정렬·아이콘을 함께 쓰세요. `destructive` 말풍선이라면 색 처리에 기대지 말고 오류 상황을 메시지 본문에 적어 두세요.

## API Reference

### Bubble

말풍선의 루트 래퍼입니다.

| Prop        | Type                                                                                       | Default     | Description                      |
| ----------- | ------------------------------------------------------------------------------------------ | ----------- | -------------------------------- |
| `variant`   | `"default" \| "secondary" \| "muted" \| "tinted" \| "outline" \| "ghost" \| "destructive"` | `"default"` | 말풍선의 시각 처리입니다.        |
| `align`     | `"start" \| "end"`                                                                         | `"start"`   | 말풍선의 가로 정렬입니다.        |
| `className` | `string`                                                                                   | -           | 루트 요소에 덧붙일 클래스입니다. |

### BubbleContent

말풍선 내용을 감싸는 래퍼입니다.

| Prop        | Type                       | Default | Description                           |
| ----------- | -------------------------- | ------- | ------------------------------------- |
| `render`    | `ReactElement \| function` | -       | 내용을 링크처럼 다른 요소로 그립니다. |
| `className` | `string`                   | -       | 내용 요소에 덧붙일 클래스입니다.      |

### BubbleReactions

말풍선에 겹쳐 놓는 반응을 보여 줍니다.

| Prop        | Type                | Default    | Description                    |
| ----------- | ------------------- | ---------- | ------------------------------ |
| `side`      | `"top" \| "bottom"` | `"bottom"` | 반응을 붙일 말풍선 방향입니다. |
| `align`     | `"start" \| "end"`  | `"end"`    | 반응의 가로 정렬입니다.        |
| `className` | `string`            | -          | 반응 줄에 덧붙일 클래스입니다. |

### BubbleGroup

같은 사람이 연달아 보낸 말풍선을 묶습니다.

| Prop        | Type     | Default | Description                      |
| ----------- | -------- | ------- | -------------------------------- |
| `className` | `string` | -       | 그룹 루트에 덧붙일 클래스입니다. |
