## Variants

## With Icon

배지 안에 아이콘을 그릴 수 있습니다. 왼쪽에 두려면 `data-icon="inline-start"`, 오른쪽에 두려면 `data-icon="inline-end"`를 씁니다.

<ComponentPreview styleName="base-nova" name="badge-icon" />

## With Spinner

배지 안에 스피너를 그릴 수 있습니다. 스피너에 `data-icon="inline-start"`나 `data-icon="inline-end"` prop을 꼭 붙이세요.

## API Reference

### Badge

`Badge`는 배지 또는 배지처럼 보이는 요소를 보여 줍니다.

| Prop        | Type                                                                          | Default     |
| ----------- | ----------------------------------------------------------------------------- | ----------- |
| `variant`   | `"default" \| "secondary" \| "destructive" \| "outline" \| "ghost" \| "link"` | `"default"` |
| `className` | `string`                                                                      | -           |
