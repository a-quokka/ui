## Usage

```tsx
import { Label } from "@/components/ui/label"
```

```tsx
<Label htmlFor="email">이메일 주소</Label>
```

## Label in Field

폼 입력에는 `FieldLabel`·`FieldDescription`·`FieldError`가 들어 있는 [Field](/docs/components/base/field) 컴포넌트를 쓰세요.

```tsx
<Field>
  <FieldLabel htmlFor="email">이메일 주소</FieldLabel>
  <Input id="email" />
</Field>
```
