**Charts**를 소개합니다. 프로젝트에 복사해 붙여 넣고 바로 쓰는 차트 컴포넌트 모음입니다.

차트는 기본값 그대로도 보기 좋습니다. 다른 컴포넌트와 잘 어울리고, 프로젝트에 맞게 원하는 만큼 고칠 수 있습니다.

[차트 라이브러리 둘러보기](/charts).

## Component

내부적으로 [Recharts](https://recharts.org/)를 씁니다.

`chart` 컴포넌트는 조합을 염두에 두고 만들었습니다. **차트는 Recharts 컴포넌트로 직접 만들고, `ChartTooltip` 같은 전용 컴포넌트는 필요한 자리에만 가져다 씁니다**.

```tsx showLineNumbers /ChartContainer/ /ChartTooltipContent/
import { Bar, BarChart } from "recharts"

import { ChartContainer, ChartTooltipContent } from "@/components/ui/chart"

export function MyChart() {
  return (
    <ChartContainer>
      <BarChart data={data}>
        <Bar dataKey="value" />
        <ChartTooltip content={<ChartTooltipContent />} />
      </BarChart>
    </ChartContainer>
  )
}
```

Recharts를 감싸지 않습니다. 특정 추상화에 묶이지 않는다는 뜻입니다. Recharts 새 버전이 나오면 공식 업그레이드 절차를 그대로 따라가면 됩니다.

**이 컴포넌트는 이제 여러분의 것입니다**.

## Updating to Recharts v3

예전 차트 코드를 Recharts v3로 올린다면 아래를 확인하세요.

- CSS 변수로 차트 토큰을 참조할 때 `hsl(var(--chart-1))` 대신 `var(--chart-1)`을 씁니다.
- `ChartTooltip.defaultIndex`는 툴팁 초기 상태에만 씁니다. 계속 유지되는 활성 도형은 차트 상태에서 직접 관리하세요.
- 부모 `<BarChart>`에 이미 지정돼 있다면 `<Bar>`의 `layout`은 지웁니다.
- `ResponsiveContainer`가 첫 렌더에서 크기를 잴 수 있도록 `ChartContainer`에 높이나 `min-h-*`, `aspect-*` 중 하나는 남겨 둡니다.

## Chart Config

차트 config에는 차트의 라벨·아이콘·색상을 정의합니다.

차트 데이터와는 일부러 분리해 두었습니다.

그래서 config와 색상 토큰을 여러 차트가 나눠 쓸 수 있습니다. 데이터나 색상 토큰이 원격에 있거나 형식이 다를 때도 config만 따로 쓸 수 있습니다.

```tsx showLineNumbers /ChartConfig/
import { Monitor } from "lucide-react"

import { type ChartConfig } from "@/components/ui/chart"

const chartConfig = {
  desktop: {
    label: "Desktop",
    icon: Monitor,
    // A color like 'hsl(220, 98%, 61%)' or 'var(--color-name)'
    color: "#2563eb",
    // OR a theme object with 'light' and 'dark' keys
    theme: {
      light: "#2563eb",
      dark: "#dc2626",
    },
  },
} satisfies ChartConfig
```

## Tooltip

차트 툴팁은 라벨·이름·인디케이터·값으로 이루어집니다. 필요한 것만 골라 조합하면 됩니다.

<ComponentPreview styleName="base-nova" name="chart-tooltip" hideCode />

`hideLabel`·`hideIndicator` prop으로 표시 여부를 정하고, `indicator` prop으로 인디케이터 모양을 바꿉니다.

툴팁 라벨과 이름에 다른 키를 쓰려면 `labelKey`와 `nameKey`를 지정합니다.

Chart에는 `<ChartTooltip>`과 `<ChartTooltipContent>` 컴포넌트가 함께 들어 있습니다. 이 둘로 차트에 원하는 툴팁을 붙입니다.

```tsx title="components/example-chart.tsx"
import { ChartTooltip, ChartTooltipContent } from "@/components/ui/chart"
```

```tsx title="components/example-chart.tsx"
<ChartTooltip content={<ChartTooltipContent />} />
```

### Props

아래 prop으로 툴팁을 조정합니다.

| Prop            | Type                     | Description                            |
| :-------------- | :----------------------- | :------------------------------------- |
| `labelKey`      | string                   | 라벨에 쓸 config 또는 데이터 키입니다. |
| `nameKey`       | string                   | 이름에 쓸 config 또는 데이터 키입니다. |
| `indicator`     | `dot` `line` or `dashed` | 툴팁 인디케이터 모양입니다.            |
| `hideLabel`     | boolean                  | 라벨을 숨길지 여부입니다.              |
| `hideIndicator` | boolean                  | 인디케이터를 숨길지 여부입니다.        |

### Colors

색상은 차트 config에서 자동으로 가져옵니다.

### Custom

툴팁 라벨과 이름에 다른 키를 쓰려면 `labelKey`와 `nameKey` prop을 지정합니다.

```tsx showLineNumbers /browser/
const chartData = [
  { browser: "chrome", visitors: 187, fill: "var(--color-chrome)" },
  { browser: "safari", visitors: 200, fill: "var(--color-safari)" },
]

const chartConfig = {
  visitors: {
    label: "Total Visitors",
  },
  chrome: {
    label: "Chrome",
    color: "var(--chart-1)",
  },
  safari: {
    label: "Safari",
    color: "var(--chart-2)",
  },
} satisfies ChartConfig
```

```tsx title="components/example-chart.tsx"
<ChartTooltip
  content={<ChartTooltipContent labelKey="visitors" nameKey="browser" />}
/>
```

이렇게 하면 라벨은 `Total Visitors`, 툴팁 이름은 `Chrome`과 `Safari`가 됩니다.
