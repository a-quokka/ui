## Features

- 인라인 마커, 테두리 줄, 라벨 구분선 세 가지 변형
- 보조 기술에서 감춰지는 장식용 아이콘 자리
- `render`로 링크나 버튼 마커를 만들 수 있는 다형 루트
- 스트리밍 상태 텍스트에는 [`shimmer`](/docs/utils/shimmer) 유틸리티와 조합
- 모든 파트에서 `className` prop으로 스타일을 바꿀 수 있습니다

## Accessibility

`Marker`는 기본적으로 표시용입니다. 알맞은 의미 구조는 쓰임새에 따라 달라지므로, 기본값 하나에 기대지 말고 의도에 맞는 role을 고르세요.

### Status and Progress

"Thinking..." 이나 실행 중인 도구처럼 스트리밍·진행 마커에는 `role="status"`를 줘서 보조 기술이 상태 변화를 바로 읽게 하세요. `Marker`는 `role`을 내부 요소로 그대로 넘깁니다.

```tsx showLineNumbers
<Marker role="status">
  <MarkerIcon>
    <Spinner />
  </MarkerIcon>
  <MarkerContent>Compacting conversation</MarkerContent>
</Marker>
```

### Labeled Separators

날짜나 구간 라벨처럼 글자가 들어간 구분선에는 role이 필요 없습니다. 양옆 선은 장식용 CSS 가상 요소이고, 글자는 평범한 내용으로 읽힙니다.

```tsx showLineNumbers
<Marker variant="separator">
  <MarkerContent>Today</MarkerContent>
</Marker>
```

<Callout>
  **참고:** 라벨이 달린 구분선에 `role="separator"`를 붙이지 마세요. separator는
  접근성 이름을 글자가 아니라 `aria-label`에서 가져오고 내용은 표시용으로
  취급되므로, 눈에 보이는 라벨이 읽히지 않습니다. `role="separator"`는 의미 있는
  글자가 없는 구분선에만 쓰세요.
</Callout>

### Bordered Markers

테두리 마커의 의미 구조는 기본 마커와 같습니다. 아래 테두리는 장식이므로 마커의 목적에 따라 `role="status"`를 주거나, `render`를 쓰거나, role 없이 두세요.

```tsx showLineNumbers
<Marker variant="border">
  <MarkerIcon>
    <FileTextIcon />
  </MarkerIcon>
  <MarkerContent>Opened implementation notes</MarkerContent>
</Marker>
```

### Decorative Icons

`MarkerIcon`은 장식용이라 `aria-hidden`으로 보조 기술에서 감춰집니다. 의미는 옆에 있는 `MarkerContent`가 담습니다. 아이콘만 있는 마커라면 `aria-label`이나 눈에 보이는 글자를 넣어 빈 항목으로 읽히지 않게 하세요.

```tsx showLineNumbers
<Marker aria-label="Synced">
  <MarkerIcon>
    <CheckIcon />
  </MarkerIcon>
</Marker>
```

### Interactive Markers

마커가 링크이거나 동작을 실행한다면 `render` prop으로 진짜 `<button>`이나 `<a>`를 그리세요. 그래야 포커스가 가고 역할도 올바르게 전달됩니다. 접근성 이름은 마커 텍스트에서 옵니다.

```tsx showLineNumbers
<Marker render={<a href="/files" />}>
  <MarkerIcon>
    <FileTextIcon />
  </MarkerIcon>
  <MarkerContent>Explored 4 files</MarkerContent>
</Marker>
```

## API Reference

### Marker

마커의 루트 요소입니다. 이 파일은 마커 스타일을 다른 컴포넌트에 조합해 쓸 수 있도록 `markerVariants`도 내보냅니다.

| Prop        | Type                                   | Default     | Description                      |
| ----------- | -------------------------------------- | ----------- | -------------------------------- |
| `variant`   | `"default" \| "border" \| "separator"` | `"default"` | 마커 배치 방식입니다.            |
| `render`    | `ReactElement \| function`             | -           | 링크처럼 다른 요소로 그립니다.   |
| `className` | `string`                               | -           | 루트 요소에 덧붙일 클래스입니다. |

### MarkerIcon

장식용 아이콘 자리입니다. `aria-hidden`으로 보조 기술에서 감춰집니다.

| Prop        | Type     | Default | Description                        |
| ----------- | -------- | ------- | ---------------------------------- |
| `className` | `string` | -       | 아이콘 자리에 덧붙일 클래스입니다. |

### MarkerContent

마커의 텍스트 내용입니다.

| Prop        | Type     | Default | Description                      |
| ----------- | -------- | ------- | -------------------------------- |
| `className` | `string` | -       | 내용 자리에 덧붙일 클래스입니다. |
