## Usage

```tsx showLineNumbers
import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"
```

```tsx showLineNumbers
<Card>
  <CardHeader>
    <CardTitle>카드 제목</CardTitle>
    <CardDescription>카드 설명</CardDescription>
    <CardAction>카드 동작</CardAction>
  </CardHeader>
  <CardContent>
    <p>카드 내용</p>
  </CardContent>
  <CardFooter>
    <p>카드 바닥글</p>
  </CardFooter>
</Card>
```

## Composition

아래 구조로 `Card`를 만듭니다.

```text
Card
├── CardHeader
│   ├── CardTitle
│   ├── CardDescription
│   └── CardAction
├── CardContent
└── CardFooter
```

## Spacing

`size` prop 말고도 `--card-spacing` CSS 변수로 구획 사이 간격과 카드 파트의 안쪽 여백을 조절할 수 있습니다.

<ComponentPreview
  styleName="base-nova"
  name="card-spacing"
  previewClassName="h-[34rem]"
/>

`-mx-(--card-spacing)`처럼 음수 여백을 쓰면 카드 안쪽 여백에 맞춰 정렬을 유지하면서 내용을 좌우 끝까지 채울 수 있습니다. 그 내용이 푸터 위에 놓인다면 `CardContent`에 `-mb-(--card-spacing)`을 줘서 구획 간격을 없애세요.

## API Reference

### Card

`Card`는 카드 내용을 담는 루트 컨테이너입니다.

| Prop        | Type                | Default     |
| ----------- | ------------------- | ----------- |
| `size`      | `"default" \| "sm"` | `"default"` |
| `className` | `string`            | -           |

### CardHeader

`CardHeader` 에는 제목과 설명, 필요하면 동작 버튼이 들어갑니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### CardTitle

`CardTitle`은 카드 제목입니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### CardDescription

`CardDescription`은 제목 아래 도움말입니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### CardAction

`CardAction`은 헤더 오른쪽 위에 버튼이나 배지 같은 내용을 놓습니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### CardContent

`CardContent`는 카드의 본문입니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### CardFooter

`CardFooter`는 카드 아래쪽의 동작 버튼과 보조 내용을 담습니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

## Changelog

### Spacing Variable

이전 버전 `Card`를 쓰고 있다면 `--card-spacing` 변수를 쓰기 위해 아래를 적용해야 합니다.

<Steps>

<Step>Card 루트의 여백 클래스를 고칩니다.</Step>

박아 둔 gap과 세로 padding을 `--card-spacing`으로 바꾸고, 루트에 기본 크기와 작은 크기 값을 지정합니다.

```diff
  className={cn(
-   "group/card flex flex-col gap-4 overflow-hidden rounded-xl bg-card py-4 text-sm text-card-foreground ring-1 ring-foreground/10 has-data-[slot=card-footer]:pb-0 has-[>img:first-child]:pt-0 data-[size=sm]:gap-3 data-[size=sm]:py-3 data-[size=sm]:has-data-[slot=card-footer]:pb-0 *:[img:first-child]:rounded-t-xl *:[img:last-child]:rounded-b-xl",
+   "group/card flex flex-col gap-(--card-spacing) overflow-hidden rounded-xl bg-card py-(--card-spacing) text-sm text-card-foreground ring-1 ring-foreground/10 [--card-spacing:--spacing(4)] has-data-[slot=card-footer]:pb-0 has-[>img:first-child]:pt-0 data-[size=sm]:[--card-spacing:--spacing(3)] data-[size=sm]:has-data-[slot=card-footer]:pb-0 *:[img:first-child]:rounded-t-xl *:[img:last-child]:rounded-b-xl",
    className
  )}
```

<Step>CardHeader의 여백 클래스를 고칩니다.</Step>

가로 padding과 테두리 여백을 공용 변수로 바꿉니다.

```diff
  className={cn(
-   "group/card-header @container/card-header grid auto-rows-min items-start gap-1 rounded-t-xl px-4 group-data-[size=sm]/card:px-3 has-data-[slot=card-action]:grid-cols-[1fr_auto] has-data-[slot=card-description]:grid-rows-[auto_auto] [.border-b]:pb-4 group-data-[size=sm]/card:[.border-b]:pb-3",
+   "group/card-header @container/card-header grid auto-rows-min items-start gap-1 rounded-t-xl px-(--card-spacing) has-data-[slot=card-action]:grid-cols-[1fr_auto] has-data-[slot=card-description]:grid-rows-[auto_auto] [.border-b]:pb-(--card-spacing)",
    className
  )}
```

<Step>CardContent와 CardFooter의 여백 클래스를 고칩니다.</Step>

내용의 안쪽 여백과 푸터 padding에 `--card-spacing`을 씁니다.

```diff
  function CardContent({ className, ...props }: React.ComponentProps<"div">) {
    return (
      <div
        data-slot="card-content"
-       className={cn("px-4 group-data-[size=sm]/card:px-3", className)}
+       className={cn("px-(--card-spacing)", className)}
        {...props}
      />
    )
  }
```

```diff
  className={cn(
-   "flex items-center rounded-b-xl border-t bg-muted/50 p-4 group-data-[size=sm]/card:p-3",
+   "flex items-center rounded-b-xl border-t bg-muted/50 p-(--card-spacing)",
    className
  )}
```

</Steps>

여기까지 적용하면 `Card`에 임의 속성 클래스로 `--card-spacing`을 지정해 카드 여백을 조절할 수 있습니다.

```tsx
function Example() {
  return <Card className="[--card-spacing:--spacing(6)]">...</Card>
}
```
