## Usage

```tsx showLineNumbers
import {
  Alert,
  AlertAction,
  AlertDescription,
  AlertTitle,
} from "@/components/ui/alert"
```

```tsx showLineNumbers
<Alert>
  <InfoIcon />
  <AlertTitle>알려 드립니다</AlertTitle>
  <AlertDescription>
    You can add components and dependencies to your app using the cli.
  </AlertDescription>
  <AlertAction>
    <Button variant="outline">Enable</Button>
  </AlertAction>
</Alert>
```

## API Reference

### Alert

`Alert`는 사용자의 주의를 끄는 안내를 보여 줍니다.

| Prop      | Type                         | Default     |
| --------- | ---------------------------- | ----------- |
| `variant` | `"default" \| "destructive"` | `"default"` |

### AlertTitle

`AlertTitle`은 알림의 제목입니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### AlertDescription

`AlertDescription`은 알림의 설명이나 내용입니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### AlertAction

`AlertAction`은 버튼 같은 동작 요소를 알림 오른쪽 위에 고정해 보여 줍니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |
