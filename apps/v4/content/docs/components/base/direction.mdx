`DirectionProvider`로 애플리케이션의 텍스트 방향(`ltr` 또는 `rtl`)을 정합니다. 아랍어·히브리어·페르시아어처럼 오른쪽에서 왼쪽으로 읽는 언어를 지원하려면 꼭 필요합니다.

아래는 RTL 모드 미리보기입니다. 언어 선택기로 언어를 바꿔 보세요. 다른 예시는 각 컴포넌트 문서의 RTL 섹션에 있습니다.

## Usage

```tsx showLineNumbers
import { DirectionProvider } from "@/components/ui/direction"
```

```tsx showLineNumbers
<html dir="rtl">
  <body>
    <DirectionProvider direction="rtl">
      {/* Your app content */}
    </DirectionProvider>
  </body>
</html>
```

## useDirection

`useDirection` 훅으로 현재 애플리케이션의 방향을 읽습니다.

```tsx showLineNumbers
import { useDirection } from "@/components/ui/direction"

function MyComponent() {
  const direction = useDirection()
  return <div>Current direction: {direction}</div>
}
```
