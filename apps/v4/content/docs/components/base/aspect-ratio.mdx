## Usage

```tsx showLineNumbers
import { AspectRatio } from "@/components/ui/aspect-ratio"
```

```tsx showLineNumbers
<AspectRatio ratio={16 / 9}>
  <Image src="..." alt="Image" className="rounded-md object-cover" />
</AspectRatio>
```

## Square

`ratio={1 / 1}` prop을 쓴 정사각형 비율입니다. 이미지를 정사각형으로 보여 줄 때 씁니다.

## API Reference

### AspectRatio

`AspectRatio`는 원하는 비율 안에 콘텐츠를 담습니다.

| Prop        | Type     | Default | Required |
| ----------- | -------- | ------- | -------- |
| `ratio`     | `number` | -       | Yes      |
| `className` | `string` | -       | No       |

자세한 내용은 [Base UI 문서](https://base-ui.com/react/components/aspect-ratio#api-reference)를 보세요.
