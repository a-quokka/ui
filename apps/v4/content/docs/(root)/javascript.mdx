이 프로젝트와 컴포넌트는 TypeScript 로 쓰였습니다. 여러분의 프로젝트에도 TypeScript 를 권합니다.

다만 JavaScript 버전도 제공합니다. [CLI](/docs/cli) 로 받을 수 있습니다.

TypeScript 를 쓰지 않으려면 `components.json` 의 `tsx` 플래그를 끄세요.

```json {4} title="components.json" showLineNumbers
{
  "style": "new-york",
  "rsc": false,
  "tsx": false,
  "tailwind": {
    "config": "",
    "css": "src/app/globals.css",
    "baseColor": "zinc",
    "cssVariables": true
  },
  "iconLibrary": "lucide",
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils",
    "ui": "@/components/ui",
    "lib": "@/lib",
    "hooks": "@/hooks"
  }
}
```

`import` 별칭은 아래 `jsconfig.json` 으로 설정합니다.

```json {4} title="jsconfig.json" showLineNumbers
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./*"]
    }
  }
}
```
