## init

`init` 명령으로 기존 프로젝트의 설정과 의존성을 잡거나, `--name` 을 주어 새 프로젝트를 만듭니다.

`init` 은 의존성을 설치하고 `cn` 유틸을 넣고 프로젝트의 CSS 변수를 설정합니다.

```bash
npx shadcn@latest init
```

**옵션**

```bash
Usage: shadcn init [options] [components...]

initialize your project and install dependencies

Arguments:
  components                 names, url or local path to component

Options:
  -t, --template <template>  the template to use. (next, vite, start, react-router, laravel, astro)
  -b, --base <base>          the component library to use. (base, radix, aria)
  -p, --preset [name]        use a preset configuration
  -y, --yes                  skip confirmation prompt. (default: true)
  -d, --defaults             use default configuration: --template=next --preset=nova (default: false)
  -f, --force                force overwrite of existing configuration. (default: false)
  -c, --cwd <cwd>            the working directory. defaults to the current directory.
  -n, --name <name>          the name for the new project.
  -s, --silent               mute output. (default: false)
  --css-variables            use css variables for theming. (default: true)
  --no-css-variables         do not use css variables for theming.
  --monorepo                 scaffold a monorepo project.
  --no-monorepo              skip the monorepo prompt.
  --rtl                      enable RTL support.
  --no-rtl                   disable RTL support.
  --pointer                  enable pointer cursor for buttons.
  --no-pointer               disable pointer cursor for buttons.
  --reinstall                re-install existing UI components.
  --no-reinstall             do not re-install existing UI components.
  -h, --help                 display help for command
```

`create` 는 `init` 의 다른 이름입니다.

```bash
npx shadcn@latest create
```

## add

`add` 명령으로 컴포넌트와 의존성을 프로젝트에 추가합니다.

```bash
npx shadcn@latest add [component]
```

**옵션**

```bash
Usage: shadcn add [options] [components...]

add a component to your project

Arguments:
  components           name, url or local path to component

Options:
  -y, --yes            skip confirmation prompt. (default: false)
  -o, --overwrite      overwrite existing files. (default: false)
  -c, --cwd <cwd>      the working directory. defaults to the current directory.
  -a, --all            add all available components (default: false)
  -p, --path <path>    the path to add the component to.
  -s, --silent         mute output. (default: false)
  --dry-run            preview changes without writing files. (default: false)
  --diff [path]        show diff for a file.
  --view [path]        show file contents.
  -h, --help           display help for command
```

## apply

`apply` 명령으로 기존 프로젝트에 프리셋을 적용합니다.

```bash
npx shadcn@latest apply a2r6bw
```

UI 컴포넌트를 다시 설치하지 않고 프리셋의 테마나 폰트만 적용할 수도 있습니다.

```bash
npx shadcn@latest apply a2r6bw --only theme
```

`--only` 에는 `theme` 과 `font` 를 줄 수 있습니다.

**옵션**

```bash
Usage: shadcn apply [options] [preset]

apply a preset to an existing project

Arguments:
  preset             the preset to apply

Options:
  --preset <preset>  preset configuration to apply
  --only [parts]     apply only parts of a preset: theme, font
  -y, --yes          skip confirmation prompt. (default: false)
  -c, --cwd <cwd>    the working directory. defaults to the current directory.
  -s, --silent       mute output. (default: false)
  -h, --help         display help for command
```

## search

`search` 명령으로 레지스트리에서 항목을 찾습니다.

```bash
npx shadcn@latest search [registry]
```

검색어를 줄 수 있습니다.

```bash
npx shadcn@latest search @shadcn -q "button"
```

여러 레지스트리를 한 번에 찾을 수도 있습니다.

```bash
npx shadcn@latest search @shadcn @v0 @acme
```

`list` 는 `search` 의 다른 이름입니다.

```bash
npx shadcn@latest list @acme
```

**옵션**

```bash
Usage: shadcn search|list [options] <registries...>

search items from registries

Arguments:
  registries             the registry names or urls to search items from. Names
                         must be prefixed with @.

Options:
  -c, --cwd <cwd>        the working directory. defaults to the current directory.
  -q, --query <query>    query string
  -l, --limit <number>   maximum number of items to display per registry (default: "100")
  -o, --offset <number>  number of items to skip (default: "0")
  -h, --help             display help for command
```

## build

`build` 명령으로 레지스트리 JSON 파일을 만듭니다.

```bash
npx shadcn@latest build
```

이 명령은 `registry.json` 을 읽어 `public/r` 디렉터리에 레지스트리 JSON 파일을 만듭니다.

**옵션**

```bash
Usage: shadcn build [options] [registry]

build components for a shadcn registry

Arguments:
  registry             path to registry.json file (default: "./registry.json")

Options:
  -o, --output <path>  destination directory for json files (default: "./public/r")
  -c, --cwd <cwd>      the working directory. defaults to the current directory.
  -h, --help           display help for command
```

출력 위치를 바꾸려면 `--output` 옵션을 씁니다.

```bash
npx shadcn@latest build --output ./public/registry
```

## migrate

`migrate` 명령으로 프로젝트에 마이그레이션을 돌립니다.

```bash
npx shadcn@latest migrate [migration]
```

**쓸 수 있는 마이그레이션**

| Migration    | Description                                            |
| ------------ | ------------------------------------------------------ |
| `icons`      | UI 컴포넌트를 다른 아이콘 라이브러리로 옮깁니다.       |
| `base-color` | 테마를 다른 기준 색으로 옮깁니다.                      |
| `radix`      | radix-ui 로 옮깁니다.                                  |
| `rtl`        | 컴포넌트가 RTL(오른쪽에서 왼쪽)을 지원하도록 옮깁니다. |

**옵션**

```bash
Usage: shadcn migrate [options] [migration] [path]

run a migration.

Arguments:
  migration          the migration to run.
  path               optional path or glob pattern to migrate.

Options:
  -c, --cwd <cwd>    the working directory. defaults to the current directory.
  -l, --list         list all migrations. (default: false)
  -y, --yes          skip confirmation prompt. (default: false)
  -f, --from <name>  the base color or icon library to migrate from.
  -t, --to <name>    the base color or icon library to migrate to.
  -h, --help         display help for command
```

---

### migrate icons

`icons` 마이그레이션은 컴포넌트를 다른 아이콘 라이브러리로 옮깁니다.

```bash
npx shadcn@latest migrate icons
```

출발 라이브러리와 목표 라이브러리를 물어본 뒤 `ui` 디렉터리의 아이콘 import 와 JSX 사용을 고치고, 목표 라이브러리를 설치하고, `components.json` 의 `iconLibrary` 를 갱신합니다. 그래야 이후 `npx shadcn add` 가 새 라이브러리를 씁니다.

지원하는 라이브러리는 `lucide`·`tabler`·`hugeicons`·`phosphor`·`remixicon`·`radix`(레거시)입니다.

**물어보지 않고 돌리기**

`--from` 과 `--to` 를 주면 묻지 않고 진행합니다.

```bash
npx shadcn@latest migrate icons --from lucide --to phosphor --yes
```

**특정 파일만 옮기기**

특정 파일만 옮기거나 glob 패턴을 쓸 수 있습니다. 범위를 좁혀 돌리면 `components.json` 은 건드리지 않습니다.

```bash
# Migrate a specific file.
npx shadcn@latest migrate icons src/components/ui/button.tsx --from lucide --to tabler

# Migrate files matching a glob pattern.
npx shadcn@latest migrate icons "src/components/**" --from lucide --to tabler
```

목표 라이브러리에 대응이 없는 아이콘은 그대로 두고 마지막에 알려 줍니다.

---

### migrate base-color

`base-color` 마이그레이션은 테마의 기준 색을 다른 색으로 바꿉니다.

```bash
npx shadcn@latest migrate base-color
```

출발 색과 목표 색을 물어본 뒤 테마 CSS 변수(`components.json` 의 `tailwind.css` 가 가리키는 파일)를 고치고 `baseColor` 를 갱신합니다. 그래야 이후 `npx shadcn add` 가 새 기준 색을 씁니다.

지원하는 기준 색은 `neutral`·`zinc`·`stone`·`mauve`·`olive`·`mist`·`taupe` 입니다.

**물어보지 않고 돌리기**

`components.json` 의 현재 `baseColor` 에서 옮기려면 `--to` 만 주고, 아니면 `--from` 과 `--to` 를 모두 지정하세요.

```bash
npx shadcn@latest migrate base-color --to zinc --yes
```

출발 기준 색과 더 이상 맞지 않는 테마 토큰은 그대로 두고 마지막에 알려 줍니다.

### migrate rtl

`rtl` 마이그레이션은 컴포넌트가 RTL(오른쪽에서 왼쪽) 언어를 지원하도록 고칩니다.

```bash
npx shadcn@latest migrate rtl
```

이때 이런 일이 일어납니다.

1. `components.json` 에 `rtl: true` 를 설정합니다
2. 방향이 박힌 CSS 속성을 논리 속성으로 바꿉니다(예: `ml-4` → `ms-4`, `text-left` → `text-start`)
3. 필요한 곳에 `rtl:` variant 를 붙입니다(예: `space-x-4` → `space-x-4 rtl:space-x-reverse`)

**특정 파일만 옮기기**

특정 파일만 옮기거나 glob 패턴을 쓸 수 있습니다.

```bash
# Migrate a specific file
npx shadcn@latest migrate rtl src/components/ui/button.tsx

# Migrate files matching a glob pattern
npx shadcn@latest migrate rtl "src/components/ui/**"
```

경로를 주지 않으면 `components.json` 이 가리키는 `ui` 디렉터리의 모든 파일을 고칩니다.

---

### migrate radix

`radix` 마이그레이션은 낱개 `@radix-ui/react-*` 패키지에서 통합된 `radix-ui` 패키지로 import 를 옮깁니다.

```bash
npx shadcn@latest migrate radix
```

이때 이런 일이 일어납니다.

1. `@radix-ui/react-*` import 를 `radix-ui` 로 바꿉니다
2. `package.json` 에 `radix-ui` 패키지를 추가합니다

**전**

```tsx
import * as DialogPrimitive from "@radix-ui/react-dialog"
import * as SelectPrimitive from "@radix-ui/react-select"
```

**후**

```tsx
import { Dialog as DialogPrimitive, Select as SelectPrimitive } from "radix-ui"
```

**특정 파일만 옮기기**

특정 파일만 옮기거나 glob 패턴을 쓸 수 있습니다.

```bash
# Migrate a specific file.
npx shadcn@latest migrate radix src/components/ui/dialog.tsx

# Migrate files matching a glob pattern.
npx shadcn@latest migrate radix "src/components/ui/**"
```

경로를 주지 않으면 `components.json` 이 가리키는 `ui` 디렉터리의 모든 파일을 고칩니다.

끝나면 `package.json` 에서 쓰지 않는 `@radix-ui/react-*` 패키지를 지워도 됩니다.

## eject

`init` 을 돌리면 shadcn 이 전역 CSS 파일에 `@import "shadcn/tailwind.css"` 를 넣습니다. 여기에는 `data-open:`·`data-closed:` 같은 커스텀 variant 와 아코디언 애니메이션 등 공용 Tailwind v4 유틸리티가 들어 있습니다.

`eject` 명령으로 `shadcn/tailwind.css` 를 전역 CSS 파일 안에 펼쳐 넣고 프로젝트에서 `shadcn` 의존성을 걷어냅니다.

<Callout icon={<TriangleAlertIcon />}>
  **참고: 되돌릴 수 없습니다.** eject 한 뒤에는 shadcn CLI 가
  `shadcn/tailwind.css` 를 갱신해도 자동으로 반영되지 않습니다.
</Callout>

```bash
npx shadcn@latest eject
```

**전**

```css
@import "tailwindcss";
@import "tw-animate-css";
@import "shadcn/tailwind.css";
```

**후**

```css
@import "tailwindcss";
@import "tw-animate-css";
/* ejected from shadcn@4.8.3 */
@theme inline {
  @keyframes accordion-down {
    from {
      height: 0;
    }
    to {
      height: var(
        --radix-accordion-content-height,
        var(--accordion-panel-height, auto)
      );
    }
  }
}

@custom-variant data-open {
  &:where([data-state="open"]),
  &:where([data-open]:not([data-open="false"])) {
    @slot;
  }
}

@utility no-scrollbar {
  -ms-overflow-style: none;
  scrollbar-width: none;

  &::-webkit-scrollbar {
    display: none;
  }
}
```

**모노레포**

모노레포에서는 `components.json` 과 전역 CSS 파일이 있는 워크스페이스에서 명령을 돌리세요.

```bash
npx shadcn@latest eject -c packages/ui
```

**옵션**

```bash
Usage: shadcn eject [options]

inline shadcn/tailwind.css and remove the shadcn dependency

Options:
  -c, --cwd <cwd>  the working directory. defaults to the current directory.
  -y, --yes        skip confirmation prompt. (default: false)
  -s, --silent     mute output. (default: false)
  -h, --help       display help for command
```
