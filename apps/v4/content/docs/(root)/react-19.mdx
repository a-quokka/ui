## TL;DR

`npm` 을 쓴다면 플래그를 붙여 의존성을 설치할 수 있습니다. `shadcn` CLI 가 실행할 때 어떤 플래그를 쓸지 물어봅니다. pnpm·bun·yarn 은 플래그가 필요 없습니다.

패키지별 React 19 지원 현황은 [Upgrade Status](#upgrade-status) 를 보세요.

## What's happening?

React 19 는 현재 [rc](https://www.npmjs.com/package/react?activeTab=versions) 이고 [최신 Next.js 15 릴리스에서 검증되고 지원됩니다](https://nextjs.org/blog/next-15#react-19).

React 19 를 지원하려면 각 패키지 관리자가 React 19 를 peer dependency 로 넣고 검증해야 합니다. [이미](https://github.com/radix-ui/primitives/pull/2952) [진행](https://github.com/pacocoursey/cmdk/pull/318) [중입니다](https://github.com/emilkowalski/vaul/pull/498).

```diff /^19.0/
"peerDependencies": {
-  "react": "^16.8 || ^17.0 || ^18.0",
+  "react": "^16.8 || ^17.0 || ^18.0 || ^19.0",
-  "react-dom": "^16.8 || ^17.0 || ^18.0"
+  "react-dom": "^16.8 || ^17.0 || ^18.0 || ^19.0"
},
```

<Callout>
  `npm info <package> peerDependencies` 로 그 패키지가 React 19 를 peer
  dependency 로 두는지 확인할 수 있습니다.
</Callout>

그전까지는 React 19 를 peer dependency 로 두지 **않은** 패키지를 설치할 때 이런 오류가 뜹니다.

```bash
npm error code ERESOLVE
npm error ERESOLVE unable to resolve dependency tree
npm error
npm error While resolving: my-app@0.1.0
npm error Found: react@19.0.0-rc-69d4b800-20241021
npm error node_modules/react
npm error   react@"19.0.0-rc-69d4b800-20241021" from the root project
```

<Callout>
  **참고:** npm 에서만 그렇습니다. PNPM 과 Bun 은 조용히 경고만 띄웁니다.
</Callout>

## How to fix this

### Solution 1: `--force` or `--legacy-peer-deps`

`--force` 나 `--legacy-peer-deps` 플래그로 강제 설치할 수 있습니다.

```bash
npm i <package> --force

npm i <package> --legacy-peer-deps
```

그러면 peer dependency 경고를 무시하고 설치합니다.

<Accordion type="multiple">
  <AccordionItem value="flags">
    <AccordionTrigger className="font-medium">
      `--force` 와 `--legacy-peer-deps` 는 무슨 일을 하나요?

    <AccordionContent className="[&_ul]:mt-0">

      - `--legacy-peer-deps`: 엄격한 peer dependency 검사를 건너뛰어, 조건을
        못 맞춘 패키지도 오류 없이 설치되게 합니다.

    </AccordionContent>

  </AccordionItem>
</Accordion>

### Solution 2: Use React 18

설치하려는 패키지와 맞는 18 버전으로 `react` 와 `react-dom` 을 내렸다가, 의존성이 갱신되면 다시 올리는 방법도 있습니다.

```bash
npm i react@18 react-dom@18
```

어느 쪽을 고르든 되돌아간 부분이 없는지 앱을 꼼꼼히 확인하세요.

## Using shadcn/ui on Next.js 15

### Using pnpm, bun, or yarn

[설치 문서](/docs/installation/next)를 따라 shadcn/ui 를 설치하세요. 플래그는 필요 없습니다.

### Using npm

`npx shadcn@latest init -d` 를 돌리면 peer dependency 문제를 어떻게 풀지 물어봅니다.

```bash
It looks like you are using React 19.
Some packages may fail to install due to peer dependency issues (see https://ui.shadcn.com/react-19).

? How would you like to proceed? › - Use arrow-keys. Return to submit.
❯   Use --force
    Use --legacy-peer-deps
```

그다음 고른 플래그를 붙여 명령을 돌리면 됩니다.

## Adding components

컴포넌트를 추가하는 과정도 위와 같습니다. peer dependency 문제를 풀 플래그를 고르세요.

**새 의존성을 설치한 뒤에는 반드시 앱을 확인하세요.**

## Recharts

React 19 에서 recharts 를 쓰려면 `react-is` 의존성을 덮어써야 합니다.

<Steps>

<Step>`package.json` 에 아래를 추가하세요.</Step>

```json title="package.json"
"overrides": {
  "react-is": "^19.0.0-rc-69d4b800-20241021"
}
```

참고: `react-is` 버전은 쓰고 있는 React 19 버전과 맞아야 합니다. 위는 예시입니다.

<Step>`npm install --legacy-peer-deps` 를 돌립니다.</Step>

</Steps>
