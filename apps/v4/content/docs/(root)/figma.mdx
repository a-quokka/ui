## Free

- [shadcn/ui components](https://www.figma.com/community/file/1342715840824755935) — [Sitsiilia Bergmann](https://x.com/sitsiilia). shadcn 컴포넌트 체계에 맞춰 잘 정리된 라이브러리이고 꾸준히 관리됩니다.
- [shadcn/ui design system](https://www.figma.com/community/file/1203061493325953101) — [Pietro Schirano](https://twitter.com/skirano). shadcn/ui 의 디자인 짝입니다. 각 컴포넌트를 코드 구현과 정확히 맞도록 공들여 만들었습니다.
- [Obra shadcn/ui Community Edition](https://www.figma.com/community/file/1514746685758799870/) — [Obra Studio](https://obra.studio/). 무료 shadcn/ui Figma 킷 중 가장 완성도가 높습니다. 모든 컴포넌트와 손쉬운 테마 체계를 담았고 디자이너 팀이 관리합니다.

## Paid

- [shadcn/ui kit](https://shadcndesign.com) — [Matt Wierzbicki](https://x.com/matsugfx). 늘 최신 상태로 유지되는 유료 Figma UI 킷입니다. shadcn/ui 와 호환되고 디자인에서 개발로 넘기는 과정에 맞춰져 있습니다.
- [shadcncraft – shadcn/ui Figma kit](https://shadcncraft.com/figma) — shadcn 스타일 여덟 벌과 수백 개의 Pro 컴포넌트·블록을 대응하는 React 코드와 함께 담았습니다. 플러그인으로 새 스타일을 만들고, 커스텀 프리셋과 tweakcn 테마를 불러오고, 프레임을 React 로 내보냅니다. 에이전트 스킬이 Figma MCP 를 통해 디자인을 코드로 바꿉니다.
- [shadcn/studio UI Kit](https://shadcnstudio.com/figma) — shadcn/ui 와 호환되는 Figma 킷입니다. 최신 컴포넌트와 블록 550여 개, 템플릿 10여 개, 테마 20여 개, 그리고 디자인을 shadcn/ui 코드로 바꿔 주는 AI 도구가 들어 있습니다.
- [Shadcnblocks.com](https://www.shadcnblocks.com) — 컴포넌트와 Pro 블록 500여 개, shadcn 테마 변수, 라이트·다크 모드를 갖춘 유료 Figma UI 킷입니다. Figma MCP 도 지원합니다.
- [Obra shadcn/ui Pro](https://shadcn.obra.studio/products/obra-shadcn-ui-pro) — [Obra Studio](https://obra.studio/). Figma 안에서 shadcn/ui 를 다루는 가장 좋은 디자이너 경험을 목표로 합니다. 여덟 스타일 전부, shadcn 과의 일관성, Pro 블록, 디자인에서 코드로 넘기는 플러그인을 담았습니다.
- [Shadcn Space](https://shadcnspace.com/figma) — 잘 다듬어진 블록 320여 개, 템플릿 9종, 컴포넌트 250여 개를 shadcn/ui 호환 Figma 킷으로 묶었습니다. 실제 코드 구조를 그대로 옮긴 Figma 컴포넌트로 더 빠르게 디자인하고 시제품을 만들고 내보낼 수 있습니다.
- [Shadcn Design System](https://shadcnstore.com/) — [ShadcnStore](https://x.com/shadcnstore). 컴포넌트·변형·디자인 토큰과 바로 쓸 수 있는 블록·템플릿을 담은 shadcn/ui 용 Figma UI 킷입니다. 빠른 작업과 픽셀 단위 인계를 염두에 두고 만들었습니다.
