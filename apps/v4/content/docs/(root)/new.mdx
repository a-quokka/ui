---

shadcn/ui 로 만들기 시작할 때 해 볼 만한 것들입니다.

## Add Components

CLI 로 프로젝트에 컴포넌트를 추가합니다.

```bash
npx shadcn@latest add button
```

그다음 코드에서 가져다 씁니다.

```tsx title="app/page.tsx"
import { Button } from "@/components/ui/button"

export default function Home() {
  return <Button>Click me</Button>
}
```

보통의 컴포넌트 라이브러리와 달리 shadcn/ui 는 컴포넌트 소스를 `components/ui/` 아래에 직접 넣습니다. 그 코드는 여러분 것이고 마음대로 고칠 수 있습니다.

여러 컴포넌트를 한 번에 추가하거나 전부 추가할 수도 있습니다.

```bash
npx shadcn@latest add button card input label
```

```bash
npx shadcn@latest add --all
```

전체 컴포넌트는 [컴포넌트](/docs/components) 페이지에서 볼 수 있습니다.

## Customize Your Theme

테마는 CSS 파일에서 바로 고칩니다. CSS 변수와 유틸리티 클래스를 쓰는 방법은 [테마](/docs/theming) 문서를 보세요.

새 프리셋을 써 보고 싶다면 [ui.shadcn.com](https://ui.shadcn.com) 에서 테마를 눈으로 만들고 프리셋 코드로 프로젝트에 적용할 수 있습니다.

```bash
npx shadcn@latest init --preset [CODE]
```

## Add a block

CLI 로 프로젝트에 블록을 추가할 수 있습니다.

```bash
npx shadcn@latest add login-03
```

그러면 `login-03` 블록이 추가됩니다. 코드에서 가져다 쓰면 됩니다.

```tsx title="app/page.tsx"
import { Login03 } from "@/components/login-03"

export default function Home() {
  return <Login03 />
}
```

## Install from Registries

shadcn/ui 에는 커뮤니티 레지스트리 생태계가 넓어지고 있습니다. CLI 로 어떤 레지스트리 주소에서든 컴포넌트를 설치할 수 있습니다.

```bash
npx shadcn@latest add @[registry]/[name]
```

쓸 수 있는 레지스트리 목록은 레지스트리 디렉터리에서 볼 수 있습니다.

## Use AI to Build

shadcn/ui 는 AI 와 함께 쓰도록 설계했습니다. AI 어시스턴트가 프로젝트의 컴포넌트 소스를 읽고 API 를 이해해 페이지와 기능을 조립할 수 있습니다.

이렇게 시켜 보세요.

- _"이름·이메일·비밀번호를 받는 가입 페이지를 만들어 줘."_
- _"프로필 정보를 수정하는 폼이 있는 설정 페이지를 만들어 줘."_
- _"헤더와 통계 카드, 데이터 테이블이 있는 대시보드를 만들어 줘."_

## Install the shadcn Skills

AI 어시스턴트에 shadcn 스킬을 설치하세요. 그러면 컴포넌트 레지스트리 전체와 문서, 검색에 닿을 수 있습니다.

```bash
npx skills add shadcn/ui
```

자세한 내용은 [스킬](/docs/skills) 문서를 보세요.

## Connect the MCP Server

shadcn MCP 서버는 AI 어시스턴트에 컴포넌트 레지스트리 전체와 문서, 검색을 열어 줍니다. 편집기에 연결하면 가장 편합니다.

```bash
npx shadcn@latest mcp init
```

자세한 내용은 [MCP Server](/docs/mcp) 페이지를 보세요.
