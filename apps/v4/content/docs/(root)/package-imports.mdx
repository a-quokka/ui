title: 패키지 import
description: package.json 의 imports 로 shadcn/ui 를 설정합니다.
---

`shadcn` CLI 는 컴포넌트 설치, import 고쳐 쓰기, 서드파티 레지스트리 해석에
[패키지 import](https://nodejs.org/api/packages.html#imports) 를 지원합니다.

패키지 import 를 쓰면 `tsconfig.json` 의 `compilerOptions.paths` 대신
`package.json` 의 비공개 `#...` 별칭을 쓸 수 있습니다.

## Example

`package.json` 에 `imports` 를 설정합니다.

```json title="package.json" showLineNumbers
{
  "imports": {
    "#components/*": "./src/components/*.tsx",
    "#lib/*": "./src/lib/*.ts",
    "#hooks/*": "./src/hooks/*.ts"
  }
}
```

그다음 생성된 컴포넌트를 `#...` 지정자로 가져옵니다.

```tsx
import { Button } from "#components/ui/button"
import { cn } from "#lib/utils"
```

<Callout className="mt-6">
  패키지 import 지정자는 `#` 로 시작해야 합니다. TypeScript 5 이상에서
  `moduleResolution: "bundler"` 와 `resolvePackageJsonImports: true` 를 쓰세요.
</Callout>

## App

컴포넌트를 같은 워크스페이스에 설치하는 Next.js·Vite·TanStack Start 앱을
위한 설정입니다.

<Steps>

### Configure `package.json`

shadcn/ui 설치 대상에 대한 imports 를 추가합니다.

```json title="package.json" showLineNumbers
{
  "imports": {
    "#components/*": "./src/components/*.tsx",
    "#lib/*": "./src/lib/*.ts",
    "#hooks/*": "./src/hooks/*.ts"
  }
}
```

앱이 `src` 디렉터리를 쓰지 않는다면 대상에서 `src/` 를 빼세요. 예를 들면
이렇습니다.

```json title="package.json" showLineNumbers
{
  "imports": {
    "#components/*": "./components/*.tsx",
    "#lib/*": "./lib/*.ts",
    "#hooks/*": "./hooks/*.ts"
  }
}
```

### Configure TypeScript

패키지 import 해석을 켭니다.

```json title="tsconfig.json" showLineNumbers
{
  "compilerOptions": {
    "moduleResolution": "bundler",
    "resolvePackageJsonImports": true
  }
}
```

이 별칭들에는 `compilerOptions.paths` 가 필요 없습니다.

### Configure `components.json`

`components.json` 에도 같은 `#...` 루트를 씁니다.

```json title="components.json" showLineNumbers
{
  "aliases": {
    "components": "#components",
    "ui": "#components/ui",
    "lib": "#lib",
    "hooks": "#hooks",
    "utils": "#lib/utils"
  }
}
```

`ui` 별칭은 `#components/ui` 를 씁니다. `package.json` 의 `#components/*`
`import` 가 이를 감쌉니다.

`utils` 별칭은 `#lib/utils` 를 씁니다. `#lib/*` 가 감싸므로 `#utils` 를 따로
둘 필요는 없습니다.

</Steps>

## Monorepo

모노레포에서는 패키지 안의 파일에는 패키지 import 를, 워크스페이스 사이에서
공유하는 파일에는 패키지 exports 를 쓰세요.

앱 워크스페이스라면 이렇습니다.

```json title="apps/web/package.json" showLineNumbers
{
  "name": "web",
  "private": true,
  "imports": {
    "#components/*": "./src/components/*.tsx",
    "#lib/*": "./src/lib/*.ts",
    "#hooks/*": "./src/hooks/*.ts"
  },
  "dependencies": {
    "@workspace/ui": "workspace:*"
  }
}
```

```json title="apps/web/components.json" showLineNumbers
{
  "aliases": {
    "components": "#components",
    "ui": "@workspace/ui/components",
    "lib": "#lib",
    "hooks": "#hooks",
    "utils": "@workspace/ui/lib/utils"
  }
}
```

공용 UI 패키지라면 이렇습니다.

```json title="packages/ui/package.json" showLineNumbers
{
  "name": "@workspace/ui",
  "private": true,
  "imports": {
    "#components/*": "./src/components/*.tsx",
    "#lib/*": "./src/lib/*.ts",
    "#hooks/*": "./src/hooks/*.ts"
  },
  "exports": {
    "./globals.css": "./src/styles/globals.css",
    "./components/*": "./src/components/*.tsx",
    "./lib/*": "./src/lib/*.ts",
    "./hooks/*": "./src/hooks/*.ts"
  }
}
```

```json title="packages/ui/components.json" showLineNumbers
{
  "aliases": {
    "components": "#components",
    "ui": "#components",
    "lib": "#lib",
    "hooks": "#hooks",
    "utils": "#lib/utils"
  }
}
```

`apps/web` 에서 `add` 를 돌리면 앱 안의 파일은 `#...` import 를 쓰고 공용 UI
파일은 `@workspace/ui` 에서 가져옵니다.

```tsx
import { Button } from "@workspace/ui/components/button"
import { LoginForm } from "#components/login-form"
```

## File extensions

`package.json#imports` 의 대상 패턴이 생성된 import 에 확장자를 붙일지
결정합니다.

```json title="package.json" showLineNumbers
{
  "imports": {
    "#components/*": "./src/components/*.tsx"
  }
}
```

이렇게 하면 확장자 없는 import 가 만들어집니다.

```tsx
import { Button } from "#components/ui/button"
```

확장자 없는 대상을 쓰면,

```json title="package.json" showLineNumbers
{
  "imports": {
    "#components/*": "./src/components/*"
  }
}
```

생성된 import 가 원본 확장자를 그대로 답니다.

```tsx
import { Button } from "#components/ui/button.tsx"
```

대부분의 앱에서는 대상 패턴에 확장자를 넣는 편이 좋습니다.

## Troubleshooting

TypeScript 가 `#...` import 를 풀지 못한다면 이것들을 확인하세요.

- 지정자가 `#` 로 시작하는지
- `imports` 항목이 가장 가까운 `package.json` 에 있는지
- `moduleResolution` 이 `bundler` 인지
- `resolvePackageJsonImports` 가 켜져 있는지
- 컴포넌트를 추가한 뒤 대상 경로가 실제로 있는지

컴포넌트는 설치됐는데 import 가 여전히 `@/...` 를 가리킨다면, `components.json`
의 별칭이 패키지 import 와 같은 `#...` 인지 확인하세요.
