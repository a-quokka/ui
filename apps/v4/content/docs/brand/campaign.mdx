## `ic_` 접두사

캠페인 자산도 아이콘과 같은 디렉터리에 있어서 이름이 `ic_` 로 시작합니다.
아이콘이라는 뜻이 아니라 자산이 놓인 자리 때문입니다. 아이콘 체계의 24×24
규칙은 이들에게 적용되지 않습니다.

| 자산                                | 원본 크기   |
| ----------------------------------- | ----------- |
| `ic_doubleweek_wordmark_desktop`    | 1502 × 541  |
| `ic_doubleweek_wordmark_mobile`     | 779 × 102   |
| `ic_doubleweek_banner_bg`           | 늘려 씀     |
| `ic_doubleweek_countdown_bg`        | 늘려 씀     |
