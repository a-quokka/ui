`Questionnaire` 는 한 번에 질문 하나를 보여 주는 스타일 없는 폼 프리미티브입니다.
답변·진행도·검증·이동을 모두 맡습니다.

에이전트의 확인 질문, 온보딩, 설문, 접수 양식, 설정 화면에 잘 맞습니다.

스타일 없는 패키지를 쓰면 마크업과 스타일을 온전히 다룰 수 있습니다. 스타일이 붙은
버전과 테마 예시는 [Questionnaire](/docs/components/base/questionnaire) 를 보세요.

## Installation

```bash
npm install @shadcn/react
```

## Import

```tsx
import { Questionnaire } from "@shadcn/react/questionnaire"
```

`Questionnaire` 는 구성 요소를 네임스페이스 하나로 내보냅니다. 각 구성 요소는 기본
요소의 기본 prop 을 그대로 받습니다.

## Anatomy

```tsx
<Questionnaire.Root>
  <Questionnaire.Progress />
  <Questionnaire.Item name="question">
    <Questionnaire.Title />
    <Questionnaire.Description />
    <Questionnaire.Choices>
      <Questionnaire.Choice>
        <Questionnaire.ChoiceInput />
        <Questionnaire.ChoiceLabel />
        <Questionnaire.ChoiceShortcut />
      </Questionnaire.Choice>
      <Questionnaire.Input />
    </Questionnaire.Choices>
    <Questionnaire.Error />
  </Questionnaire.Item>
  <Questionnaire.Previous />
  <Questionnaire.Skip />
  <Questionnaire.Next />
  <Questionnaire.Submit />
</Questionnaire.Root>
```

`Root` 는 form 을 그립니다. `Item` 은 fieldset 이고 `Title` 이 그 legend 입니다.
`ChoiceInput` 은 기본 radio 나 checkbox 를 그립니다.

## Styled version

스타일이 붙은 레지스트리 컴포넌트는 개별 이름을 씁니다.

| Styled component                                                                         | Unstyled part                                                                                |
| ---------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `Questionnaire`                                                                          | `Questionnaire.Root`                                                                         |
| `QuestionnaireProgress`                                                                  | `Questionnaire.Progress`                                                                     |
| `QuestionnaireItem`                                                                      | `Questionnaire.Item`                                                                         |
| `QuestionnaireTitle`                                                                     | `Questionnaire.Title`                                                                        |
| `QuestionnaireDescription`                                                               | `Questionnaire.Description`                                                                  |
| `QuestionnaireChoices`                                                                   | `Questionnaire.Choices`                                                                      |
| `QuestionnaireChoice`                                                                    | `Questionnaire.Choice` with `ChoiceInput`, `ChoiceLabel`, and `ChoiceShortcut`               |
| `QuestionnaireInput`                                                                     | `Questionnaire.Input`                                                                        |
| `QuestionnaireError`                                                                     | `Questionnaire.Error`                                                                        |
| `QuestionnaireActions`                                                                   | None. Layout only; use your own container.                                                   |
| `QuestionnairePrevious`, `QuestionnaireSkip`, `QuestionnaireNext`, `QuestionnaireSubmit` | `Questionnaire.Previous`, `Questionnaire.Skip`, `Questionnaire.Next`, `Questionnaire.Submit` |

스타일이 붙은 `QuestionnaireChoice` 는 입력·레이블·단축키·표시를 대신 엮어 줍니다.
스타일 없는 패키지에서는 그 구성 요소를 직접 엮으면 됩니다.

`Item` 하나가 한 단계입니다. `name` 이 그 단계를 가리키며 답변의 폼 필드 이름이
됩니다. 제출되는 답은 `Choice.value` 입니다.

```tsx
const items = [
  {
    name: "prototype",
    required: true,

    description: "Choose a direction or write your own.",
    choices: [
      {
        value: "delegation",

      },
      {
        value: "questions",
        label: "Question prompts",
        description: "Show choices while the interface waits.",
      },
      { value: "both", label: "Both together" },
    ],
    input: { label: "Another answer", placeholder: "Type another answer…" },
  },
  {
    name: "detail",
    required: false,
    prompt: "How much detail should it include?",
    description: "Skip this if you are not sure yet.",
    choices: [
      { value: "focused", label: "Focused" },
      { value: "complete", label: "Complete flow" },
    ],
  },
] as const
```

```tsx showLineNumbers
"use client"

import * as React from "react"
import { Questionnaire } from "@shadcn/react/questionnaire"

export function ProjectQuestionnaire() {
  function handleSubmit(event: React.FormEvent<HTMLFormElement>) {
    event.preventDefault()

    const formData = new FormData(event.currentTarget)

    console.log({
      prototype: formData.get("prototype"),
      detail: formData.get("detail"),
    })
  }

  return (
    <Questionnaire.Root items={items} onSubmit={handleSubmit}>
      <Questionnaire.Progress />
      {items.map((question) => (
        <Questionnaire.Item
          key={question.name}
          name={question.name}
          required={question.required}
        >
          <Questionnaire.Title>{question.prompt}</Questionnaire.Title>
          <Questionnaire.Description>
            {question.description}
          </Questionnaire.Description>
          <Questionnaire.Choices>
            {question.choices.map((choice) => (
              <Questionnaire.Choice key={choice.value} value={choice.value}>
                <Questionnaire.ChoiceInput />
                <Questionnaire.ChoiceLabel>
                  <span>{choice.label}</span>
                  {"description" in choice ? (
                    <span>{choice.description}</span>
                  ) : null}
                </Questionnaire.ChoiceLabel>
                <Questionnaire.ChoiceShortcut />
              </Questionnaire.Choice>
            ))}
            {"input" in question ? (
              <Questionnaire.Input
                aria-label={question.input.label}
                placeholder={question.input.placeholder}
              />
            ) : null}
          </Questionnaire.Choices>
          <Questionnaire.Error />
        </Questionnaire.Item>
      ))}
      <Questionnaire.Previous />
      <Questionnaire.Skip />
      <Questionnaire.Next />
      <Questionnaire.Submit />
    </Questionnaire.Root>
  )
}
```

`Item` 과 `Choice` 로 그리는 것과 같은 `items` 를 `Root` 에도 넘기세요. 그러면 항목
순서·진행도·동작 노출·답변 단축키가 서버에서 그린 HTML 에도 담깁니다.

```tsx showLineNumbers
"use client"

import * as React from "react"
import {
  Questionnaire,
  type QuestionnaireItemStatus,
} from "@shadcn/react/questionnaire"

export function PlanningQuestionnaire() {
  const [timingStatus, setTimingStatus] =
    React.useState<QuestionnaireItemStatus>("unanswered")

  function handleSubmit(event: React.FormEvent<HTMLFormElement>) {
    event.preventDefault()

    const formData = new FormData(event.currentTarget)

    console.log({
      timing:
        timingStatus === "skipped"
          ? { status: "skipped" }
          : {
              status: "answered",
              value: formData.get("timing"),
            },
    })
  }

  return (
    <Questionnaire.Root defaultItem="timing" onSubmit={handleSubmit}>
      <Questionnaire.Item name="timing" onStatusChange={setTimingStatus}>
        <Questionnaire.Title>
          When should this be revisited?
        </Questionnaire.Title>
        <Questionnaire.Description>
          Skip this if timing has not been decided.
        </Questionnaire.Description>
        <Questionnaire.Choices>
          <Questionnaire.Choice value="week">
            <Questionnaire.ChoiceInput />
            <Questionnaire.ChoiceLabel>This week</Questionnaire.ChoiceLabel>
            <Questionnaire.ChoiceShortcut />
          </Questionnaire.Choice>
          <Questionnaire.Choice value="cycle">
            <Questionnaire.ChoiceInput />
            <Questionnaire.ChoiceLabel>Next cycle</Questionnaire.ChoiceLabel>
            <Questionnaire.ChoiceShortcut />
          </Questionnaire.Choice>
        </Questionnaire.Choices>
      </Questionnaire.Item>
      <Questionnaire.Skip />
      <Questionnaire.Submit />
    </Questionnaire.Root>
  )
}
```

## Validation

Questionnaire 는 다음으로 넘어가기 전에 현재 항목을 검증하고, 폼을 제출할 때는
활성화된 모든 항목을 검증합니다.

- 필수 항목은 답이 있어야 통과합니다.
- 선택 항목은 답이 있거나 명시적으로 건너뛰어야 통과합니다.
- 비활성 항목과 답변은 무시합니다.

`required` 를 준다고 “필수” 같은 글자가 보이지는 않습니다. `Title` 이나
`Description` 에 적어 주세요.

검증에 실패하면 Questionnaire 가 문제가 있는 항목을 그대로 두거나 열고 답변에
포커스를 줍니다. 메시지를 보여 주려면 `Error` 를 넣으세요.

```tsx
<Questionnaire.Item name="scope" required>
  <Questionnaire.Title>
    What should the project include? (Required)
  </Questionnaire.Title>
  <Questionnaire.Choices>{/* choices */}</Questionnaire.Choices>
  <Questionnaire.Error />
</Questionnaire.Item>
```

`Error` 는 항목에 문제가 생기기 전까지 숨어 있습니다. 자식을 넘기면 기본 메시지를
바꿀 수 있습니다.

```tsx
<Questionnaire.Error>Please choose a project scope.</Questionnaire.Error>
```

`Error` 가 없어도 검증은 동작합니다. 그려진 경우 메시지는 스크린 리더에도
읽힙니다.

Zod 같은 외부 검증기를 쓴다면 `Item.invalid` 를 지정하고 `Error` 에 메시지를 그린 뒤
`Root.item` 을 문제가 있는 첫 항목으로 옮기세요.

<ComponentPreview
  align="end"

  name="questionnaire-validation"

```tsx

  <Questionnaire.Item invalid={Boolean(errors.detail)} name="detail" required>
    <Questionnaire.Title>How much detail?</Questionnaire.Title>
```

`disabled` 를 주면 그 항목이 흐름에서 빠집니다. 비활성 항목은 진행도·이동·검증·제출에서
모두 제외됩니다.

<ComponentPreview
  align="end"

  name="questionnaire-conditional"
  hideCode
  previewClassName="min-h-[520px] p-4 sm:p-8"
/>

```tsx
const [runtime, setRuntime] = React.useState("local")

<Questionnaire.Root>
  <Questionnaire.Item name="runtime" required>
    <Questionnaire.Title>Where should the agent run?</Questionnaire.Title>
    <Questionnaire.Choices>
      <Questionnaire.Choice
        value="local"
        checked={runtime === "local"}
        onChange={() => setRuntime("local")}
      >
        <Questionnaire.ChoiceInput />
        <Questionnaire.ChoiceLabel>Locally</Questionnaire.ChoiceLabel>
      </Questionnaire.Choice>
      <Questionnaire.Choice
        value="remote"
        checked={runtime === "remote"}
        onChange={() => setRuntime("remote")}
      >
        <Questionnaire.ChoiceInput />
        <Questionnaire.ChoiceLabel>
          Remote environment
        </Questionnaire.ChoiceLabel>
      </Questionnaire.Choice>
    </Questionnaire.Choices>
  </Questionnaire.Item>
  <Questionnaire.Item name="region" disabled={runtime !== "remote"} required>
    {/* remote-only question */}
  </Questionnaire.Item>
</Questionnaire.Root>
```


```css
[data-navigation-action][data-status="unanswered"] {
  opacity: 0.5;
}
```

```tsx
      <Questionnaire.Submit>Submit</Questionnaire.Submit>
    </CardFooter>
  </Card>
</Questionnaire.Root>
```

## Custom render targets

구성 요소의 기본 요소를 바꾸려면 `render` 를 쓰세요. 요소를 넘기거나, 상태가 필요하면
함수를 넘깁니다.

```tsx
<Questionnaire.Next render={<Button />}>Next</Questionnaire.Next>
```

`Root` 와 `Item` 은 언제나 `form` 과 `fieldset` 을 그립니다. `Title` 이 더 이상
`legend` 를 그리지 않는다면 `id` 를 주고 그 값을 `Item` 의 `aria-labelledby` 로
넘기세요.

프리미티브는 `data-slot` 을 붙이지 않습니다. 슬롯과 시각 표시는 스타일이 붙은 껍데기가
맡습니다.

## Native forms

`Root` 는 언제나 기본 form 을 그리며 `onSubmit`·`onReset`·`action` 을 비롯한 form prop 을
지원합니다. Questionnaire 를 다른 form 안에 넣지 마세요.

답변은 기본 입력 요소를 통해 직렬화됩니다.

- 답이 하나면 `FormData.get(itemName)` 으로 읽습니다.
- 답이 여럿이면 `FormData.getAll(itemName)` 으로 읽습니다.
- 건너뛴 항목은 `FormData` 에 담기지 않습니다.
- 건너뛴 답과 빠진 답을 구분하려면 `Item.onStatusChange` 를 쓰세요.

`Root` 는 기본으로 `noValidate` 를 붙입니다. 그래서 브라우저 기본 검증 UI 대신
`Questionnaire.Error` 로 검증 결과를 보여 줍니다.

`form.reset()` 을 부르면 처음 항목·기본 답변·건너뛴 상태·검증 상태가 모두 처음으로
돌아갑니다.

## Keyboard navigation

Questionnaire 는 기본 radio·checkbox·input·button 동작 위에 올려져 있습니다.

| Key                      | Behavior                                                                                                                        |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| `Tab`                    | Moves focus between answer controls and visible actions.                                                                        |
| `Shift` + `Tab`          | Moves focus to the previous control or action.                                                                                  |
| `ArrowUp`                | Moves to the previous answer from the item, a fixed answer, or an empty text-like freeform input. Native radios also select it. |
| `ArrowDown`              | Moves to the next answer from the item, a fixed answer, or an empty text-like freeform input. Native radios also select it.     |
| `ArrowLeft`              | Moves to the previous item when focus is outside a radio or text entry control.                                                 |
| `ArrowRight`             | Moves to the next item when the active item is answered or skipped and focus is outside a radio or text entry control.          |
| `Space`                  | Selects a radio, toggles a checkbox, or activates a focused action.                                                             |
| `Enter`                  | Continues from a selected choice or selected, filled input; activates a focused action.                                         |
| `Command/Ctrl` + `Enter` | Validates and continues from anywhere inside the questionnaire, or submits the final item.                                      |

텍스트 입력에 글자를 넣는 동안에는 단축키와 화살표 이동이 멈춥니다. 루트의
`onKeyDown` 을 막으면 키 처리가 아예 꺼집니다.

눌렀을 때 검증 결과를 보여 줄 수 있도록 이동 버튼은 기본적으로 켜져 있습니다. 답하지
않은 상태의 버튼을 잠그거나 다르게 꾸미려면 [이동 상태](#navigation-state)를 보세요.

## Accessibility

- `Item` 은 `fieldset` 을 그립니다.
- `Title` 은 기본적으로 fieldset 의 `legend` 를 그립니다. 다른 요소로 바꿨다면 그
  `id` 를 항목의 `aria-labelledby` 와 이어 주세요.
- `Description` 과 현재 `Error` 는 `aria-describedby` 로 이어집니다.
- 문제가 있는 항목과 답변 요소에는 `aria-invalid` 가 붙습니다.
- `Progress` 는 현재값·최솟값·최댓값·텍스트를 갖춘 이름 있는 progressbar 를 그립니다.
- 고정 선택지는 기본 radio 와 checkbox 를 씁니다.
- 배정된 단축키와 쓸 수 있는 이동은 `aria-keyshortcuts` 로 알립니다.
- 활성이 아닌 항목과 버튼은 숨겨지고 동작하지 않습니다.
- 이동하면 새로 활성이 된 fieldset 에 포커스가 갑니다.
- 검증에 걸리면 처음 답변 요소에 포커스가 갑니다.
- 비활성 항목은 진행도와 이동에서 빠집니다.

`Input` 에는 언제나 접근성 이름을 주세요. 보이는 레이블이 있다면 `id` 로 이어 줍니다.

```tsx
<Label htmlFor="other-answer">Other answer</Label>
<Questionnaire.Input
  id="other-answer"
  placeholder="Type another answer…"
/>
```

디자인에 보이는 레이블이 없다면 `aria-label` 이나 `aria-labelledby` 를 쓰세요.

```tsx
<Questionnaire.Input
  aria-label="Other answer"
  placeholder="Type another answer…"
/>
```

placeholder 는 레이블이 아닙니다.

## Data attributes

꾸밀 때는 아래 속성을 쓰세요. 참·거짓 속성은 참일 때만 붙고 거짓이면 사라집니다.

### Root and Progress

| Data attribute   | Value                                            |
| ---------------- | ------------------------------------------------ |
| `data-current`   | One-based active item position.                  |
| `data-total`     | Number of enabled items.                         |
| `data-first`     | Present on the first item.                       |
| `data-last`      | Present on the last item.                        |
| `data-shortcuts` | `"letters"` \| `"numbers"` on Root when enabled. |

### Item

| Data attribute  | Value                                         |
| --------------- | --------------------------------------------- |
| `data-active`   | Present when active.                          |
| `data-status`   | `"unanswered"` \| `"answered"` \| `"skipped"` |
| `data-required` | Present when required.                        |
| `data-multiple` | Present when multiple.                        |
| `data-disabled` | Present when disabled.                        |
| `data-invalid`  | Present after failed validation.              |

### Choice

| Data attribute   | Value                             |
| ---------------- | --------------------------------- |
| `data-type`      | `"radio"` \| `"checkbox"`         |
| `data-checked`   | Present when selected.            |
| `data-unchecked` | Present when not selected.        |
| `data-disabled`  | Present when disabled.            |
| `data-invalid`   | Present when its item is invalid. |
| `data-shortcut`  | Assigned letter or number.        |

### Choices

| Data attribute   | Value                                    |
| ---------------- | ---------------------------------------- |
| `data-shortcuts` | `"letters"` \| `"numbers"` when enabled. |

### Input

| Data attribute  | Value                                      |
| --------------- | ------------------------------------------ |
| `data-filled`   | Present when the input has non-empty text. |
| `data-empty`    | Present when the input has no answer text. |
| `data-disabled` | Present when disabled.                     |
| `data-invalid`  | Present when its item is invalid.          |

### Error

| Data attribute | Value                              |
| -------------- | ---------------------------------- |
| `data-invalid` | Present while the error is active. |

### Previous, Skip, Next, and Submit

| Data attribute  | Value                                                      |
| --------------- | ---------------------------------------------------------- |
| `data-visible`  | Present when the action applies to the active item.        |
| `data-hidden`   | Present when the action does not apply.                    |
| `data-disabled` | Present when disabled.                                     |
| `data-shortcut` | `"Enter"` on an enabled, visible Next or Submit.           |
| `data-status`   | Active item: `"unanswered"`, `"answered"`, or `"skipped"`. |

`Title` 과 `Description` 에는 상태 속성이 없습니다. 헤드리스 구성 요소는 `data-slot` 을
붙이지 않습니다.

## API Reference

### Questionnaire.Root

폼이자 전체를 조율하는 루트입니다.

| Prop           | Type                                     | Default            | Description                                                                       |
| -------------- | ---------------------------------------- | ------------------ | --------------------------------------------------------------------------------- |
| `item`         | `string`                                 | -                  | 제어되는 현재 항목의 이름입니다.                                                  |
| `defaultItem`  | `string`                                 | first enabled item | 처음 활성이 되는 항목의 이름입니다.                                               |
| `items`        | `readonly QuestionnaireItemDefinition[]` | -                  | 서버 렌더링과 항목 순서를 위한 선택 데이터입니다.                                 |
| `onItemChange` | `(item: string) => void`                 | -                  | 다른 항목으로 이동해 달라는 요청이 있을 때 불립니다.                              |
| `shortcuts`    | `"letters" \| "numbers"`                 | -                  | 정의된 순서나 그려진 DOM 순서로 답변 단축키를 배정합니다.                         |
| `noValidate`   | `boolean`                                | `true`             | questionnaire 검증은 그대로 두고 브라우저 기본 검증 UI 만 끕니다.                 |
| `onSubmit`     | `FormEventHandler<HTMLFormElement>`      | -                  | 모든 항목이 검증을 통과한 뒤 불리는 기본 form 제출 핸들러입니다.                  |
| `onReset`      | `FormEventHandler<HTMLFormElement>`      | -                  | 기본 reset 핸들러입니다. 기본 동작을 막으면 questionnaire 가 초기화되지 않습니다. |

루트는 `current`·`total`·`first`·`last`·`shortcuts` 를 데이터 속성으로 알려 줍니다.

선택 데이터의 타입은 `@shadcn/react/questionnaire` 에서 내보냅니다.

```ts
type QuestionnaireChoiceDefinition = {
  value: string
  disabled?: boolean
}

type QuestionnaireItemDefinition = {
  name: string
  required?: boolean
  disabled?: boolean
  choices?: readonly QuestionnaireChoiceDefinition[]
}
```

### Questionnaire.Progress

활성화된 항목들 안에서의 위치입니다.

| Prop         | Type                                             | Default                         | Description                              |
| ------------ | ------------------------------------------------ | ------------------------------- | ---------------------------------------- |
| `children`   | `React.ReactNode`                                | `Question {current} of {total}` | 진행도 자리에 넣을 내용입니다.           |
| `aria-label` | `string`                                         | `Questionnaire progress`        | progressbar 의 접근성 이름입니다.        |
| `render`     | `ReactElement \| (props, state) => ReactElement` | `<div>`                         | 진행도 상태를 함께 받는 렌더 대상입니다. |

render 상태에는 `current`·`total`·`first`·`last` 가 담깁니다.

### Questionnaire.Item

설문의 한 단계입니다.

| Prop             | Type                                        | Default  | Description                                                     |
| ---------------- | ------------------------------------------- | -------- | --------------------------------------------------------------- |
| `name`           | `string`                                    | required | 항목을 구분하는 이름이자 폼 필드 이름입니다.                    |
| `invalid`        | `boolean`                                   | `false`  | 외부 검증기가 이 항목에 문제가 있다고 표시할 때 씁니다.         |
| `required`       | `boolean`                                   | `false`  | 답을 반드시 받고 건너뛰기를 막습니다.                           |
| `multiple`       | `boolean`                                   | `false`  | 고정 선택지를 checkbox 로 그립니다.                             |
| `disabled`       | `boolean`                                   | `false`  | 이 항목을 진행도와 이동에서 뺍니다.                             |
| `onStatusChange` | `(status: QuestionnaireItemStatus) => void` | -        | `"unanswered"`·`"answered"`·`"skipped"` 로 바뀔 때 알려 줍니다. |

항목은 `active`·`disabled`·`invalid`·`multiple`·`required`·`status` 를 데이터 속성으로
알려 줍니다.

항목 이름은 한 Root 안에서 겹치면 안 됩니다. 이 이름은 fieldset 이 아니라 답변
요소의 것입니다.

### Questionnaire.Title

항목 제목입니다. 기본적으로 의미가 있는 `legend` 를 그립니다.

| Prop     | Type                              | Default    | Description                                                                        |
| -------- | --------------------------------- | ---------- | ---------------------------------------------------------------------------------- |
| `render` | `ReactElement \| render function` | `<legend>` | 직접 지정하는 렌더 대상입니다. 그 `id` 를 항목의 `aria-labelledby` 와 이어 주세요. |

### Questionnaire.Description

`aria-describedby` 로 항목과 이어지는 보조 설명입니다.

| Prop     | Type                              | Default | Description                    |
| -------- | --------------------------------- | ------- | ------------------------------ |
| `render` | `ReactElement \| render function` | `<p>`   | 직접 지정하는 렌더 대상입니다. |

### Questionnaire.Choices

고정 선택지와 자유 입력을 담는 레이아웃 컨테이너입니다.

| Prop     | Type                              | Default | Description                    |
| -------- | --------------------------------- | ------- | ------------------------------ |
| `render` | `ReactElement \| render function` | `<div>` | 직접 지정하는 렌더 대상입니다. |

render 상태에는 `shortcuts` 가 담깁니다.

### Questionnaire.Choice

고정 답변을 담는 컨테이너입니다. 안에 `ChoiceInput` 하나와 `ChoiceLabel` 하나, 그리고
원한다면 `ChoiceShortcut` 을 넣습니다. 기본 `<label>` 덕분에 행 전체가 입력 요소와
이어집니다.

| Prop             | Type                                             | Default   | Description                            |
| ---------------- | ------------------------------------------------ | --------- | -------------------------------------- |
| `value`          | `string`                                         | required  | 기본 입력에 담기는 답변 값입니다.      |
| `checked`        | `boolean`                                        | -         | 제어되는 선택 상태입니다.              |
| `defaultChecked` | `boolean`                                        | `false`   | 처음 선택 상태입니다.                  |
| `disabled`       | `boolean`                                        | `false`   | 기본 답변 입력 요소를 잠급니다.        |
| `onChange`       | `ChangeEventHandler<HTMLInputElement>`           | -         | 기본 input 의 change 핸들러입니다.     |
| `render`         | `ReactElement \| (props, state) => ReactElement` | `<label>` | 선택 상태를 함께 받는 렌더 대상입니다. |

render 상태에는 `checked`·`disabled`·`invalid`·`shortcut`·`type` 이 담깁니다.

### Questionnaire.ChoiceInput

자신을 감싼 `Choice` 의 기본 radio 나 checkbox 입니다. 선택·제출·검증·키보드 조작에
필요한 prop 은 Questionnaire 가 넣어 줍니다. `className`·`id`·`ref`·`render` 를 비롯해
부딪히지 않는 기본 input prop 도 받습니다.

`ChoiceInput` 은 반드시 `Choice` 안에서 써야 합니다. render 상태는 `Choice` 와 같습니다.

### Questionnaire.ChoiceLabel

고정 선택지에 보이는 레이블입니다. `Choice` 레이블 안에 `<span>` 을 그리며 기본 span
prop 과 `render` 를 받습니다.

### Questionnaire.ChoiceShortcut

고정 선택지에 보이는 단축키입니다. 배정된 글자나 숫자를 담은 `<span>` 을 그리고,
단축키가 없으면 숨습니다. 기본 span prop 과 `render` 를 받으며 render 상태에는
`shortcut` 이 담깁니다.

### Questionnaire.Input

자유 입력 답변입니다. 기본 `name` 은 이 답변을 담은 항목이 관리합니다.

| Prop           | Type                                             | Default   | Description                                                     |
| -------------- | ------------------------------------------------ | --------- | --------------------------------------------------------------- |
| `value`        | `string \| number \| readonly string[]`          | -         | 제어되는 기본 input 값입니다.                                   |
| `defaultValue` | `string \| number \| readonly string[]`          | -         | 처음 기본 input 값입니다.                                       |
| `disabled`     | `boolean`                                        | `false`   | 입력을 잠급니다.                                                |
| `onChange`     | `ChangeEventHandler<HTMLInputElement>`           | -         | 기본 input 의 change 핸들러입니다.                              |
| `type`         | `QuestionnaireInputType`                         | `"text"`  | `"email"`·`"number"`·`"date"` 처럼 글자를 넣는 입력 종류입니다. |
| `render`       | `ReactElement \| (props, state) => ReactElement` | `<input>` | 입력 상태를 함께 받는 렌더 대상입니다.                          |

render 상태에는 `disabled`·`filled`·`invalid` 가 담깁니다.

### Questionnaire.Error

검증 메시지입니다. 항목이 검증에 걸리기 전까지는 숨어 있습니다.

| Prop       | Type                                             | Default            | Description                            |
| ---------- | ------------------------------------------------ | ------------------ | -------------------------------------- |
| `children` | `React.ReactNode`                                | contextual message | 직접 지정하는 검증 메시지입니다.       |
| `render`   | `ReactElement \| (props, state) => ReactElement` | `<p>`              | 오류 상태를 함께 받는 렌더 대상입니다. |

### Navigation actions

`Previous`·`Skip`·`Next`·`Submit` 는 기본 button 을 그리며, 보였다 숨었다 하는 동안에도
계속 붙어 있습니다.

| Part       | Default type | Visible when             | Disabled when             |
| ---------- | ------------ | ------------------------ | ------------------------- |
| `Previous` | `"button"`   | Not on the first item.   | Consumer sets `disabled`. |
| `Skip`     | `"button"`   | Active item is optional. | Consumer sets `disabled`. |
| `Next`     | `"button"`   | Not on the last item.    | Consumer sets `disabled`. |
| `Submit`   | `"submit"`   | On the last item.        | Consumer sets `disabled`. |

각각 기본 button prop 과 아래 값을 받습니다.

| Prop     | Type                                             | Description                            |
| -------- | ------------------------------------------------ | -------------------------------------- |
| `render` | `ReactElement \| (props, state) => ReactElement` | 이동 상태를 함께 받는 렌더 대상입니다. |

render 상태에는 `visible`·`disabled`·`shortcut` 과 현재 항목의 `status` 가 담깁니다.
