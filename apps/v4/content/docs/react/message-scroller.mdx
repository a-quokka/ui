`MessageScroller` 는 `@shadcn/react` 패키지에 헤드리스 프리미티브로 들어 있습니다.
턴 고정, 스트리밍 출력 따라가기, 이전 기록을 불러올 때 읽던 자리 지키기,
노출 상태 추적 같은 스크롤 동작을 모두 패키지가 맡고, 스타일은 전혀 넣지
않습니다.

레지스트리의 `message-scroller.tsx` 는 여기에 Tailwind 클래스만 얹은 얇은 껍데기입니다.
마크업과 스타일을 온전히 다루고 싶거나 레지스트리를 쓰지 않는다면 패키지를 바로
쓰세요.

동작 설명과 실제 예시는 [Message Scroller](/docs/components/base/message-scroller)
컴포넌트 문서를 보세요.

## Installation

```bash
npm install @shadcn/react
```

## Usage

```tsx
import {
  MessageScroller,
  useMessageScroller,
} from "@shadcn/react/message-scroller"
```

이 패키지는 개별 컴포넌트 대신 네임스페이스 객체를 내보냅니다. 구성 요소와 동작은
스타일이 붙은 컴포넌트와 같고 스타일만 없습니다.

```tsx
<MessageScroller.Provider>
  <MessageScroller.Root>
    <MessageScroller.Viewport>
      <MessageScroller.Content>
        {messages.map((message) => (
          <MessageScroller.Item
            key={message.id}
            messageId={message.id}
            scrollAnchor={message.role === "user"}
          >
            {/* your message UI */}
          </MessageScroller.Item>
        ))}
      </MessageScroller.Content>
    </MessageScroller.Viewport>
    <MessageScroller.Button />
  </MessageScroller.Root>
</MessageScroller.Provider>
```

## Parts

스타일이 붙은 컴포넌트를 쓰던 분이라면 각 구성 요소가 네임스페이스 객체와 이렇게
대응합니다.

| Styled component          | Unstyled part              |
| ------------------------- | -------------------------- |
| `MessageScrollerProvider` | `MessageScroller.Provider` |
| `MessageScroller`         | `MessageScroller.Root`     |
| `MessageScrollerViewport` | `MessageScroller.Viewport` |
| `MessageScrollerContent`  | `MessageScroller.Content`  |
| `MessageScrollerItem`     | `MessageScroller.Item`     |
| `MessageScrollerButton`   | `MessageScroller.Button`   |

훅은 `MessageScroller.Provider` 에서 값을 읽으므로 가져오는 방법도 동작도
똑같습니다.

```tsx
import {
  useMessageScroller,
  useMessageScrollerScrollable,
  useMessageScrollerVisibility,
} from "@shadcn/react/message-scroller"
```

## Example

직접 스타일을 넣고 스크롤러를 AI SDK 와 이어 붙인 전체 예시입니다.

```tsx showLineNumbers
"use client"

import { useChat } from "@ai-sdk/react"
import { MessageScroller } from "@shadcn/react/message-scroller"
import { DefaultChatTransport } from "ai"

import { ChatInput } from "@/components/chat-input"

export function Chat() {
  const { messages, sendMessage, status } = useChat({
    transport: new DefaultChatTransport({ api: "/api/chat" }),
  })

  return (
    <div className="flex h-svh w-full flex-col">
      <MessageScroller.Provider>
        <MessageScroller.Root className="relative flex flex-1 flex-col overflow-hidden">
          <MessageScroller.Viewport className="flex flex-1 flex-col overflow-y-auto">
            <MessageScroller.Content className="flex flex-col gap-4 p-6 text-base">
              {messages.map((message, index) => (
                <MessageScroller.Item
                  key={message.id}
                  messageId={`message-${index}`}
                  scrollAnchor={message.role === "user"}
                >
                  <div className="rounded-lg bg-muted p-4">
                    {message.parts.map((part, i) =>
                      part.type === "text" ? (
                        <span key={i}>{part.text}</span>
                      ) : null
                    )}
                  </div>
                </MessageScroller.Item>
              ))}
            </MessageScroller.Content>
          </MessageScroller.Viewport>
          <MessageScroller.Button className="absolute bottom-2 left-1/2 z-10 -translate-x-1/2 rounded-full border bg-background px-3 py-1 text-sm font-medium inert:opacity-0">
            Jump to latest
          </MessageScroller.Button>
        </MessageScroller.Root>
      </MessageScroller.Provider>
      <ChatInput onSend={sendMessage} disabled={status !== "ready"} />
    </div>
  )
}
```

## API Reference

### MessageScroller.Provider

헤드리스 루트입니다. 스크롤 상태와 동작 관련 prop 을 갖고 있다가 각 구성 요소와
훅에 전달합니다. 자체 DOM 은 만들지 않습니다.

| Prop                     | Type                                | Default | Description                                                                                                                                                                        |
| ------------------------ | ----------------------------------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `autoScroll`             | `boolean`                           | `false` | 읽는 사람이 이미 맨 아래에 있을 때만 새 내용을 따라갑니다. 휠·터치·키보드 스크롤이나 직접 이동하면 따라가기가 풀립니다.                                                            |
| `defaultScrollPosition`  | `"start" \| "end" \| "last-anchor"` | `"end"` | 내용이 처음 채워질 때의 시작 위치이며 한 번만 적용됩니다. `"last-anchor"` 는 마지막 `scrollAnchor` 행에서 시작하고, 턴이 화면에 다 들어가거나 앵커가 없으면 `"end"` 로 물러납니다. |
| `scrollEdgeThreshold`    | `number`                            | `8`     | 이만큼 떨어져 있어도 맨 위·맨 아래로 봅니다. 상태 속성과 스크롤 버튼 노출을 좌우합니다.                                                                                            |
| `scrollMargin`           | `number`                            | `0`     | `scrollToMessage` 와 노출 판정, 코드로 지정한 대상에서 맞춰지는 쪽에 주는 여백입니다.                                                                                              |
| `scrollPreviousItemPeek` | `number`                            | `64`    | 새로 붙은 `scrollAnchor` 항목을 놓을 때 앞 항목이 조금 보이도록 `scrollMargin` 에 더하는 여백입니다.                                                                               |

### MessageScroller.Root

틀이자 레이아웃 컨테이너입니다. 부모를 가득 채우므로 높이가 정해진 레이아웃 안,
그리고 `MessageScroller.Provider` 안에서 쓰세요.

| Prop       | Type                          | Default | Description                        |
| ---------- | ----------------------------- | ------- | ---------------------------------- |
| `...props` | `React.ComponentProps<"div">` | -       | 틀 요소에 그대로 넘길 prop 입니다. |

루트에도 아래의 스크롤 상태 속성이 그대로 붙습니다(뷰포트에도 붙습니다). 그래서
틀 가장자리를 흐리게 하는 식으로 스크롤 상태에 따라 컨테이너를 꾸밀 수 있습니다.

| Data attribute       | Value                                             | Description                                                                                                         |
| -------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `data-scrollable`    | `"start"` \| `"end"` \| `"start end"` \| _absent_ | 뷰포트가 스크롤할 수 있는 방향입니다. `[data-scrollable~="end"]` 로 확인하며, 없으면 내용이 다 들어간다는 뜻입니다. |
| `data-autoscrolling` | present                                           | 뷰포트가 최신 메시지로 스크롤하는 동안 붙습니다.                                                                    |

### MessageScroller.Viewport

스크롤되는 뷰포트입니다.

| Prop                      | Type                          | Default      | Description                                                       |
| ------------------------- | ----------------------------- | ------------ | ----------------------------------------------------------------- |
| `preserveScrollOnPrepend` | `boolean`                     | `true`       | 이전 기록이 위에 붙을 때 처음 보이던 메시지가 그대로 있게 합니다. |
| `role`                    | `string`                      | `"region"`   | 이름이 붙은 대화 기록 뷰포트의 랜드마크 role 입니다.              |
| `aria-label`              | `string`                      | `"Messages"` | 스크롤되는 대화 기록의 접근성 이름입니다.                         |
| `tabIndex`                | `number`                      | `0`          | 대화 기록 뷰포트를 키보드로 스크롤할 수 있게 합니다.              |
| `...props`                | `React.ComponentProps<"div">` | -            | 뷰포트 요소에 그대로 넘길 prop 입니다.                            |

| Data attribute       | Value                                             | Description                                                                                                         |
| -------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `data-scrollable`    | `"start"` \| `"end"` \| `"start end"` \| _absent_ | 뷰포트가 스크롤할 수 있는 방향입니다. `[data-scrollable~="end"]` 로 확인하며, 없으면 내용이 다 들어간다는 뜻입니다. |
| `data-autoscrolling` | present                                           | 뷰포트가 최신 메시지로 스크롤하는 동안 붙습니다.                                                                    |

### MessageScroller.Content

대화 기록의 내용 요소입니다. 바로 아래 자식은 모두 `MessageScroller.Item` 이어야
합니다.

| Prop              | Type                          | Default       | Description                                                         |
| ----------------- | ----------------------------- | ------------- | ------------------------------------------------------------------- |
| `role`            | `string`                      | `"log"`       | 실시간 안내를 위해 메시지 목록에 붙는 ARIA role 입니다.             |
| `aria-relevant`   | `string`                      | `"additions"` | 안내할 라이브 영역 변경 범위입니다. 기본값은 새로 생긴 행만입니다.  |
| `aria-busy`       | `boolean`                     | -             | 필요하다면 턴이 스트리밍되는 동안 라이브 영역을 busy 로 표시합니다. |
| `spacerClassName` | `string`                      | -             | 고정된 행의 자리를 만드는 내부 여백 요소의 클래스 이름입니다.       |
| `...props`        | `React.ComponentProps<"div">` | -             | 내용 요소에 그대로 넘길 prop 입니다.                                |

### MessageScroller.Item

대화 기록의 한 행입니다. 메시지·표식·입력 중 표시·구분선·더 보기 행이 될 수 있습니다.

| Prop           | Type                          | Default | Description                                                                        |
| -------------- | ----------------------------- | ------- | ---------------------------------------------------------------------------------- |
| `messageId`    | `string`                      | -       | `scrollToMessage`·노출 판정·앞쪽 추가 시 자리 지키기에 쓰이는 고정된 행 id 입니다. |
| `scrollAnchor` | `boolean`                     | `false` | 이 행을 새 턴이 붙을 때 기준이 되는 턴 경계로 표시합니다.                          |
| `...props`     | `React.ComponentProps<"div">` | -       | 항목 요소에 그대로 넘길 prop 입니다.                                               |

| Data attribute       | Value                 | Description                                    |
| -------------------- | --------------------- | ---------------------------------------------- |
| `data-message-id`    | `string`              | `messageId` 가 있으면 그 값을 그대로 붙입니다. |
| `data-scroll-anchor` | `"true"` \| `"false"` | `scrollAnchor` 값을 그대로 붙입니다.           |

### MessageScroller.Button

대화 기록의 처음이나 끝으로 스크롤하는 버튼입니다. 갈 곳이 없으면 동작하지 않고
탭 순서에서도 빠집니다.

| Prop        | Type                                    | Default    | Description                                                            |
| ----------- | --------------------------------------- | ---------- | ---------------------------------------------------------------------- |
| `behavior`  | `ScrollBehavior`                        | `"smooth"` | 버튼이 목표 끝으로 스크롤할 때 쓰는 기본 스크롤 동작입니다.            |
| `direction` | `"start" \| "end"`                      | `"end"`    | 버튼이 향하는 대화 기록의 끝입니다.                                    |
| `children`  | `React.ReactNode`                       | -          | 버튼 안에 넣을 내용입니다. 기본값은 스크롤 아이콘과 접근성 이름입니다. |
| `render`    | `React.ReactElement \| render function` | -          | 직접 지정하는 렌더 대상입니다.                                         |
| `...props`  | `React.ComponentProps<"button">`        | -          | 버튼에 그대로 넘길 prop 입니다.                                        |

| Data attribute   | Value                 | Description                                     |
| ---------------- | --------------------- | ----------------------------------------------- |
| `data-direction` | `"start"` \| `"end"`  | `direction` 값을 그대로 붙입니다.               |
| `data-active`    | `"true"` \| `"false"` | 지금 이 버튼으로 스크롤할 수 있는지 여부입니다. |

### useMessageScroller

대화 기록을 직접 조작하는 명령입니다.

| Method            | Type                                       | Description                            |
| ----------------- | ------------------------------------------ | -------------------------------------- |
| `scrollToMessage` | `(messageId: string, options?) => boolean` | 이미 그려진 메시지 id 로 스크롤합니다. |
| `scrollToEnd`     | `(options?) => boolean`                    | 최신 메시지로 스크롤합니다.            |
| `scrollToStart`   | `(options?) => boolean`                    | 맨 위로 스크롤합니다.                  |

명령을 적용하지 못하면 모두 `false` 를 돌려줍니다.
`scrollToStart` 와 `scrollToEnd` 는 뷰포트가 아직 없을 때만 `false` 입니다.
`scrollToMessage` 는 대상이 없고 대기열에도 넣을 수 없을 때 `false` 입니다.

명령 옵션입니다.

| Option         | Type                                              | Default                 | Description                                         |
| -------------- | ------------------------------------------------- | ----------------------- | --------------------------------------------------- |
| `align`        | `"start"` \| `"center"` \| `"end"` \| `"nearest"` | `"start"`               | 대상 메시지를 뷰포트 안에서 어디에 맞출지 정합니다. |
| `behavior`     | `ScrollBehavior`                                  | `"auto"`                | 이 명령에 쓸 기본 스크롤 동작입니다.                |
| `scrollMargin` | `number`                                          | provider `scrollMargin` | 이 명령에서 맞춰지는 쪽에 주는 여백입니다.          |

### useMessageScrollerScrollable

뷰포트가 어느 쪽으로 스크롤할 수 있는지 알려 줍니다. 옆에 있는 UI 가 이 값을
자바스크립트로 써야 할 때 쓰세요. 스크롤러 자체를 꾸밀 때는 `data-scrollable`
속성을 쓰는 편이 낫습니다.

| Value   | Type      | Description                                                                                                                                                           |
| ------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `start` | `boolean` | 위쪽으로 스크롤할 수 있는지 여부입니다. 위에 가려진 내용이 있다는 뜻이며, `!start` 면 맨 위입니다.                                                                    |
| `end`   | `boolean` | 아래쪽으로 스크롤할 수 있는지 여부입니다. 아래에 가려진 내용이 있다는 뜻이며, `!end` 면 맨 아래입니다. 따라가기가 맨 아래를 붙잡고 있는 동안에는 계속 `false` 입니다. |

### useMessageScrollerVisibility

개요·검색·현재 턴 UI 를 위한 노출 상태입니다. `useMessageScrollerScrollable` 과
따로 구독하므로 필요한 곳에서만 비용을 치릅니다.

| Value               | Type             | Description                                                                 |
| ------------------- | ---------------- | --------------------------------------------------------------------------- |
| `currentAnchorId`   | `string \| null` | 읽는 줄 위쪽에 있는 마지막 `scrollAnchor` 항목을 기준으로 한 현재 턴입니다. |
| `visibleMessageIds` | `string[]`       | 뷰포트에 걸쳐 있는 메시지 id 를 문서 순서대로 담습니다.                     |

사용자 메시지·고정된 턴·검색 결과처럼 더 좁은 개요가 필요하면 앱에서
`visibleMessageIds` 를 걸러 쓰세요.
